# 📚 Lecture Notes

부트캠프 수업에서 배운 내용을 **주차별·날짜별로 기록하고 복습하기 위한 강의노트 저장소**이다.

매일 수업에서 다룬 개념과 실습 내용을 정리하며, 수업의 전체 흐름과 학습 과정을 다시 확인할 수 있도록 기록한다.

---

## 📂 Structure

```text
lecture-notes/
├── assets/
├── week01/
├── week02/
├── week03/
└── ...
```

각 `week` 폴더에는 해당 주차의 날짜별 강의노트를 저장한다. 학습이 진행됨에 따라 새로운 주차 폴더와 노트를 추가한다.

```text
weekXX/
├── dayXX_MM.DD.md
└── ...
```

---

## 📝 Lecture Notes

각 강의노트에는 수업에서 배운 내용을 중심으로 다음 내용을 정리한다.

- 주요 개념과 용어
- 실습 과정과 주요 코드
- 실행 결과와 개념 비교
- 중요하게 기억하거나 복습할 내용

필요에 따라 표, 코드 예제, 이미지를 함께 사용하며, 노트에 사용한 이미지는 `assets` 폴더에서 관리한다.

---

## 🗓️ Learning Flow

주차별 강의노트를 통해 학습 주제의 흐름을 순서대로 확인할 수 있다.

```text
Python / Git / GitHub
        ↓
Database / SQL / Docker
        ↓
Open API / Web Crawling
        ↓
Linear Algebra / NumPy / Pandas
        ↓
Data Visualization / EDA / Preprocessing
        ↓
Machine Learning / Model Evaluation
        ↓
Deep Learning
        ↓
...
```

위 흐름은 주요 학습 분야를 요약한 것으로, 세부 내용은 각 주차의 강의노트에서 확인할 수 있다.

---

## 🎯 Goal

- 매일 배운 내용을 정리하며 수업을 복습한다.
- 개념과 실습 코드를 함께 기록해 학습 흐름을 이해한다.
- 이전에 배운 내용과 헷갈렸던 개념을 쉽게 다시 찾아본다.
- 주차별 학습 기록을 꾸준히 쌓아간다.
