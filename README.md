# 📚 Lecture Notes

부트캠프 수업에서 배운 내용을  
**주차별·날짜별로 기록하고 복습하기 위한 강의노트 저장소**이다.

매일 수업에서 다룬 개념과 실습 내용을 정리하며,  
수업의 전체 흐름과 학습 과정을 다시 확인할 수 있도록 기록한다.

---

## 📂 Structure

```text
lecture-notes/
├── assets/
├── week01/
├── week02/
├── week03/
├── week04/
├── week05/
└── ...
```

각 `week` 폴더에는 해당 주차에 작성한 날짜별 강의노트를 저장한다.

```text
weekXX/
├── dayXX_MM.DD.md
├── dayXX_MM.DD.md
└── ...
```

학습이 진행됨에 따라 새로운 주차 폴더와 강의노트를 계속 추가한다.

---

## 📝 Lecture Notes

각 강의노트에는 수업에서 배운 내용을 중심으로 다음 내용을 정리한다.

- 주요 개념과 용어
- 수업 중 작성한 주요 코드
- 실습 과정과 결과
- 헷갈리기 쉬운 개념 비교
- 중요하게 기억해야 할 내용
- 추가로 복습이 필요한 내용

필요한 경우 표, 코드 예제, 이미지 등을 함께 사용하여 내용을 정리한다.

강의노트에서 사용하는 이미지는 `assets` 폴더에서 관리한다.

---

## 🗓️ Learning Flow

강의 진행 순서에 따라 노트를 작성하기 때문에  
이 저장소를 통해 학습 과정의 흐름을 순서대로 확인할 수 있다.

```text
Python
   ↓
Git / GitHub
   ↓
Database / SQL
   ↓
Open API / Web Crawling
   ↓
Linear Algebra
   ↓
NumPy / Pandas
   ↓
Data Visualization / EDA
   ↓
Data Preprocessing
   ↓
Machine Learning
   ↓
...
```

수업 진행에 따라 새로운 분야와 주제를 계속 추가한다.

---

## 🎯 Goal

- 매일 배운 내용을 정리하며 수업 내용을 복습한다.
- 개념과 실습 코드를 함께 기록하여 학습 흐름을 이해한다.
- 이전 수업 내용을 필요할 때 빠르게 찾아볼 수 있도록 한다.
- 헷갈렸던 내용과 중요한 내용을 다시 확인할 수 있도록 기록한다.
- 주차별 학습 내용을 연결하여 전체적인 흐름을 이해한다.
- 학습 과정과 성장 기록을 꾸준히 남긴다.
