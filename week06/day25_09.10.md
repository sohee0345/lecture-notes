### 일반화와 과적합 판단

일반화는 훈련에 사용하지 않은 데이터에서도 성능을 유지하는 능력이다. 훈련 점수와 검증 점수의 차이가 크면 과적합 가능성을 의심할 수 있지만, 점수 차이 하나만으로 확정하지 않고 기준 모델과 교차검증 결과를 함께 살펴야 한다.

### 파라미터와 하이퍼파라미터

모델 파라미터는 학습 과정에서 데이터로부터 결정되는 값이고, 하이퍼파라미터는 학습 전에 정해 모델의 구조와 학습 방식을 조절하는 값이다. 모델과 하이퍼파라미터는 검증 데이터로 선택하고 테스트 데이터는 모든 선택이 끝난 뒤 최종 평가에만 사용한다.

> **핵심:** 좋은 모델은 훈련 점수만 높은 모델이 아니라 여러 검증 데이터에서 안정적으로 일반화하는 모델이다.

## 1. 교차검증

교차검증(Cross Validation)은 훈련 데이터를 여러 부분으로 나누고, 검증 부분을 번갈아 바꾸며 모델을 반복 학습·평가하는 방법이다. 하나의 검증 세트만 사용할 때 발생할 수 있는 우연한 데이터 구성의 영향을 줄이고 일반화 성능을 더 안정적으로 추정할 수 있다.

### 1.1 K-Fold 교차검증

K-Fold는 훈련 데이터를 $K$개의 폴드로 나눈다. 매 반복에서 한 폴드를 검증에 사용하고 나머지 $K-1$개를 학습에 사용하므로 총 $K$번 학습한다.

```text
훈련 데이터
  ↓
5개 폴드로 분할
  ↓
1회차: 1번 검증, 2~5번 학습
  ↓
2회차: 2번 검증, 나머지 학습
  ↓
...
  ↓
5회차: 5번 검증, 1~4번 학습
  ↓
다섯 검증 점수의 평균과 표준편차 확인
```

```python
from sklearn.model_selection import KFold, cross_val_score

kf = KFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(
    model,
    X_train,
    y_train,
    scoring="accuracy",
    cv=kf,
)

print(scores.mean(), scores.std())
```

| 확인 항목 | 의미 |
| --- | --- |
| 평균 | 높을수록 여러 검증 폴드에서 전반적인 성능이 좋다는 뜻이다. |
| 표준편차 | 작을수록 데이터 분할이 달라져도 성능이 비교적 안정적이라는 뜻이다. |
| `n_splits=5` | 훈련 데이터를 5개의 폴드로 나눈다는 뜻이다. |

> [!NOTE]
> **Iris 선형 SVC 실습 결과**
> 5-Fold 평균 정확도가 약 `0.978`, 별도 테스트 정확도가 약 `0.967`이었다.

### 1.2 Stratified K-Fold

Stratified K-Fold는 각 폴드의 클래스 비율이 전체 데이터와 비슷하도록 나눈다. 분류 문제, 특히 클래스 불균형이 있거나 클래스별 샘플이 적을 때 사용한다.

```python
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42,
)

scores = cross_val_score(model, X_train, y_train, cv=skf)
```

### 1.3 교차검증 함수

| 함수 | 반환 내용 | 사용 목적 |
| --- | --- | --- |
| `cross_val_score()` | 폴드별 단일 평가 점수 | 한 지표를 간단히 비교 |
| `cross_validate()` | 학습 시간, 평가 시간, 여러 점수 | 여러 지표와 훈련 점수 분석 |
| `cross_val_predict()` | 각 샘플의 Out-of-Fold 예측 | 혼동행렬 등 예측 기반 평가 |

```python
from sklearn.model_selection import cross_validate

result = cross_validate(
    model,
    X_train,
    y_train,
    scoring={"auc": "roc_auc", "f1": "f1"},
    cv=skf,
    return_train_score=True,
)
```

> [!WARNING]
> **전처리 데이터 누수 방지**
> 전처리는 교차검증 전에 전체 데이터에 미리 학습하지 않고 파이프라인에 포함해야 한다. 그래야 각 반복의 훈련 폴드에서만 결측치 대체, 인코딩, 스케일링 기준을 학습할 수 있다.

> **핵심:** 교차검증은 훈련 데이터 안에서 모델을 비교하기 위한 절차이며 별도 테스트 데이터의 역할을 대신하지 않는다.

## 2. AutoML과 PyCaret

AutoML(Automated Machine Learning)은 전처리, 알고리즘 비교, 하이퍼파라미터 탐색과 평가 등 반복적인 머신러닝 워크플로를 자동화한다. 초보자에게는 합리적인 기본값을 제공하고, 숙련자에게는 여러 후보를 빠르게 비교하는 기준선을 제공한다.

> [!WARNING]
> **AutoML 사용 시 주의**
> AutoML이 모든 판단을 대신하는 것은 아니다. 문제 정의, 타깃의 의미, 평가 지표, 데이터 누수 가능성, 모델의 배포 조건과 결과 해석은 사용자가 확인해야 한다.

### 2.1 PyCaret 분류 흐름

실습에서는 PyCaret `3.3.2`와 신용카드 연체 데이터로 분류 모델을 비교했다.

```python
from pycaret.classification import setup, compare_models
from sklearn.model_selection import StratifiedKFold

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

experiment = setup(
    data=train,
    target="default",
    session_id=123,
    verbose=False,
)

best_model = compare_models(sort="AUC", fold=skf)
```

| 설정 및 함수 | 역할 |
| --- | --- |
| `setup()` | 데이터와 타깃을 등록하고 전처리·검증 환경을 구성한다. |
| `session_id` | 재현성을 위한 난수 시드 역할을 한다. |
| `compare_models()` | 여러 모델을 같은 검증 조건에서 비교한다. |
| `sort="AUC"` | 교차검증 AUC를 기준으로 결과를 정렬한다. |

선택한 모델은 혼동행렬, ROC Curve와 특성 중요도 등으로 분석할 수 있다.

```python
plot_model(best_model, plot="confusion_matrix")
plot_model(best_model, plot="auc")
plot_model(best_model, plot="feature")

predictions = predict_model(best_model, data=test)
```

> [!NOTE]
> **파이프라인 저장**
> `save_model()`은 전처리와 모델이 결합된 파이프라인을 저장하고 `load_model()`은 이를 다시 불러온다. 새 데이터에도 학습 때와 같은 전처리를 적용하려면 모델만 따로 저장하지 않고 파이프라인 전체를 보존하는 것이 중요하다.

## 3. 하이퍼파라미터 탐색

하이퍼파라미터 최적화(Hyperparameter Optimization, HPO)는 검증 성능을 기준으로 모델의 설정 조합을 탐색하는 과정이다. 같은 테스트 데이터를 보며 설정을 반복해서 바꾸면 테스트 데이터에 과적합할 수 있으므로 탐색 과정에는 교차검증을 사용한다.

### 3.1 Manual Search

Manual Search는 사람이 경험을 바탕으로 설정을 직접 바꾸어 비교하는 방법이다. 빠르게 탐색 범위를 이해하는 데는 유용하지만, 시도 기록이 일관되지 않거나 일부 조합만 편향되게 살펴볼 수 있다.

### 3.2 Grid Search

Grid Search는 지정한 후보값의 모든 조합을 평가한다. 탐색 공간이 작을 때 체계적이지만 후보 수가 늘면 계산량이 조합 수의 곱만큼 증가한다.

```python
from sklearn.model_selection import GridSearchCV

param_grid = {
    "max_depth": [5, 6, 7],
    "n_estimators": [800, 1000, 1200],
    "learning_rate": [0.001, 0.01, 0.1],
}

search = GridSearchCV(
    estimator=model,
    param_grid=param_grid,
    scoring="roc_auc",
    cv=skf,
    n_jobs=-1,
)
search.fit(X_train, y_train)
```

> [!NOTE]
> **Grid Search 실습 결과**
> LightGBM의 최고 교차검증 ROC-AUC는 약 `0.839`, 테스트 ROC-AUC는 약 `0.888`이었다.

### 3.3 Random Search

Random Search는 탐색 공간에서 정해진 횟수만큼 조합을 무작위로 선택한다. 모든 조합을 보장하지는 않지만 제한된 계산 예산으로 더 넓은 범위를 탐색할 수 있다.

```python
from sklearn.model_selection import RandomizedSearchCV

search = RandomizedSearchCV(
    estimator=model,
    param_distributions=param_grid,
    n_iter=30,
    scoring="roc_auc",
    cv=skf,
    random_state=42,
    n_jobs=-1,
)
search.fit(X_train, y_train)
```

> [!NOTE]
> **Random Search 실습 결과**
> 탐색 범위를 조정한 결과 최고 교차검증 ROC-AUC는 약 `0.841`, 테스트 ROC-AUC는 약 `0.894`였다.

### 3.4 Bayesian Optimization과 Optuna

Bayesian Optimization 계열 방법은 이전 시도의 하이퍼파라미터와 성능을 이용해 다음에 평가할 유망한 지점을 선택한다. Optuna의 TPE Sampler는 좋은 결과와 나쁜 결과의 분포를 바탕으로 다음 후보를 제안한다.

```python
import optuna
from optuna.samplers import TPESampler

def objective(trial):
    params = {
        "max_depth": trial.suggest_int("max_depth", 2, 8),
        "num_leaves": trial.suggest_int("num_leaves", 8, 64),
        "min_child_samples": trial.suggest_int("min_child_samples", 10, 50),
        "n_estimators": trial.suggest_int("n_estimators", 50, 500, step=50),
        "learning_rate": trial.suggest_float(
            "learning_rate", 1e-3, 1e-1, log=True
        ),
        "verbosity": -1,
    }
    model = LGBMClassifier(random_state=42, **params)
    return cross_val_score(
        model,
        X_train,
        y_train,
        scoring="roc_auc",
        cv=skf,
    ).mean()

study = optuna.create_study(
    direction="maximize",
    sampler=TPESampler(seed=42),
)
study.optimize(objective, n_trials=50)
```

> [!NOTE]
> **Optuna 실습 결과**
> 최고 교차검증 ROC-AUC가 약 `0.853`, 선택한 설정의 테스트 ROC-AUC가 약 `0.899`였다.

> [!WARNING]
> **탐색 공간 구성**
> 탐색 공간에는 실제 모델이 사용하는 하이퍼파라미터만 넣어야 한다. 또한 ROC-AUC처럼 클수록 좋은 지표의 누적 최고값을 그릴 때는 `cummax()`를 사용한다.

```python
best_so_far = results["mean_test_score"].cummax()
```

## 4. XAI와 특성 기여도

설명 가능한 인공지능(Explainable Artificial Intelligence, XAI)은 모델의 예측 결과나 전체적인 동작을 사람이 이해할 수 있는 형태로 설명하는 방법과 분야다. 복잡한 모델은 높은 성능을 낼 수 있지만 왜 특정 예측이 나왔는지 알기 어려울 수 있으므로 검증, 신뢰 형성, 오류 분석을 위해 설명이 필요하다.

### 4.1 지역 설명과 전역 설명

| 구분 | 질문 | 대표 방법 |
| --- | --- | --- |
| 지역 설명 | 특정 샘플의 예측에 각 특성이 얼마나 기여했는가? | SHAP |
| 전역 설명 | 모델 전체가 어떤 특성에 얼마나 의존하는가? | SAGE, 전역 SHAP 요약 |

모델이 자체적으로 제공하는 분할 횟수나 이득 기반 특성 중요도는 전역 중요도의 한 종류지만 SAGE와 같은 계산은 아니다.

### 4.2 SHAP

SHAP(Shapley Additive Explanations)은 게임 이론의 Shapley Value를 이용해 예측값과 기준값의 차이를 특성별 기여도로 나눈다.

```text
기준 예측값
  + 특성 A의 기여
  + 특성 B의 기여
  + ...
  = 해당 샘플의 예측값
```

```python
import shap

explainer = shap.Explainer(model, X_train)
shap_values = explainer(X_test)

shap.plots.waterfall(shap_values[0])
shap.plots.beeswarm(shap_values)
shap.plots.bar(shap_values)
```

- 개별 설명은 특정 샘플의 예측을 높이거나 낮춘 특성을 보여준다.
- Beeswarm 형태의 요약 그래프는 전체 샘플에서 특성값과 기여도의 분포를 보여준다.
- Bar 그래프는 절댓값 기준 평균 기여도로 전역 중요도를 요약한다.
- Dependence Plot은 한 특성의 값과 SHAP 기여도의 관계 및 상호작용을 살펴본다.

> [!NOTE]
> **Titanic LightGBM 실습 결과**
> 테스트 ROC-AUC는 약 `0.882`였다. 설명 그래프에서는 성별, 객실 등급, 나이 같은 특성이 예측에 미친 방향과 크기를 확인했다.

> [!WARNING]
> **SHAP 해석**
> SHAP 값은 모델 예측에 대한 기여이지 현실의 인과관계나 단순 상관관계를 증명하지 않는다.

### 4.3 SAGE

SAGE(Shapley Additive Global Importance)는 특정 샘플 하나가 아니라 전체 데이터에서 각 특성이 모델의 손실 감소에 얼마나 기여하는지 평가하는 전역 설명 방법이다. SHAP와 SAGE 모두 Shapley Value 관점을 사용하지만 설명 대상이 다르다.

> **핵심:** XAI는 모델의 판단 근거를 분석하는 도구이며 설명 결과 자체가 인과관계나 모델의 공정성을 보장하지는 않는다.

## 전체 흐름

```text
훈련·검증·테스트 역할 분리
  ↓
K-Fold 또는 Stratified K-Fold로 일반화 성능 추정
  ↓
AutoML로 여러 전처리와 모델을 같은 조건에서 비교
  ↓
Grid·Random·Bayesian 탐색으로 하이퍼파라미터 선택
  ↓
선택한 설정을 별도 테스트 데이터로 최종 평가
  ↓
SHAP·SAGE로 개별 예측과 모델 전체의 의존성 해석
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `K-Fold` | 검증 폴드를 번갈아 바꾸며 $K$번 학습·평가하는 방법 |
| `Stratified K-Fold` | 각 폴드의 클래스 비율을 유지하는 분류용 교차검증 |
| `AutoML` | 전처리, 모델 비교와 튜닝 등 반복적인 워크플로를 자동화하는 방식 |
| `HPO` | 검증 성능을 기준으로 하이퍼파라미터 조합을 탐색하는 과정 |
| `SHAP` | 개별 예측을 특성별 기여도로 분해하는 설명 방법 |
| `SAGE` | 전체 데이터에서 특성별 모델 의존도를 평가하는 전역 설명 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `cross_val_score()` | 폴드별 단일 검증 점수 반환 |
| `StratifiedKFold()` | 클래스 비율을 유지하는 폴드 생성 |
| `compare_models()` | PyCaret에서 여러 모델 비교 |
| `GridSearchCV()` | 모든 지정 조합을 교차검증으로 탐색 |
| `RandomizedSearchCV()` | 제한된 횟수만큼 무작위 조합 탐색 |
| `study.optimize()` | Optuna 목적 함수를 반복 최적화 |

### ⭐ 오늘의 핵심

- 교차검증 평균은 일반화 성능을, 표준편차는 분할에 따른 안정성을 판단하는 데 도움을 준다.
- 분류에서는 클래스 비율을 유지하는 Stratified K-Fold를 우선 고려한다.
- AutoML과 HPO도 올바른 데이터 분리와 평가 지표가 없으면 신뢰할 수 없다.
- 탐색 공간에는 모델이 실제로 사용하는 하이퍼파라미터만 포함한다.
- SHAP는 개별 예측 기여도, SAGE는 모델 전체의 특성 의존도를 설명한다.
