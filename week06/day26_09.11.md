### 교차검증과 전처리 누수

교차검증은 훈련 데이터를 여러 폴드로 나누어 모델의 일반화 성능을 추정한다. 이때 결측치 대체, 인코딩, 스케일링 같은 전처리를 전체 훈련 데이터에 먼저 학습하면 검증 폴드의 정보가 훈련 폴드에 섞이는 데이터 누수가 생긴다. 전처리와 모델을 하나의 파이프라인으로 묶으면 각 교차검증 반복에서 훈련 폴드에만 전처리 기준을 학습할 수 있다.

### 손실과 파라미터 갱신

딥러닝 학습에서도 모델은 손실함수의 값을 줄이는 방향으로 가중치와 편향을 조정한다. 경사하강법은 손실의 기울기를 이용하며, 학습률은 한 번의 업데이트에서 파라미터를 얼마나 움직일지 결정한다.

> **핵심:** 전처리와 모델 학습의 경계를 지키고, 손실을 기준으로 파라미터를 반복 갱신하는 흐름이 머신러닝과 딥러닝 학습의 공통 기반이다.

## 1. Pipeline과 ColumnTransformer

scikit-learn의 `Pipeline`은 전처리 단계와 최종 모델을 정해진 순서로 묶는다. `fit()`을 호출하면 앞 단계는 `fit_transform()`으로 학습·변환되고, 마지막 모델은 변환된 데이터로 학습된다. `predict()`나 `score()`를 호출하면 학습된 전처리 기준으로 입력을 변환한 뒤 모델에 전달한다.

### 1.1 Pipeline이 필요한 이유

유방암 데이터의 SVC 실습에서 훈련 세트 전체로 `MinMaxScaler`를 먼저 학습한 뒤 `GridSearchCV`를 실행하면, 각 교차검증의 검증 폴드도 스케일의 최솟값과 최댓값 계산에 참여한다. 파이프라인 안에 스케일러를 넣으면 교차검증이 분할된 뒤 각 훈련 폴드에서만 스케일러가 학습된다.

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import MinMaxScaler
from sklearn.svm import SVC

pipe = Pipeline([
    ("scaler", MinMaxScaler()),
    ("svm", SVC()),
])

pipe.fit(X_train, y_train)
score = pipe.score(X_test, y_test)
```

> [!NOTE]
> **SVC 실습 결과**
> 파이프라인을 사용한 테스트 정확도는 약 `0.972`였다.

### 1.2 Pipeline 내부 하이퍼파라미터 탐색

파이프라인 내부 단계의 하이퍼파라미터는 `단계이름__파라미터이름` 형식으로 지정한다.

```python
from sklearn.model_selection import GridSearchCV

param_grid = {
    "svm__C": [0.01, 0.1, 1, 10],
    "svm__gamma": [0.01, 0.1, 1, 10],
}

search = GridSearchCV(pipe, param_grid=param_grid, cv=5)
search.fit(X_train, y_train)
```

### 1.3 ColumnTransformer

`ColumnTransformer`는 열의 데이터 유형에 따라 서로 다른 전처리를 적용한다. 수치형 열에는 중앙값 대체와 표준화를, 범주형 열에는 최빈값 대체와 원-핫 인코딩을 적용한 뒤 결과를 합칠 수 있다.

```python
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LinearRegression

numeric_pipe = make_pipeline(
    SimpleImputer(strategy="median"),
    StandardScaler(),
)
categorical_pipe = make_pipeline(
    SimpleImputer(strategy="most_frequent"),
    OneHotEncoder(handle_unknown="ignore"),
)

preprocessor = ColumnTransformer([
    ("num", numeric_pipe, numeric_columns),
    ("cat", categorical_pipe, categorical_columns),
])

model = make_pipeline(preprocessor, LinearRegression())
```

> [!NOTE]
> **전복 데이터 회귀 실습 결과**
> 이 파이프라인의 MAPE는 약 `0.185`였다.

> **핵심:** Pipeline은 처리 순서를 보존하고, ColumnTransformer는 열 유형별 전처리를 하나의 재현 가능한 학습 과정으로 묶는다.

## 2. 인공신경망과 딥러닝

인공신경망은 생물학적 뉴런의 연결 구조에서 아이디어를 얻어 여러 입력을 조합하고 출력을 만드는 모델이다. 가장 기본적인 인공 뉴런은 입력에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 적용한다.

$$z=b+\sum_{i=1}^{m}w_i x_i$$

$$y=h(z)$$

| 기호 | 의미 |
| --- | --- |
| $x_i$ | 입력 특성 |
| $w_i$ | 각 입력의 영향력을 나타내는 가중치 |
| $b$ | 출력 기준을 이동시키는 편향 |
| $h$ | 비선형성을 추가하는 활성화 함수 |

신경망은 입력층, 하나 이상의 은닉층, 출력층으로 구성된다. 데이터가 입력층에서 출력층 방향으로 전달되는 구조를 피드포워드 신경망이라고 한다. 여러 은닉층을 쌓은 인공신경망을 딥러닝 모델이라고 부른다.

> [!WARNING]
> **딥러닝 모델의 일반화**
> 딥러닝은 이미지, 음성, 텍스트 같은 비정형 데이터에서 유용한 표현을 계층적으로 학습할 수 있지만 많은 데이터와 계산 자원이 필요하고 결과를 해석하기 어려울 수 있다. 파라미터 수가 많은 모델은 표현력이 큰 만큼 과적합되기 쉬우며, 데이터 추가 수집, 규제, Dropout, Early Stopping 등의 방법으로 일반화를 관리한다.

출력층과 손실함수는 문제 유형에 맞춰 선택한다.

| 문제 | 대표 출력 활성화 | 대표 손실함수 |
| --- | --- | --- |
| 회귀 | 선형 출력 | MSE, MAE |
| 이진분류 | Sigmoid | Binary Cross Entropy |
| 상호 배타적 다중분류 | Softmax | Cross Entropy |
| 다중 레이블 분류 | 클래스별 Sigmoid | Binary Cross Entropy |

## 3. 역전파와 기울기 소실

신경망 학습은 순전파, 손실 계산, 역전파, 파라미터 갱신 순서로 진행된다.

```text
입력 데이터
  ↓
순전파로 예측 계산
  ↓
예측과 정답으로 손실 계산
  ↓
역전파로 각 파라미터의 기울기 계산
  ↓
옵티마이저가 가중치와 편향 갱신
```

역전파(Backpropagation)는 연쇄법칙을 이용해 출력층에서 입력층 방향으로 손실의 미분을 전달한다. 역전파 자체는 기울기를 계산하며, 실제 파라미터 변경은 옵티마이저가 수행한다.

### 3.1 기울기 소실

기울기 소실(Vanishing Gradient)은 깊은 신경망의 앞쪽 층으로 전달되는 기울기가 매우 작아져 학습이 거의 진행되지 않는 현상이다. Sigmoid의 미분값은 최대 `0.25`이고 입력의 절댓값이 커지면 0에 가까워진다. 역전파에서 이런 값이 여러 층에 걸쳐 반복해서 곱해지면 기울기가 빠르게 작아질 수 있다.

> [!WARNING]
> **ReLU 사용 시 주의**
> ReLU는 양수 영역에서 기울기가 1이므로 Sigmoid보다 기울기 소실을 완화하고 계산도 단순하다. 다만 음수 영역의 기울기가 0이어서 뉴런이 계속 비활성화되는 Dying ReLU 문제가 생길 수 있다.

기울기 소실을 완화하는 대표적인 방법은 다음과 같다.

- ReLU 계열 활성화 함수 사용
- 적절한 가중치 초기화
- Batch Normalization 적용
- 잔차 연결(Residual Connection) 사용
- 네트워크 깊이와 학습률 조절

## 4. Batch, Iteration과 Epoch

배치는 한 번의 순전파와 역전파에 함께 넣는 샘플 묶음이다. 학습 데이터 전체를 한 번 사용하면 1 Epoch이며, 한 배치를 처리해 파라미터를 한 번 갱신하는 단위를 Iteration 또는 Step이라고 한다.

$$\text{Iterations per Epoch}=\left\lceil\frac{\text{Number of Samples}}{\text{Batch Size}}\right\rceil$$

> [!NOTE]
> **Iteration 계산 예시**
> 샘플 60,000개를 배치 크기 100으로 학습하면 한 Epoch에 600 Iteration이 필요하다.

| 방식 | 한 번의 업데이트에 사용하는 데이터 | 특징 |
| --- | --- | --- |
| Batch Gradient Descent | 전체 학습 데이터 | 안정적이지만 메모리와 계산 부담이 큼 |
| Stochastic Gradient Descent | 샘플 1개 | 업데이트가 빠르지만 변동이 큼 |
| Mini-Batch Gradient Descent | 일부 샘플 묶음 | 계산 효율과 안정성의 균형이 좋아 널리 사용 |

> [!WARNING]
> **배치 크기 선택**
> 미니배치는 GPU의 병렬 연산을 활용하고 대규모 데이터를 나누어 처리하는 데 유리하다. 배치 크기가 너무 크면 메모리 사용량이 증가하고, 너무 작으면 기울기의 변동성이 커질 수 있다.

## 5. Batch Normalization과 Optimizer

### 5.1 Batch Normalization

Batch Normalization은 미니배치 통계를 이용해 층의 활성값을 정규화한 뒤 학습 가능한 스케일과 이동 파라미터를 적용한다. 학습을 안정시키고 더 큰 학습률을 사용할 수 있게 도우며 경우에 따라 규제와 비슷한 효과를 낸다.

> [!WARNING]
> **학습 모드와 평가 모드**
> 학습 시에는 현재 미니배치의 평균과 분산을 사용하면서 이동 평균을 갱신하고, 평가·추론 시에는 학습 중 누적한 통계를 사용한다. 따라서 학습 모드와 평가 모드를 올바르게 전환해야 한다.

### 5.2 Optimizer

옵티마이저는 역전파로 구한 기울기를 이용해 파라미터를 갱신하는 알고리즘이다.

| 옵티마이저 | 동작 방식 |
| --- | --- |
| `SGD` | 현재 미니배치의 기울기를 따라 파라미터를 갱신한다. |
| `Momentum` | 이전 이동 방향을 누적해 진동을 줄이고 일관된 방향의 이동을 가속한다. |
| `Adagrad` | 파라미터별 누적 기울기에 따라 학습률을 조절하지만 학습률이 지나치게 작아질 수 있다. |
| `RMSprop` | 최근 제곱 기울기의 이동 평균을 사용해 Adagrad의 학습률 감소 문제를 완화한다. |
| `Adam` | Momentum의 1차 모멘트와 RMSprop 계열의 2차 모멘트를 함께 사용한다. |

> [!NOTE]
> **옵티마이저 선택**
> Adam이 자주 사용되지만 모든 문제에서 항상 최선인 것은 아니다. 검증 성능, 수렴 속도와 일반화를 비교해 선택한다.

## 6. PyTorch Tensor

Tensor는 PyTorch에서 데이터를 저장하고 연산하는 기본 다차원 배열이다. NumPy 배열과 비슷하지만 GPU 연산과 자동미분을 지원한다.

```python
import numpy as np
import torch

array = np.array([[1, 2], [3, 4]])
tensor = torch.from_numpy(array)

print(tensor.shape)
print(tensor.dtype)
print(tensor.device)
```

| 속성 | 의미 |
| --- | --- |
| `shape` | 각 축의 크기 |
| `dtype` | 원소의 데이터 타입 |
| `device` | 텐서가 위치한 CPU 또는 GPU |

> [!WARNING]
> **Tensor 연산 조건**
> 서로 다른 장치에 있는 텐서는 직접 연산할 수 없으므로 같은 장치로 이동해야 한다. 데이터 타입이 다르면 연산에 따라 자동 형 변환이 일어날 수도 있지만, 모델 입력과 파라미터의 타입을 명시적으로 맞추는 것이 안전하다.

### 6.1 Tensor 생성과 변환

```python
torch.rand((2, 3))
torch.randn((2, 3))
torch.ones((2, 3))
torch.zeros((2, 3))
torch.empty((2, 3))
```

> [!WARNING]
> **`torch.empty()` 사용 시 주의**
> `torch.empty()`는 메모리를 초기화하지 않으므로 값이 0이나 무작위 값이라고 가정하지 않는다. 기존 텐서와 같은 모양을 만들 때는 `ones_like()`나 `rand_like()`를 사용할 수 있다.

```python
x = torch.randn(2, 3, 4)

x.reshape(2, -1)       # (2, 12)
x.permute(0, 2, 1)     # (2, 4, 3)
x.unsqueeze(1)         # (2, 1, 3, 4)
x.unsqueeze(1).squeeze(1)  # (2, 3, 4)
```

| 함수 | 동작 |
| --- | --- |
| `reshape()` | 전체 원소 수를 유지하며 모양을 바꾼다. |
| `permute()` | 축의 순서를 바꾼다. |
| `unsqueeze()` | 크기가 1인 축을 추가한다. |
| `squeeze()` | 크기가 1인 축을 제거한다. |

### 6.2 결합과 행렬 곱셈

```python
t1 = torch.tensor([[1, 2], [3, 4]])
t2 = torch.tensor([[5, 6], [7, 8]])

torch.cat((t1, t2), dim=1).shape    # (2, 4)
torch.stack((t1, t2), dim=1).shape  # (2, 2, 2)
```

`cat()`은 기존 축을 따라 이어 붙이고 `stack()`은 새 축을 만들어 쌓는다.

행렬 곱셈은 앞 행렬의 마지막 차원과 뒤 행렬의 뒤에서 두 번째 차원이 같아야 한다.

```python
torch.mm(torch.randn(2, 3), torch.randn(3, 4)).shape
# torch.Size([2, 4])

torch.bmm(torch.randn(10, 3, 5), torch.randn(10, 5, 2)).shape
# torch.Size([10, 3, 2])
```

`bmm()`의 배치 차원은 각 배치의 행렬 곱을 병렬로 구분하며 결과에도 유지된다.

### 6.3 In-place 연산과 NumPy 메모리 공유

메서드 이름이 `_`로 끝나면 원본 텐서를 직접 변경하는 In-place 연산이다.

```python
t = torch.ones(5)
n = t.numpy()
t.add_(1)

print(n)  # 같은 CPU 메모리를 공유하므로 값도 변경됨
```

> [!WARNING]
> **In-place 연산**
> In-place 연산은 메모리를 절약할 수 있지만 자동미분에 필요한 값을 덮어쓰면 오류가 생길 수 있으므로 주의한다.

## 7. FashionMNIST와 DataLoader

FashionMNIST는 28×28 크기의 흑백 의류 이미지 60,000개로 이루어진 훈련 세트와 10,000개의 테스트 세트를 제공한다. PyTorch 이미지 배치는 일반적으로 `(batch, channel, height, width)` 순서의 4차원 텐서다.

```python
from torchvision import datasets
from torchvision.transforms import ToTensor

train_dataset = datasets.FashionMNIST(
    root="fashion_data",
    train=True,
    download=True,
    transform=ToTensor(),
)

test_dataset = datasets.FashionMNIST(
    root="fashion_data",
    train=False,
    download=True,
    transform=ToTensor(),
)
```

FashionMNIST의 레이블은 총 10개다.

```python
labels = (
    "T-shirt/top", "Trouser", "Pullover", "Dress", "Coat",
    "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot",
)
```

`DataLoader`는 Dataset에서 샘플을 배치 단위로 가져오고 필요하면 순서를 섞는다.

```python
from torch.utils.data import DataLoader

train_loader = DataLoader(
    train_dataset,
    batch_size=100,
    shuffle=True,
)

images, targets = next(iter(train_loader))
print(images.shape)  # torch.Size([100, 1, 28, 28])
```

> [!NOTE]
> **배치 수 계산**
> 배치 크기가 100이면 훈련 데이터 60,000개를 모두 한 번 사용하는 데 600개 배치가 필요하다.

## 전체 흐름

```text
전처리와 모델을 Pipeline으로 결합
  ↓
ColumnTransformer로 열 유형별 전처리
  ↓
교차검증 안에서 데이터 누수 방지
  ↓
인공 뉴런을 층으로 연결해 신경망 구성
  ↓
Batch 단위로 순전파와 손실 계산
  ↓
역전파로 기울기 계산
  ↓
Optimizer로 파라미터 갱신
  ↓
Tensor와 DataLoader로 데이터를 장치·배치 단위로 처리
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Pipeline` | 전처리와 모델을 순서대로 묶어 학습·예측하는 구조 |
| `인공 뉴런` | 입력의 가중합에 활성화 함수를 적용하는 신경망 기본 단위 |
| `역전파` | 연쇄법칙으로 손실에 대한 파라미터 기울기를 계산하는 방법 |
| `Batch` | 한 번의 학습 단계에서 함께 처리하는 샘플 묶음 |
| `Optimizer` | 기울기를 이용해 모델 파라미터를 갱신하는 알고리즘 |
| `Tensor` | PyTorch의 다차원 데이터와 연산 기본 단위 |
| `DataLoader` | Dataset을 배치 단위로 순회하는 도구 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `Pipeline()` | 전처리와 모델 단계 결합 |
| `ColumnTransformer()` | 열 그룹마다 다른 전처리 적용 |
| `torch.tensor()` | Python 데이터로 Tensor 생성 |
| `reshape()` | 원소 수를 유지하며 Tensor 모양 변경 |
| `torch.mm()` | 2차원 행렬 곱셈 |
| `DataLoader()` | Dataset을 미니배치로 구성 |

### ⭐ 오늘의 핵심

- Pipeline은 전처리를 교차검증 폴드 안에서 학습시켜 데이터 누수를 방지한다.
- 딥러닝 모델도 과적합될 수 있으며 모델 복잡도와 데이터 양, 규제를 함께 관리해야 한다.
- 역전파는 기울기를 계산하고 옵티마이저는 그 기울기로 파라미터를 갱신한다.
- Sigmoid를 깊게 반복하면 기울기 소실이 발생할 수 있어 ReLU 계열 활성화 함수가 널리 사용된다.
- PyTorch에서는 Tensor의 shape, dtype, device를 확인하고 DataLoader로 배치를 구성한다.
