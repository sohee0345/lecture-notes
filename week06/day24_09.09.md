## 🔁 이전 내용 복습

### 모델 선택과 최종 평가

모델의 성능은 훈련 데이터에 얼마나 잘 맞는지만으로 판단하지 않는다. 모델과 하이퍼파라미터는 검증 데이터나 교차검증으로 선택하고, 테스트 데이터는 선택이 끝난 모델의 최종 일반화 성능을 평가하는 데 사용한다.

### 분류 평가 지표

분류 모델의 평가는 정확도뿐 아니라 혼동행렬, 정밀도, 재현율, F1 Score, ROC-AUC처럼 문제 목적에 맞는 지표를 함께 확인해야 한다. 특히 클래스 비율이 치우친 문제에서는 다수 클래스를 주로 예측하는 모델도 높은 정확도를 얻을 수 있다.

> **핵심:** 훈련·검증·테스트 데이터의 역할을 분리하고 데이터 특성에 맞는 평가 지표를 선택해야 한다.

## 1. 군집화

군집화(Clustering)는 정답 레이블 없이 데이터의 유사성을 기준으로 비슷한 샘플을 그룹으로 묶는 비지도학습이다. 정답이 주어진 상태에서 클래스를 예측하는 분류와 달리, 데이터 안에 어떤 구조가 있는지 탐색하는 데 목적이 있다.

> [!warning] 군집 번호의 의미
> 군집 번호는 단순한 식별자다. 예측 군집 `0`이 실제 클래스 `0`과 같은 의미라고 볼 수 없으며,
> 군집 번호가 바뀌어도 군집 구조 자체는 같을 수 있다.

### 1.1 K-means

K-means는 사용자가 정한 $K$개의 중심을 기준으로 가까운 샘플을 할당하고, 각 군집의 평균으로 중심을 갱신하는 과정을 반복한다.

```text
K개의 초기 중심 선택
  ↓
각 샘플을 가장 가까운 중심에 할당
  ↓
군집별 평균으로 중심 재계산
  ↓
할당이나 중심이 수렴할 때까지 반복
```

```python
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=3, random_state=42)
labels = kmeans.fit_predict(X_scaled)
centers = kmeans.cluster_centers_
```

| 설정 및 속성 | 의미 |
| --- | --- |
| `n_clusters` | 만들 군집 수를 지정한다. |
| `labels_` | 학습 데이터에 배정된 군집 번호다. |
| `cluster_centers_` | 학습된 군집 중심이다. |
| `k-means++` | 초기 중심을 서로 떨어지도록 선택해 불안정한 시작을 줄인다. |

> [!warning] K-means 사용 시 주의
> K-means는 거리와 평균을 사용하므로 특성의 단위 차이와 이상치에 민감하다.
> 일반적으로 스케일링을 먼저 적용하며, 둥글고 크기와 밀도가 비슷한 군집에서 잘 작동한다.
> 길쭉하거나 복잡한 모양, 밀도가 크게 다른 군집에는 적합하지 않을 수 있다.

### 1.2 MiniBatchKMeans

MiniBatchKMeans는 전체 데이터를 매 반복마다 사용하지 않고 작은 미니배치를 이용해 중심을 갱신한다. 대규모 데이터에서 K-means보다 빠르고 메모리 부담이 작지만 결과가 조금 덜 안정적일 수 있다.

손글씨 데이터 실습에서는 10개 군집으로 MiniBatchKMeans를 학습해 다음 점수를 얻었다.

| 지표           |    점수 |
| ------------ | ----: |
| Homogeneity  | 0.735 |
| Completeness | 0.754 |
| V-measure    | 0.745 |
| Silhouette   | 0.187 |

### 1.3 병합 군집

병합 군집(Agglomerative Clustering)은 각 샘플을 하나의 군집으로 시작한 뒤 가장 가까운 군집을 차례로 합쳐 지정된 군집 수에 도달하는 계층적 군집 방법이다.

```python
from sklearn.cluster import AgglomerativeClustering

model = AgglomerativeClustering(n_clusters=10)
labels = model.fit_predict(X_scaled)
```

> [!example] 손글씨 데이터 실습 결과
> - Homogeneity: 약 `0.858`
> - Completeness: 약 `0.879`
> - V-measure: 약 `0.868`
> - Silhouette: 약 `0.178`
>
> 외부 지표는 K-means 계열보다 높았지만 실루엣 점수는 비슷하게 낮았다. 서로 다른 지표는 군집의 서로 다른 성질을 평가하므로 하나의 점수만으로 알고리즘의 우열을 확정하지 않는다.

### 1.4 DBSCAN

DBSCAN은 일정 반경 안에 이웃이 충분히 많은 영역을 연결해 군집을 만드는 밀도 기반 알고리즘이다. 군집 수를 미리 정하지 않아도 되고 복잡한 모양의 군집과 잡음을 찾을 수 있다.

| 설정 및 레이블 | 의미 |
| --- | --- |
| `eps` | 이웃으로 인정하는 최대 거리 |
| `min_samples` | 핵심 샘플이 되기 위해 반경 안에 필요한 최소 샘플 수 |
| 레이블 `-1` | 어느 군집에도 속하지 않은 잡음 |

`eps`를 크게 하면 군집이 연결되어 합쳐지기 쉽고, `min_samples`를 크게 하면 핵심 샘플이 줄고 잡음이 늘기 쉽다. 두 값 모두 데이터의 거리와 밀도에 영향을 받으므로 스케일링이 중요하다.

> [!example] 손글씨 데이터 실습 결과
> 사용한 설정의 실루엣 점수는 약 `-0.292`였다. 음수는 많은 샘플이 자기 군집보다 다른 군집에 더 가까운 구조임을 뜻하므로 해당 설정이 데이터에 적합하지 않았음을 보여준다.

## 2. 군집 평가

군집 평가는 정답 레이블의 존재 여부에 따라 방법이 달라진다.

### 2.1 정답 레이블이 있을 때

| 지표 | 의미 |
| --- | --- |
| `Homogeneity` | 하나의 군집 안에 같은 실제 클래스가 얼마나 잘 모였는지 평가한다. |
| `Completeness` | 하나의 실제 클래스가 같은 군집 안에 얼마나 빠짐없이 모였는지 평가한다. |
| `V-measure` | Homogeneity와 Completeness의 조화평균이다. |

```python
from sklearn.metrics import (
    homogeneity_score,
    completeness_score,
    v_measure_score,
)

h = homogeneity_score(y_true, labels)
c = completeness_score(y_true, labels)
v = v_measure_score(y_true, labels)
```

> [!example] K-means 실습 결과
> - Homogeneity: 약 `0.744`
> - Completeness: 약 `0.754`
> - V-measure: 약 `0.749`

### 2.2 정답 레이블이 없을 때

실루엣 계수는 같은 군집 안의 응집도와 가장 가까운 다른 군집과의 분리도를 함께 측정한다.

$$s=\frac{b-a}{\max(a,b)}$$

| 값 | 의미 |
| --- | --- |
| $a$ | 같은 군집 샘플들과의 평균 거리 |
| $b$ | 가장 가까운 다른 군집 샘플들과의 평균 거리 |
| 1에 가까움 | 군집 내부는 가깝고 다른 군집과 잘 분리됨 |
| 0에 가까움 | 군집 경계가 겹침 |
| 음수 | 다른 군집에 더 가까울 가능성이 큼 |

```python
from sklearn.metrics import silhouette_score

score = silhouette_score(X_scaled, labels)
```

> [!warning] 실루엣 계수 해석
> 실루엣 계수는 밀집되고 분리된 군집을 선호하므로 길쭉하거나 밀도가 다른 복잡한 군집을 항상 올바르게 평가하지는 못한다. 군집의 목적과 시각화, 도메인 해석을 함께 고려해야 한다.

## 3. 일반화, 과적합과 과소적합

일반화(Generalization)는 훈련에 사용하지 않은 새로운 데이터에서도 성능을 유지하는 능력이다. 훈련 데이터는 실제 환경에서 만날 전체 데이터의 일부이므로, 훈련 성능만 높이는 것이 학습의 최종 목적은 아니다.

| 상태 | 의미 |
| --- | --- |
| `과적합` | 모델이 훈련 데이터의 규칙뿐 아니라 잡음과 우연한 패턴까지 학습해 훈련 성능은 높지만 검증 성능이 낮은 상태 |
| `과소적합` | 모델이 너무 단순하거나 학습이 부족해 훈련 데이터의 규칙도 충분히 배우지 못한 상태 |
| `적절한 적합` | 필요한 패턴을 학습하면서 새로운 데이터에서도 성능을 유지하는 상태 |

다항회귀 실습에서는 차수로 모델 복잡도를 조절했다. 1차 모델은 실제 곡선의 비선형 구조를 표현하지 못해 과소적합했고, 25차 모델은 훈련 샘플의 작은 변화까지 따라가 과적합했다.

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score

model = make_pipeline(
    PolynomialFeatures(degree=4, include_bias=False),
    LinearRegression(),
)

cv_mse = -cross_val_score(
    model,
    X_train,
    y_train,
    scoring="neg_mean_squared_error",
    cv=5,
).mean()
```

> [!example] 다항회귀 실습 결과
> 1차부터 40차까지 비교했을 때 5겹 교차검증 오차가 가장 낮은 차수는 4였고 MSE는 약 `0.01055`였다. 테스트 오차가 가장 낮은 차수는 5였지만, 테스트 결과를 보고 차수를 선택하면 테스트 데이터가 모델 선택 과정에 포함된다. 따라서 차수는 교차검증 결과로 선택하고 테스트 오차는 마지막에 한 번 확인한다.

> **핵심:** 훈련 오차는 모델이 복잡할수록 계속 낮아질 수 있으므로 검증 오차가 가장 낮은 복잡도를 선택해야 한다.

## 4. 불균형 데이터 평가

불균형 데이터는 목표 클래스의 표본 수가 한쪽으로 크게 치우친 데이터다. 예를 들어 다수 클래스와 소수 클래스의 비율이 99:1이면 모든 샘플을 다수 클래스로 예측해도 정확도 99%를 얻을 수 있다. 따라서 정확도가 높아도 중요한 소수 클래스를 전혀 탐지하지 못할 수 있다.

> [!example] 실습 데이터
> 1,000개 샘플 중 클래스 0이 985개, 클래스 1이 15개인 데이터를 만들고 `stratify=y`로 클래스 비율을 유지해 분할했다.

### 4.1 분류 지표 선택

| 지표 | 의미 |
| --- | --- |
| `Precision` | 양성으로 예측한 샘플 중 실제 양성의 비율 |
| `Recall` | 실제 양성 중 모델이 양성으로 찾아낸 비율 |
| `F1 Score` | Precision과 Recall의 조화평균 |
| `ROC-AUC` | 여러 임계값에서 TPR과 FPR의 관계를 요약한 값 |
| `PR-AUC` | 여러 임계값에서 Precision과 Recall의 관계를 요약한 값 |

```python
proba = model.predict_proba(X_test)[:, 1]

roc_auc = roc_auc_score(y_test, proba)
precision, recall, _ = precision_recall_curve(y_test, proba)
pr_auc = auc(recall, precision)
```

| 모델 | ROC-AUC | PR-AUC |
| --- | ---: | ---: |
| DummyClassifier | 0.489 | 0.007 |
| LogisticRegression | 0.869 | 0.231 |

> [!note] ROC-AUC와 PR-AUC 선택
> ROC-AUC는 음성 클래스가 매우 많을 때 좋은 값으로 보일 수 있다. PR Curve는 양성 예측의 정확성과 양성 탐지율에 집중하므로 희귀한 양성 클래스를 찾는 일이 중요한 문제에서 더 직접적인 정보를 준다. 다만 어떤 지표가 적합한지는 소수 클래스의 중요도와 FP·FN의 비용에 따라 결정한다.

## 5. 불균형 데이터 리샘플링

리샘플링은 훈련 데이터의 클래스 구성을 바꿔 모델이 소수 클래스를 더 충분히 학습하도록 돕는 방법이다.

> [!warning] 데이터 누수 방지
> 데이터 전체를 분할하기 전에 적용하면 같은 원본 샘플이나 그 정보가 훈련과 평가 데이터에 함께 들어가는 데이터 누수가 발생할 수 있으므로 훈련 세트에만 적용한다.

```python
from imblearn.over_sampling import SMOTE

X_train_resampled, y_train_resampled = SMOTE(
    random_state=42
).fit_resample(X_train, y_train)

model.fit(X_train_resampled, y_train_resampled)
y_pred = model.predict(X_test)
```

### 5.1 언더샘플링

언더샘플링은 다수 클래스 샘플을 줄인다. 학습 속도를 높일 수 있지만 중요한 정보를 잃을 수 있다.

| 방법 | 동작 방식 |
| --- | --- |
| `RandomUnderSampler` | 다수 클래스 샘플을 무작위로 제거한다. |
| `Tomek Links` | 서로 다른 클래스이면서 상호 간에 가장 가까운 샘플 쌍을 이용해 경계의 다수 클래스 샘플을 정리한다. |
| `OneSidedSelection` | Tomek Links와 Condensed Nearest Neighbour를 결합해 중복되거나 경계를 흐리는 다수 클래스 샘플을 줄인다. |
| `NeighbourhoodCleaningRule` | 이웃 관계를 이용해 분류 경계를 흐리는 샘플을 정리한다. |

### 5.2 오버샘플링

오버샘플링은 소수 클래스 샘플을 늘린다. 정보를 버리지 않지만 데이터가 커지고, 단순 복제는 과적합을 유발할 수 있다.

| 방법 | 동작 방식 |
| --- | --- |
| `RandomOverSampler` | 소수 클래스 샘플을 복원 추출해 반복한다. |
| `SMOTE` | 소수 클래스 샘플과 가까운 소수 클래스 이웃 사이를 보간해 합성 샘플을 만든다. |
| `ADASYN` | 분류하기 어려운 소수 클래스 샘플 주변에 더 많은 합성 샘플을 만든다. |

> [!warning] 리샘플링 결과 평가
> 리샘플링 후에는 정확도만 보지 않고 소수 클래스의 Precision, Recall, F1과 PR-AUC를 비교해야 한다. 소수 클래스 Recall이 높아지는 대신 다수 클래스 오탐이 늘어 Precision이 낮아질 수 있으므로 문제의 비용에 맞는 균형점을 선택한다.

## 전체 흐름

```text
정답 없는 데이터의 구조 탐색
  ↓
K-means·MiniBatchKMeans·병합 군집·DBSCAN 적용
  ↓
레이블 유무에 맞는 군집 평가 지표 선택
  ↓
훈련과 검증 성능으로 과적합·과소적합 판단
  ↓
교차검증으로 적절한 모델 복잡도 선택
  ↓
클래스 불균형과 정확도의 한계 확인
  ↓
PR-AUC 등 목적에 맞는 지표 선택
  ↓
훈련 데이터에만 리샘플링 적용 후 최종 평가
```

| --- | --- |
| `군집화` | 정답 없이 유사한 샘플끼리 그룹을 찾는 비지도학습 |
| `K-means` | 가까운 중심에 샘플을 할당하고 평균으로 중심을 갱신하는 알고리즘 |
| `DBSCAN` | 밀도가 높은 영역을 연결하고 잡음을 구분하는 군집 알고리즘 |
| `일반화` | 학습하지 않은 데이터에서도 성능을 유지하는 능력 |
| `PR-AUC` | 임계값별 Precision과 Recall의 관계를 면적으로 요약한 지표 |
| `리샘플링` | 훈련 데이터의 클래스별 표본 수를 조절하는 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `KMeans(n_clusters=k)` | $K$개 중심을 사용하는 군집 모델 생성 |
| `silhouette_score()` | 정답 없이 군집 응집도와 분리도 평가 |
| `cross_val_score()` | 여러 검증 분할로 일반화 성능 추정 |
| `precision_recall_curve()` | 임계값별 Precision과 Recall 계산 |
| `fit_resample()` | 훈련 데이터에 샘플링 기법 적용 |

### ⭐ 오늘의 핵심

- 군집 알고리즘은 군집 모양, 밀도, 데이터 크기와 스케일에 맞춰 선택한다.
- 군집 번호는 클래스 의미가 없으므로 정확도로 직접 비교하지 않는다.
- 모델 복잡도는 테스트 데이터가 아니라 검증 데이터나 교차검증으로 선택한다.
- 불균형 데이터에서는 정확도뿐 아니라 소수 클래스 중심의 지표를 확인한다.
- 리샘플링은 데이터 누수를 막기 위해 훈련 세트에만 적용한다.
