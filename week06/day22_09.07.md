## 🔁 이전 내용 복습

분류 모델의 성능을 올바르게 판단하려면 훈련 데이터와 테스트 데이터를 분리하고, 분류 문제에서는 가능하면 `stratify=y`로 클래스 비율을 유지해야 한다. 모델 선택과 하이퍼파라미터 조정은 검증 데이터나 교차검증으로 수행하고, 테스트 데이터는 최종 평가에만 사용한다.

훈련 점수가 높다는 사실만으로 과적합이라고 단정할 수는 없다. 훈련 성능과 검증·테스트 성능의 차이를 함께 확인해야 하며, 정확도뿐 아니라 혼동행렬, 정밀도, 재현율, F1 Score 등 문제 목적에 맞는 지표를 살펴야 한다.

## 1. 확률, 가능도와 최대우도추정

확률(Probability)은 분포와 모수가 정해졌을 때 어떤 데이터가 관측될 가능성을 계산한다. 반대로 가능도(Likelihood)는 관측 데이터가 주어졌을 때 어떤 모수가 그 데이터를 가장 그럴듯하게 설명하는지를 나타낸다.

최대우도추정(Maximum Likelihood Estimation, MLE)은 관측 데이터의 가능도를 가장 크게 만드는 모수를 찾는 방법이다. 로지스틱 회귀를 비롯한 많은 머신러닝 모델은 이 원리를 바탕으로 학습한다.

독립인 관측값 $x_1, \ldots, x_n$에 대한 가능도는 다음과 같이 표현할 수 있다.

$$L(\theta)=\prod_{i=1}^{n}p(x_i\mid\theta)$$

곱셈은 값이 매우 작아질 수 있으므로 실제 계산에서는 로그 가능도를 사용한다. 로그를 취하면 곱이 합으로 바뀌어 계산과 최적화가 쉬워진다.

## 2. 분류 확률을 만드는 함수

### 2.1 Sigmoid

Sigmoid 함수는 임의의 실수를 0과 1 사이의 값으로 변환한다. 이진 로지스틱 회귀에서는 이 값을 양성 클래스에 속할 확률로 해석한다.

$$\sigma(z)=\frac{1}{1+e^{-z}}$$

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

### 2.2 Softmax

Softmax 함수는 여러 클래스의 점수인 로짓(logit)을 합이 1인 확률 분포로 바꾼다. 서로 배타적인 다중분류에서 사용한다. 지수 계산이 너무 커지는 것을 막기 위해 가장 큰 값을 먼저 빼는 것이 안전하다.

```python
def softmax(x):
    shifted = x - np.max(x, axis=-1, keepdims=True)
    exp_x = np.exp(shifted)
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
```

`predict_proba()`가 반환한 값은 이미 클래스 확률이므로 여기에 Softmax를 다시 적용하지 않는다.

## 3. 선형 분류 모델

### 3.1 로지스틱 회귀

로지스틱 회귀는 입력 특성의 선형 결합을 만든 뒤 Sigmoid 또는 Softmax를 적용해 클래스 확률을 예측한다. 규제 강도를 조절하는 `C`는 규제 강도의 역수이므로 값이 작을수록 규제가 강해진다.

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(C=1.0, max_iter=1000)
model.fit(X_train, y_train)
```

유방암 데이터 실습에서는 훈련 정확도 약 `0.949`, 테스트 정확도 약 `0.947`을 얻었다. 두 점수가 비슷하다는 사실은 일반화 차이가 작다는 뜻이지만, 이것만으로 과소적합 여부를 판단할 수는 없다. 수렴 경고가 발생하면 특성 스케일링, `max_iter`, solver 설정을 점검한다.

### 3.2 LinearSVC

`LinearSVC`는 클래스 사이의 마진을 크게 만드는 선형 결정경계를 학습한다. `C`가 작을수록 규제가 강해져 경계가 단순해지고, 클수록 훈련 데이터에 더 밀접하게 맞출 수 있다. 최적의 `C`는 테스트 점수가 아니라 검증 데이터나 교차검증으로 선택한다.

## 4. 결정트리

결정트리는 특성에 대한 질문을 반복해 데이터를 나누고 최종 리프 노드에서 예측한다. 구조를 눈으로 해석하기 쉽고 전처리 부담이 비교적 적지만, 깊이가 지나치게 커지면 훈련 데이터의 세부 패턴과 잡음까지 학습할 수 있다.

주요 하이퍼파라미터는 다음과 같다.

- `max_depth`: 트리의 최대 깊이
- `min_samples_split`: 노드를 분할하기 위한 최소 샘플 수
- `min_samples_leaf`: 리프 노드가 가져야 할 최소 샘플 수
- `max_leaf_nodes`: 최대 리프 노드 수
- `criterion`: 분할 품질을 측정하는 기준(`gini`, `entropy` 등)
- `random_state`: 난수 재현을 위한 값

훈련 정확도가 1이어도 그 자체만으로 과적합은 아니다. 검증 성능이 낮거나 훈련 성능과의 차이가 클 때 트리 복잡도를 제한해야 한다.

## 5. 앙상블 학습

앙상블은 여러 모델의 예측을 결합해 한 모델보다 안정적이고 일반화 성능이 좋은 예측을 만드는 방법이다.

### 5.1 Bagging과 Random Forest

Bagging은 원본 훈련 데이터에서 복원 추출한 여러 부트스트랩 표본으로 모델을 각각 학습한 뒤 결과를 결합한다. Random Forest는 여러 결정트리를 병렬로 학습하면서 각 분할에서 일부 특성만 후보로 사용해 트리 사이의 상관관계를 낮춘다. 분류에서는 다수결 또는 확률 평균, 회귀에서는 평균으로 결과를 합친다.

유방암 데이터에서 기본 Random Forest는 훈련 정확도 `1.000`, 테스트 정확도 약 `0.958`을 기록했다. 깊이와 리프 조건을 제한한 모델은 훈련 정확도 약 `0.988`, 테스트 정확도 약 `0.958`로 테스트 성능을 유지하면서 복잡도를 낮췄다.

### 5.2 Boosting과 Gradient Boosting

Boosting은 약한 학습기를 순차적으로 추가하면서 이전 모델이 잘 맞히지 못한 부분을 보완한다. Gradient Boosting은 현재 예측의 손실을 줄이는 방향으로 다음 트리를 학습한다. `n_estimators`, `learning_rate`, 개별 트리의 깊이가 성능과 복잡도를 함께 결정한다.

실습에서는 `learning_rate=0.2`로 조정한 Gradient Boosting이 훈련 정확도 약 `0.995`, 테스트 정확도 약 `0.965`를 보였다.

### 5.3 XGBoost, LightGBM, CatBoost

- XGBoost는 규제와 병렬 계산을 강화한 Gradient Boosting 구현이다.
- LightGBM은 일반적으로 손실 감소가 큰 리프를 우선 확장하는 leaf-wise 방식을 사용해 큰 데이터에서 효율적인 학습을 목표로 한다.
- CatBoost는 범주형 특성 처리와 순서 기반 통계에 강점을 가지며, 대칭 트리를 주로 사용한다.

속도와 성능의 우열은 데이터 크기, 특성 형태, 하이퍼파라미터와 실행 환경에 따라 달라지므로 교차검증으로 비교한다.

### 5.4 Voting과 Stacking

Voting은 여러 모델의 결과를 직접 결합한다. Hard Voting은 예측 클래스의 다수결을 사용하고, Soft Voting은 클래스 확률을 평균낸다. Stacking은 여러 기본 모델의 예측을 새로운 특성으로 삼아 메타 모델이 최종 예측을 학습한다. 메타 모델을 학습할 때는 검증 폴드에서 얻은 예측을 사용해야 데이터 누수를 막을 수 있다.

실습 결과는 Soft Voting 약 `0.958`, Hard Voting 약 `0.944`, Stacking 약 `0.965`의 테스트 정확도를 보였다.

## 6. 다중분류 평가

다중분류의 `predict_proba()`는 각 행에 클래스별 확률을 반환한다. 예를 들어 숫자 이미지 분류에서 출력 크기가 `(450, 10)`이면 450개 샘플마다 숫자 0~9의 확률 10개가 있다는 뜻이다. 가장 큰 확률의 인덱스가 예측 클래스가 된다.

F1 Score를 여러 클래스에 대해 하나의 값으로 집계하는 방식은 다음과 같다.

- `micro`: 모든 클래스의 TP, FP, FN을 합한 뒤 계산한다.
- `macro`: 각 클래스의 F1을 동일한 비중으로 평균낸다.
- `weighted`: 각 클래스의 샘플 수를 가중치로 평균낸다.

숫자 분류 결정트리 실습에서는 micro F1 약 `0.669`, macro F1 약 `0.662`, weighted F1 약 `0.662`, Log Loss 약 `2.165`를 얻었다. Log Loss는 정답 클래스에 높은 확률을 줄수록 작아지며, 틀린 예측을 지나치게 확신하면 큰 벌점을 준다.

```python
df["family_size"] = df["sibsp"] + df["parch"] + 1

```

### 7.2 누수를 막는 학습 흐름

목표 변수와 특성을 정한 뒤 먼저 훈련·테스트 데이터로 분리한다. 결측치 대체 기준, 범주형 인코딩 규칙, 스케일링 계수처럼 데이터에서 학습하는 값은 훈련 데이터로만 구하고 테스트 데이터에는 그대로 적용한다. 트리 기반 모델은 일반적으로 특성 스케일에 민감하지 않으므로 LightGBM만을 위해 표준화가 필수인 것은 아니다.

### 7.3 교차검증과 최종 평가

훈련 데이터에서 `StratifiedKFold` 5겹 교차검증으로 설정을 비교했다. `learning_rate=0.03`인 실험의 평균 정확도는 약 `0.806`이었다. 선택한 LightGBM 모델의 최종 결과는 다음과 같다.

- 훈련 정확도: 약 `0.855`
- 테스트 정확도: 약 `0.813`
- 훈련·테스트 정확도 차이: 약 `0.042`
- 사망 클래스: 정밀도 `0.830`, 재현율 `0.857`, F1 `0.843`
- 생존 클래스: 정밀도 `0.787`, 재현율 `0.750`, F1 `0.768`
- 혼동행렬: `[[78, 13], [16, 48]]`

특성 중요도에서는 `fare`, `age`, `fare_per_person`, `pclass`, `family_size` 등이 상위에 나타났다. 이 값은 모델이 예측 과정에서 특성을 얼마나 사용했는지를 보여줄 뿐, 해당 특성이 생존의 원인임을 증명하지는 않는다.

### 🔑 주요 개념

| 개념 | 설명 |
| --- | --- |
| `MLE` | 관측 데이터의 가능도를 가장 크게 만드는 모수를 찾는 방법 |
| `Sigmoid` | 하나의 점수를 0~1 값으로 변환하는 함수 |
| `Softmax` | 여러 클래스 점수를 합이 1인 확률 분포로 변환하는 함수 |

### 🎯 오늘의 핵심

- 분류 모델은 가능도를 높이거나 손실을 줄이는 방향으로 파라미터를 학습한다.
- Random Forest는 대표적인 Bagging 모델이며, Gradient Boosting 계열은 약한 트리를 순차적으로 보완한다.
- 모델과 하이퍼파라미터는 교차검증으로 선택하고 테스트 데이터는 마지막 평가에만 사용한다.
- 정확도 하나만 보지 말고 클래스별 지표, 혼동행렬, 확률 기반 손실을 함께 확인한다.
- 특성 중요도는 모델의 사용 패턴이지 인과관계가 아니다.
