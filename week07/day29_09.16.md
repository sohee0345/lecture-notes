### 모델 정의와 자동미분

PyTorch 모델은 `nn.Module`을 상속해 만들고, `forward()`에서 입력이 계층을 통과하는 흐름을 정의한다. 순전파로 예측값과 손실을 구한 뒤 `loss.backward()`를 호출하면 자동미분이 각 파라미터의 기울기를 계산한다.

```python
prediction = model(features)
loss = loss_fn(prediction, targets)

optimizer.zero_grad()
loss.backward()
optimizer.step()
```

> **핵심:** 역전파는 기울기를 계산하고, 옵티마이저는 그 기울기로 파라미터를 갱신한다.

## 1. 재현 가능한 실험과 데이터 분리

신경망은 파라미터 초기화와 데이터 순서 등에 난수를 사용한다. 같은 조건의 실험을 비교하려면 Python, NumPy, PyTorch의 난수 시드를 고정한다. GPU 연산에서는 결정론적 설정을 추가해 결과 차이를 줄일 수 있지만, 모든 연산에서 완전히 같은 결과를 보장하거나 항상 가장 빠른 것은 아니다.

```python
import os
import random
import numpy as np
import torch

def reset_seeds(seed=42):
    random.seed(seed)
    os.environ["PYTHONHASHSEED"] = str(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.deterministic = True
```

데이터는 모델 파라미터를 학습하는 훈련 세트와 학습된 모델의 일반화 성능을 확인하는 테스트 세트로 나눈다. 테스트 데이터를 파라미터 학습이나 모델 선택에 반복적으로 사용하면 평가 결과가 낙관적으로 변할 수 있다.

```python
train_index = int(0.75 * len(X))

X_train, y_train = X[:train_index], y[:train_index]
X_test, y_test = X[train_index:], y[train_index:]
```

실습의 데이터 형태는 다음과 같았다.

```text
X_train, y_train: (37, 1), (37, 1)
X_test, y_test  : (13, 1), (13, 1)
```

## 2. PyTorch 선형회귀 모델

선형회귀는 입력과 목표의 관계를 가중치와 편향으로 표현한다.

$$\hat{y}=wX+b$$

`nn.Parameter`로 선언한 텐서는 모델이 학습할 파라미터로 등록된다. `model.parameters()`는 옵티마이저에 전달할 파라미터를 제공하고, `state_dict()`는 이름과 텐서의 대응 관계를 보관한다.

```python
from torch import nn

class LinearRegressionModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.weights = nn.Parameter(torch.randn(1, requires_grad=True))
        self.bias = nn.Parameter(torch.randn(1, requires_grad=True))

    def forward(self, x):
        return self.weights * x + self.bias
```

시드를 고정한 초기 파라미터는 `weight=0.3367`, `bias=0.1288`이었고, 학습 후에는 실제 데이터 생성값인 `weight=0.7`, `bias=0.3`에 가까운 `weight=0.6895`, `bias=0.2958`로 변했다.

## 3. 손실 함수와 옵티마이저

손실 함수는 예측값과 실제값의 차이를 하나의 수치로 나타낸다. 문제 종류와 모델 출력에 맞는 손실 함수를 선택해야 한다.

| 문제 | 대표 손실 함수 | 모델 출력 |
| --- | --- | --- |
| 회귀 | `nn.MSELoss`, `nn.L1Loss` | 연속값 |
| 이진분류 | `nn.BCEWithLogitsLoss` | 클래스 1에 대한 logit 하나 |
| 다중분류 | `nn.CrossEntropyLoss` | 클래스별 logits |

`BCEWithLogitsLoss`는 Sigmoid와 이진 교차 엔트로피를 수치적으로 안정적인 방식으로 결합한다. 따라서 학습 시 모델의 logit을 그대로 전달한다.

옵티마이저는 역전파로 구한 기울기를 이용해 파라미터를 실제로 변경한다. 학습률은 한 번의 갱신에서 이동하는 크기를 조절한다.

```python
loss_fn = nn.L1Loss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

## 4. 학습 루프와 평가 루프

에포크(Epoch)는 전체 훈련 데이터를 한 번 학습하는 단위다. 매 에포크에서는 학습 모드로 예측과 파라미터 갱신을 수행한 뒤 평가 모드에서 테스트 손실을 계산한다.

```python
for epoch in range(epochs):
    model.train()
    prediction = model(X_train)
    train_loss = loss_fn(prediction, y_train)

    optimizer.zero_grad()
    train_loss.backward()
    optimizer.step()

    model.eval()
    with torch.inference_mode():
        test_prediction = model(X_test)
        test_loss = loss_fn(test_prediction, y_test)
```

### 4.1 train과 eval 모드

`model.train()`과 `model.eval()`은 Dropout과 Batch Normalization처럼 모드에 따라 다르게 동작하는 계층의 상태를 전환한다. 평가 모드만으로 기울기 추적이 꺼지는 것은 아니므로, 평가와 추론에서는 `torch.inference_mode()`를 함께 사용한다.

### 4.2 손실 곡선 해석

훈련 손실과 테스트 손실을 함께 기록하면 학습 상태를 판단할 수 있다.

- 두 손실이 모두 높게 유지됨 → 과소적합 가능성
- 훈련 손실은 감소하지만 테스트 손실이 증가함 → 과적합 가능성
- 두 손실이 함께 감소함 → 훈련 데이터의 패턴이 테스트 데이터에도 적용되는 중

GPU 텐서를 NumPy 배열로 기록할 때는 계산 그래프에서 분리하고 CPU로 이동해야 한다.

```python
loss_value = train_loss.detach().cpu().numpy()
```

## 5. 모델 저장과 불러오기

PyTorch에서는 모델 객체 전체보다 학습된 파라미터를 담은 `state_dict()`를 저장하는 방식을 주로 사용한다.

```python
from pathlib import Path

model_path = Path("models")
model_path.mkdir(parents=True, exist_ok=True)
model_save_path = model_path / "my_first_model.pth"

torch.save(model.state_dict(), model_save_path)
```

불러올 때는 같은 구조의 모델을 먼저 생성한 뒤 저장된 상태를 적용한다.

```python
loaded_model = LinearRegressionModel()
state = torch.load(model_save_path)
loaded_model.load_state_dict(state)

loaded_model.eval()
with torch.inference_mode():
    predictions = loaded_model(X_test)
```

> **핵심:** `state_dict()`는 파라미터를 저장하므로, 복원할 때 동일한 모델 구조가 필요하다.

## 6. 이진분류 신경망

이진분류는 두 클래스 중 하나를 예측한다. 마지막 선형 계층은 샘플마다 logit 하나를 출력하며, Sigmoid를 적용하면 클래스 1일 확률로 해석할 수 있다.

```text
logit → Sigmoid → 0~1 확률 → 임계값 0.5 → 예측 클래스 0 또는 1
```

```python
logits = model(features).squeeze(dim=1)
loss = nn.BCEWithLogitsLoss()(logits, targets)

probabilities = torch.sigmoid(logits)
predictions = (probabilities >= 0.5).float()
```

모델 출력이 `(batch_size, 1)`이고 target이 `(batch_size,)`라면 `squeeze(dim=1)`로 출력 형태를 맞춘다. 축을 지정하면 배치 크기가 1일 때 배치 차원까지 사라지는 일을 피할 수 있다.

## 7. 활성화 함수와 비선형 결정 경계

원형으로 배치된 데이터처럼 직선 하나로 구분할 수 없는 분포에는 비선형 결정 경계가 필요하다. 선형 계층만 여러 개 연결해도 전체 변환은 하나의 선형 변환과 같으므로 표현력이 본질적으로 늘어나지 않는다.

```python
class BinaryClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(2, 30),
            nn.ReLU(),
            nn.Linear(30, 60),
            nn.ReLU(),
            nn.Linear(60, 1),
        )

    def forward(self, features):
        return self.layers(features)
```

실습에서 선형 계층만 사용한 V0와 V1은 테스트 정확도가 각각 `48%`, `46%`였다. ReLU를 추가한 V2는 비선형 결정 경계를 학습하여 테스트 정확도 `100%`를 기록했다. 단순히 계층과 파라미터 수를 늘리는 것보다 데이터 분포에 맞는 비선형성을 추가하는 것이 중요하다는 결과다.

## 전체 흐름

```text
난수 시드 고정과 데이터 분리
  ↓
nn.Module로 모델 정의
  ↓
문제에 맞는 손실 함수와 옵티마이저 선택
  ↓
train 모드에서 순전파·손실·역전파·갱신
  ↓
eval + inference_mode에서 일반화 성능 평가
  ↓
손실 곡선과 결정 경계로 문제 진단
  ↓
필요한 비선형성 추가 후 재실험
  ↓
state_dict 저장과 복원
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `nn.Parameter` | 모델이 학습할 텐서로 등록되는 파라미터 |
| 손실 함수 | 실제값과 예측값의 차이를 수치화하는 함수 |
| 에포크 | 전체 훈련 데이터를 한 번 학습하는 단위 |
| `state_dict` | 모델 파라미터 이름과 텐서의 매핑 |
| logit | Sigmoid 적용 전의 이진분류 원시 출력 |
| 비선형성 | 직선으로 표현할 수 없는 관계를 학습하게 하는 성질 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `model.train()` | 모델을 학습 모드로 전환 |
| `model.eval()` | 모델을 평가 모드로 전환 |
| `torch.inference_mode()` | 추론 중 Autograd 추적 비활성화 |
| `nn.BCEWithLogitsLoss()` | Sigmoid가 결합된 이진분류 손실 |
| `torch.save(model.state_dict(), path)` | 학습된 파라미터 저장 |
| `model.load_state_dict(state)` | 저장된 파라미터 적용 |

### ⭐ 오늘의 핵심

- 학습 루프는 순전파, 손실 계산, 기울기 초기화, 역전파, 파라미터 갱신 순서로 진행한다.
- 평가에서는 `eval()`과 `inference_mode()`를 함께 사용한다.
- 이진분류 학습에는 logits를 `BCEWithLogitsLoss`에 직접 전달한다.
- 선형 계층만 깊게 쌓아도 비선형 관계는 학습할 수 없으므로 활성화 함수가 필요하다.
- 모델 파라미터는 `state_dict()`로 저장하고 같은 구조의 모델에 복원한다.
