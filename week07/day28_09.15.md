### Min-Max Scaling과 이미지 입력

Min-Max Scaling은 특성의 최솟값을 0, 최댓값을 1에 대응하도록 값을 변환한다.

$$x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}}$$

이미지 배치는 일반적으로 `(batch, channel, height, width)` 형태다. 완전연결층인 `nn.Linear`에 이미지를 전달하려면 배치 차원은 유지하면서 나머지 축을 하나의 특성 축으로 펼쳐야 한다.

```text
(10, 1, 28, 28) → (10, 784)
```

> **핵심:** 전처리된 입력의 크기는 모델 첫 계층의 입력 크기와 일치해야 한다.

## 1. 신경망의 기본 계산

인공 뉴런은 여러 입력에 가중치를 곱해 더하고 편향을 더한 뒤 활성화 함수를 적용한다.

$$z=b+\sum_{i=1}^{m}w_i x_i$$

$$y=f(z)$$

- $x_i$ → 입력 특성
- $w_i$ → 각 입력이 출력에 미치는 영향의 크기
- $b$ → 활성화 기준을 이동시키는 값
- $f$ → 비선형성을 추가하는 활성화 함수

가중치와 편향은 손실을 줄이는 방향으로 학습되는 모델 파라미터다. 여러 계층을 연결하면 앞 계층이 만든 표현을 다음 계층이 다시 조합하면서 복잡한 관계를 학습할 수 있다.

### 1.1 Linear와 ReLU

`nn.Linear(in_features, out_features)`는 입력에 선형 변환을 적용한다. 가중치의 형태는 `(out_features, in_features)`, 편향의 형태는 `(out_features,)`다.

ReLU는 음수를 0으로 만들고 양수는 그대로 전달한다.

$$\operatorname{ReLU}(x)=\max(0,x)$$

ReLU는 값만 변환하므로 텐서의 shape은 바뀌지 않는다. 선형 계층 사이에 ReLU를 넣으면 여러 선형 계층을 하나로 합칠 수 없는 비선형 모델이 된다.

```python
layer = nn.Linear(in_features=784, out_features=20)
hidden = layer(flat_image)  # (batch, 20)
hidden = nn.ReLU()(hidden)  # shape 유지
```

> **핵심:** 선형 계층이 표현의 크기를 바꾸고, 활성화 함수가 비선형성을 추가한다.

## 2. nn.Module로 모델 정의하기

PyTorch 모델은 `nn.Module`을 상속해 정의한다. `__init__()`에서는 사용할 계층을 등록하고, `forward()`에서는 입력이 계층을 통과하는 순서를 작성한다. 모델 객체를 함수처럼 호출하면 PyTorch가 내부적으로 `forward()`를 실행한다.

```python
import torch
from torch import nn

class NeuralNetwork(nn.Module):
    def __init__(self, feature_size=28 * 28, hidden_size=512, target_size=10):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(feature_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, target_size),
        )

    def forward(self, features):
        features = self.flatten(features)
        return self.layers(features)
```

첫 계층의 `in_features`는 펼친 입력의 특성 수와 같아야 한다. 마지막 계층의 `out_features`는 예측할 클래스 수와 같아야 하며, 인접한 두 선형 계층에서는 앞 계층의 출력 크기와 뒤 계층의 입력 크기가 일치해야 한다.

### 2.1 Flatten

`nn.Flatten()`은 기본적으로 배치 차원을 유지하고 나머지 축을 하나로 합친다.

```python
flatten = nn.Flatten()
input_image = torch.rand(3, 28, 28)
flat_image = flatten(input_image)

print(flat_image.shape)
```

실행 결과:

```text
torch.Size([3, 784])
```

### 2.2 Sequential과 모델 모듈화

`nn.Sequential`은 등록된 계층을 앞에서부터 차례대로 실행한다. 단순한 순차 구조를 간결하게 표현할 때 적합하다. 전처리 부분과 예측 부분처럼 기능을 별도의 `nn.Module` 클래스로 나눈 뒤 상위 모델에서 다시 조합할 수도 있다.

```text
입력 이미지
  ↓
Flatten 모듈
  ↓
Linear·ReLU 모듈
  ↓
클래스별 logits
```

복잡한 분기, 여러 입력 또는 잔차 연결처럼 실행 흐름을 직접 제어해야 할 때는 `forward()`에 각 계층 호출을 명시한다.

## 3. 다중분류 출력 해석

다중분류 모델의 마지막 선형 계층은 클래스마다 하나의 원시 점수인 `logit`을 출력한다. 클래스가 10개라면 출력 shape은 `(batch_size, 10)`이다.

학습할 때 `nn.CrossEntropyLoss`를 사용한다면 모델은 Softmax나 ReLU를 적용하지 않은 logits를 반환해야 한다. 손실함수가 내부적으로 확률 변환에 필요한 계산을 안정적으로 처리한다.

예측 결과를 사람이 확률로 확인할 때는 Softmax를 적용하고 가장 큰 값의 인덱스를 고른다.

```python
logits = model(features)
pred_probab = nn.Softmax(dim=1)(logits)
y_pred = pred_probab.argmax(dim=1)
```

- `Softmax(dim=1)` → 각 샘플의 클래스 점수들을 합이 1인 확률로 변환한다.
- `argmax(dim=1)` → 각 샘플에서 가장 큰 클래스 점수의 인덱스를 반환한다.

## 4. CPU와 GPU 장치 관리

모델과 입력 텐서는 같은 장치에 있어야 연산할 수 있다. CUDA를 사용할 수 있으면 GPU를, 그렇지 않으면 CPU를 선택한다.

```python
device = "cuda" if torch.cuda.is_available() else "cpu"

model = NeuralNetwork().to(device)
features = torch.randn(10, 1, 28, 28).to(device)
logits = model(features)
```

실습 환경에서는 다음과 같이 CPU가 선택되었다.

```text
Using cpu device
```

`.to(device)`는 반환된 객체를 사용해야 한다. 모델은 보통 내부 파라미터가 해당 장치로 이동하지만, 텐서의 `.to()`는 이동된 새 텐서를 반환하므로 `features = features.to(device)`처럼 저장한다.

## 5. 자동미분과 계산 그래프

PyTorch의 자동미분(Autograd)은 순전파 중 수행된 연산을 계산 그래프로 기록하고, 역전파에서 연쇄법칙을 이용해 손실에 대한 각 파라미터의 기울기를 계산한다.

```text
입력과 파라미터
  ↓ 순전파
예측값
  ↓
손실 계산
  ↓ loss.backward()
각 파라미터의 .grad에 기울기 저장
```

```python
x = torch.ones(5)
y = torch.zeros(3)
w = torch.randn(5, 3, requires_grad=True)
b = torch.randn(3, requires_grad=True)

z = torch.matmul(x, w) + b
loss = torch.nn.functional.binary_cross_entropy_with_logits(z, y)
loss.backward()

print(w.grad)
print(b.grad)
```

`requires_grad=True`인 텐서가 참여한 연산은 기본적으로 추적된다. 결과 텐서의 `grad_fn`을 확인하면 어떤 연산을 통해 만들어졌는지 알 수 있다. `loss.backward()`는 기울기를 계산할 뿐이며, 실제 파라미터 갱신은 옵티마이저가 수행한다.

### 5.1 기울기 추적 중단

검증과 추론에서는 파라미터를 갱신하지 않으므로 계산 그래프가 필요 없다. `torch.no_grad()`를 사용하면 블록 안의 연산을 추적하지 않아 메모리와 계산량을 줄일 수 있다.

```python
with torch.no_grad():
    logits = model(features)
```

`detach()`는 특정 텐서를 기존 계산 그래프에서 분리한 새 텐서로 만든다.

```python
z_detached = z.detach()
print(z_detached.requires_grad)
```

실행 결과:

```text
False
```

`no_grad()`는 일정 구간의 모든 연산 추적을 끄고, `detach()`는 특정 텐서 하나를 그래프에서 분리한다.

## 전체 흐름

```text
입력 shape과 실행 장치 확인
  ↓
Flatten으로 배치별 특성 벡터 생성
  ↓
Linear와 ReLU로 은닉 표현 계산
  ↓
마지막 Linear에서 클래스별 logits 출력
  ↓
예측값과 정답으로 손실 계산
  ↓
Autograd가 계산 그래프를 따라 기울기 계산
  ↓
옵티마이저가 파라미터 갱신
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `nn.Module` | PyTorch 모델과 계층의 기본 클래스 |
| `nn.Flatten` | 배치 차원을 유지하며 나머지 축을 펼치는 계층 |
| `nn.Linear` | 가중치와 편향으로 선형 변환하는 계층 |
| `nn.Sequential` | 여러 계층을 등록된 순서대로 실행하는 컨테이너 |
| `logits` | 출력층이 만든 클래스별 원시 점수 |
| Autograd | 계산 그래프를 이용해 기울기를 자동 계산하는 기능 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `class Model(nn.Module)` | 사용자 정의 모델 선언 |
| `super().__init__()` | 부모 `nn.Module` 초기화 |
| `model.to(device)` | 모델을 CPU 또는 GPU로 이동 |
| `loss.backward()` | 계산 그래프를 따라 기울기 계산 |
| `torch.no_grad()` | 블록 안의 기울기 추적 중단 |
| `tensor.detach()` | 텐서를 기존 계산 그래프에서 분리 |

### ⭐ 오늘의 핵심

- `__init__()`은 계층을 등록하고 `forward()`는 입력이 흐르는 순서를 정의한다.
- 인접한 계층의 출력 크기와 입력 크기는 서로 일치해야 한다.
- 다중분류의 마지막 계층은 클래스 수만큼의 logits를 출력한다.
- 자동미분은 기울기를 계산하며 실제 파라미터 변경은 옵티마이저가 담당한다.
- 모델과 입력 텐서는 같은 장치에 있어야 한다.
