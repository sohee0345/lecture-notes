### Dataset, DataLoader와 학습 루프

`Dataset`은 인덱스별 `(feature, target)`을 반환하고, `DataLoader`는 여러 샘플을 배치로 묶어 학습 루프에 공급한다. 각 배치에서는 순전파, 손실 계산, 기울기 초기화, 역전파, 파라미터 갱신을 반복한다.

```python
for features, targets in train_dataloader:
    predictions = model(features)
    loss = loss_fn(predictions, targets)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

> **핵심:** 한 에포크는 DataLoader의 모든 배치를 한 번씩 학습한 상태다.

## 1. 이미지 데이터를 미니배치로 구성하기

scikit-learn의 손글씨 데이터는 `(샘플 수, 64)` 형태의 NumPy 배열이다. 이미지 모델에 넣기 위해 한 샘플을 `(channel, height, width)`인 `(1, 8, 8)`로 바꾼다.

### 1.1 사용자 정의 Dataset

숫자 5인지 여부를 예측하도록 target을 0과 1로 변환하고, 계층 비율을 유지하는 `stratify` 옵션으로 훈련·평가 데이터를 분리했다.

```python
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

digits = load_digits()
features = digits.data
targets = (digits.target == 5).astype(int)

x_train, x_test, y_train, y_test = train_test_split(
    features,
    targets,
    stratify=targets,
)
```

```python
import torch
from torch.utils.data import Dataset

class DigitDataset(Dataset):
    def __init__(self, features, targets):
        self.features = features
        self.targets = targets

    def __len__(self):
        return self.features.shape[0]

    def __getitem__(self, index):
        feature = torch.tensor(self.features[index], dtype=torch.float32)
        target = torch.tensor(self.targets[index], dtype=torch.float32)
        return feature.reshape(1, 8, 8), target
```

실습에서는 훈련 샘플 `1,347개`, 평가 샘플 `450개`가 만들어졌다.

### 1.2 DataLoader의 배치 형태

```python
from torch.utils.data import DataLoader

train_dataloader = DataLoader(
    train_dataset,
    batch_size=100,
    shuffle=True,
)
test_dataloader = DataLoader(
    test_dataset,
    batch_size=100,
    shuffle=False,
)
```

첫 훈련 배치의 형태는 다음과 같았다.

```text
features: torch.Size([100, 1, 8, 8])
targets : torch.Size([100])
```

훈련 데이터는 에포크마다 순서를 섞는 것이 일반적이지만, 평가 데이터는 결과 재현과 샘플 순서 확인을 위해 보통 섞지 않는다.

## 2. 미니배치 학습과 평균 손실

데이터 전체를 한 번에 모델에 넣는 대신 배치마다 파라미터를 갱신한다. 한 에포크의 손실은 모든 배치 손실을 누적한 뒤 배치 개수로 나누어 평균을 구한다.

```python
model.train()
train_loss = 0.0

for features, targets in train_dataloader:
    features = features.to(device)
    targets = targets.to(device)

    logits = model(features).squeeze(dim=1)
    loss = loss_fn(logits, targets)
    train_loss += loss.detach()

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

train_loss /= len(train_dataloader)
```

모델 출력과 target은 같은 장치에 두어 손실을 계산한다. 손실 기록을 NumPy로 바꿀 때는 `loss.detach().cpu().numpy()`처럼 계산 그래프에서 분리한 뒤 CPU로 이동한다.

평가에서는 파라미터를 갱신하지 않는다.

```python
model.eval()
test_loss = 0.0

with torch.inference_mode():
    for features, targets in test_dataloader:
        features = features.to(device)
        targets = targets.to(device)

        logits = model(features).squeeze(dim=1)
        test_loss += loss_fn(logits, targets)

test_loss /= len(test_dataloader)
```

## 3. 조기 종료

조기 종료(Early Stopping)는 검증 손실이 더 이상 개선되지 않을 때 학습을 중단하는 방법이다. 지나친 학습으로 과적합이 심해지는 것을 줄이고 불필요한 연산을 절약할 수 있다.

- `best_loss` → 지금까지 가장 낮은 검증 손실
- `patience` → 개선 없이 기다릴 최대 횟수
- `counter` → 연속으로 개선되지 않은 횟수

```text
검증 손실 개선
  → best_loss 갱신
  → counter 초기화
  → 현재 모델 저장

검증 손실 미개선
  → counter 증가
  → patience에 도달하면 학습 종료
```

조기 종료와 모델 선택에는 검증 세트를 사용하고, 테스트 세트는 최종 모델의 일반화 성능을 한 번 평가하는 용도로 남겨 두어야 한다. 학습 종료 후에는 마지막 에포크의 모델이 아니라 검증 손실이 가장 낮았을 때 저장한 모델을 불러온다.

```python
if validation_loss < best_loss:
    best_loss = validation_loss
    counter = 0
    torch.save(model.state_dict(), "best_model.pt")
else:
    counter += 1
    if counter >= patience:
        break
```

## 4. 이진분류 모델 평가

이진분류 모델은 logit 하나를 출력한다. 학습에는 `BCEWithLogitsLoss`를 사용하고, 평가할 때 Sigmoid와 임계값을 적용해 0 또는 1을 결정한다.

```python
logits = best_model(features.to(device)).squeeze(dim=1)
probabilities = torch.sigmoid(logits)
predictions = (probabilities >= 0.5).long().cpu()
```

실습에서 저장된 최적 모델의 정확도는 `99.4%`였다. 정확도는 전체 샘플 중 예측 클래스와 실제 클래스가 같은 샘플의 비율이다.

$$\text{Accuracy}=\frac{\text{correct predictions}}{\text{all predictions}}\times100$$

## 5. FashionMNIST 다중분류

FashionMNIST는 28×28 크기의 흑백 의류 이미지와 10개 클래스의 target으로 구성된다. 훈련 데이터에는 `train=True`, 테스트 데이터에는 `train=False`를 사용해야 서로 다른 데이터가 로드된다.

```python
from torchvision import datasets
from torchvision.transforms import ToTensor

train_dataset = datasets.FashionMNIST(
    root="fashion_data",
    train=True,
    download=True,
    transform=ToTensor(),
)
test_dataset = datasets.FashionMNIST(
    root="fashion_data",
    train=False,
    download=True,
    transform=ToTensor(),
)
```

이미지 한 장은 `(1, 28, 28)`, 배치 크기가 100인 입력은 `(100, 1, 28, 28)` 형태다. 모델은 이미지를 펼친 뒤 마지막 계층에서 클래스 10개의 logits를 출력한다.

```python
from torch import nn

class MultiClassModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.ReLU(),
            nn.Linear(512, 1024),
            nn.ReLU(),
            nn.Linear(1024, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
        )

    def forward(self, features):
        return self.layers(self.flatten(features))
```

### 5.1 CrossEntropyLoss와 예측 클래스

`CrossEntropyLoss`는 클래스별 logits와 정수 클래스 target을 받는다. 학습할 때 Softmax를 먼저 적용하지 않는다.

```python
loss_fn = nn.CrossEntropyLoss()

logits = model(features)
loss = loss_fn(logits, targets)
```

확률이 필요하면 평가 시 Softmax를 적용한다. 최종 클래스만 필요하면 logits에 바로 `argmax`를 적용해도 결과가 같다.

```python
probabilities = torch.softmax(logits, dim=1)
predictions = torch.argmax(probabilities, dim=1)

# 클래스 선택만 필요할 때
predictions = torch.argmax(logits, dim=1)
```

## 6. 혼동행렬로 클래스별 성능 확인하기

정확도는 전체 성능을 하나의 값으로 보여 주지만 어떤 클래스를 서로 혼동했는지는 알려 주지 않는다. 혼동행렬은 행에 실제 클래스, 열에 예측 클래스를 배치해 클래스별 예측 관계를 나타낸다.

```python
from sklearn.metrics import confusion_matrix

confusion = confusion_matrix(
    true_labels,
    predicted_labels,
    normalize="true",
)
```

`normalize="true"`는 각 실제 클래스의 행 합이 1이 되도록 정규화한다. 대각선은 올바른 분류 비율이고, 대각선 밖의 값은 다른 클래스로 잘못 분류한 비율이다.

```python
import seaborn as sns

sns.heatmap(
    confusion,
    annot=True,
    cmap="coolwarm",
    linewidths=0.5,
    xticklabels=train_dataset.classes,
    yticklabels=train_dataset.classes,
)
```

## 전체 흐름

```text
Dataset에서 이미지와 target 반환
  ↓
DataLoader로 미니배치 구성
  ↓
배치마다 순전파·손실·역전파·파라미터 갱신
  ↓
배치 손실을 평균 내어 에포크 손실 계산
  ↓
검증 손실로 조기 종료와 최적 모델 저장
  ↓
최적 모델을 불러와 테스트 데이터 평가
  ↓
정확도와 혼동행렬로 전체·클래스별 성능 확인
```

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `DataLoader(..., batch_size=100)` | 샘플을 100개씩 배치로 구성 |
| `loss.detach()` | 손실을 계산 그래프에서 분리 |

| `confusion_matrix(..., normalize="true")` | 실제 클래스별 비율 혼동행렬 계산 |

### ⭐ 오늘의 핵심

- 미니배치마다 파라미터를 갱신하고 모든 배치 손실의 평균으로 에포크 손실을 구한다.
- 조기 종료는 검증 손실을 감시하며 가장 낮은 시점의 모델을 보존한다.
- 이진분류는 logit 하나와 `BCEWithLogitsLoss`, 다중분류는 클래스별 logits와 `CrossEntropyLoss`를 사용한다.
- 테스트 데이터는 조기 종료 기준이 아니라 최종 일반화 성능 평가에 사용한다.
- 정확도와 혼동행렬을 함께 확인하면 전체 성능과 클래스별 오류를 모두 파악할 수 있다.
