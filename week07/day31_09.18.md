### 이미지 텐서와 ImageFolder

컬러 이미지 한 장은 PyTorch에서 일반적으로 `(channel, height, width)` 형태의 텐서로 표현된다. 여러 이미지를 배치로 묶으려면 모든 이미지의 채널 수, 높이와 너비가 같아야 한다.

```text
이미지 한 장: (C, H, W)
이미지 배치 : (N, C, H, W)
```

`ImageFolder`는 클래스별 폴더에서 이미지와 target을 만들고, 지정한 `transform`을 이미지를 읽을 때마다 적용한다. `DataLoader`는 변환된 이미지를 배치로 묶어 모델에 전달한다.

> **핵심:** 전처리 결과의 크기와 채널 수가 같아야 여러 이미지를 하나의 배치로 구성할 수 있다.

## 1. 이미지의 배열 구조

컴퓨터는 이미지를 픽셀값으로 이루어진 숫자 배열로 처리한다. 흑백 이미지는 밝기를 나타내는 한 채널을 사용하고, 컬러 이미지는 보통 Red, Green, Blue의 세 채널을 사용한다.

PIL 이미지를 NumPy 배열로 변환하면 축 순서는 `(height, width, channel)`이다.

```python
from PIL import Image
import numpy as np

image = Image.open("deer.jpg")
array = np.array(image)

print(image.getbands())
print(array.shape)
```

JPEG 실습 이미지는 `RGB`, PNG 로고는 투명도인 Alpha 채널이 포함된 `RGBA` 형식이었다.

```text
JPEG 채널: ('R', 'G', 'B')
PNG 채널 : ('R', 'G', 'B', 'A')
```

JPEG는 손실 압축으로 파일 크기를 줄이고, PNG는 투명도 채널을 저장할 수 있다. 이미지의 채널과 자료형을 확인한 뒤 필요한 형식으로 변환해야 한다.

## 2. torchvision.transforms의 기본 변환

`torchvision.transforms`는 이미지 크기와 색상, 방향 등을 변환하는 기능을 제공한다.

| 변환 | 역할 |
| --- | --- |
| `Pad` | 이미지 가장자리에 여백 추가 |
| `Resize` | 높이와 너비 변경 |
| `CenterCrop` | 중앙 영역 자르기 |
| `RandomCrop` | 무작위 위치 자르기 |
| `Grayscale` | 흑백 이미지로 변환 |
| `ColorJitter` | 밝기·대비·색상 변화 |
| `GaussianBlur` | 주변 픽셀을 부드럽게 섞어 흐림 처리 |
| `RandomRotation` | 무작위 각도로 회전 |
| `RandomAffine` | 회전·이동·크기 변화 적용 |

원본 PIL 이미지의 크기는 `(width, height)` 순서다. 실습에서는 `(589, 471)` 이미지에 50픽셀 패딩을 적용하여 `(689, 571)`이 되었다.

```python
import torchvision.transforms as T

padded = T.Pad(padding=50)(image)
resized = T.Resize((200, 200))(image)
center = T.CenterCrop(200)(image)
gray = T.Grayscale()(image)
```

`Resize`에 정수 하나를 전달하면 짧은 변을 기준으로 비율을 유지하고, `(height, width)`를 전달하면 지정한 크기로 맞춘다.

## 3. 데이터 증강

데이터 증강은 원본 이미지를 무작위로 회전하거나 자르고, 색상과 크기를 바꾸어 새로운 학습 샘플처럼 사용하는 방법이다. 모델이 특정 위치와 방향을 외우는 대신 객체의 공통 특징을 학습하도록 돕는다.

```python
train_transform = T.Compose([
    T.RandAugment(),
    T.RandomCrop((200, 200)),
    T.ToTensor(),
])

test_transform = T.Compose([
    T.Resize((200, 200)),
    T.ToTensor(),
])
```

학습 데이터에는 매번 결과가 달라지는 무작위 변환을 적용할 수 있다. 검증·테스트 데이터에는 일정한 조건에서 성능을 비교할 수 있도록 `Resize`, `ToTensor`, `Normalize` 같은 결정적인 변환만 적용한다.

> [!WARNING]
> 분류 문제에서는 객체 의미를 바꾸는 변환을 사용하면 안 된다. 변환의 종류와 강도는 실제 데이터에서 가능한 변화인지 확인해 선택한다.

## 4. Compose와 변환 순서

`T.Compose`는 여러 변환을 작성한 순서대로 실행한다. 각 변환이 요구하는 입력 자료형을 확인해야 한다.

```text
PIL 이미지
  ↓ 크롭·회전·색상 변형
PIL 이미지
  ↓ ToTensor
float32 텐서, 픽셀 범위 0~1
  ↓ Normalize
정규화된 텐서
```

```python
train_transform = T.Compose([
    T.RandAugment(),
    T.RandomCrop((200, 200)),
    T.ToTensor(),
    T.Normalize(mean=channel_mean, std=channel_std),
])
```

`Normalize`는 텐서를 입력으로 받으므로 `ToTensor()` 뒤에 둔다. `RandAugment`처럼 정수형 PIL 이미지에 적용하는 변환은 `ToTensor()`보다 먼저 둔다.

## 5. ImageFolder와 DataLoader에 전처리 적용하기

피자·스테이크·스시 데이터는 훈련 이미지 225개와 테스트 이미지 75개로 구성되었다. 학습과 평가에 서로 다른 transform을 연결하되 최종 출력은 모두 `(3, 200, 200)`으로 맞춘다.

```python
from torchvision import datasets

train_data = datasets.ImageFolder(
    root=train_path,
    transform=train_transform,
)
test_data = datasets.ImageFolder(
    root=test_path,
    transform=test_transform,
)
```

```python
from torch.utils.data import DataLoader

train_dataloader = DataLoader(
    train_data,
    batch_size=10,
    shuffle=True,
)
test_dataloader = DataLoader(
    test_data,
    batch_size=10,
    shuffle=False,
)
```

실습의 첫 훈련 배치는 다음 형태였다.

```text
features: torch.Size([10, 3, 200, 200])
targets : torch.Size([10])
```

## 6. 이미지 채널별 정규화

이미지 정규화는 각 채널에서 평균을 빼고 표준편차로 나누어 픽셀값의 분포를 조정한다.

$$x'_c=\frac{x_c-\mu_c}{\sigma_c}$$

평균과 표준편차는 학습 데이터만 사용해 계산한다. 검증·테스트 데이터까지 통계 계산에 포함하면 평가 데이터의 정보가 학습 과정에 들어가는 데이터 누수가 생긴다.

```python
import torch
from PIL import Image
import torchvision.transforms as T

to_tensor = T.Compose([
    T.Resize((200, 200)),
    T.ToTensor(),
])
images = torch.stack([
    to_tensor(Image.open(path).convert("RGB"))
    for path in train_path.glob("*/*.jpg")
])

channel_mean = images.mean(dim=(0, 2, 3))
channel_std = images.std(dim=(0, 2, 3))
```

`ToTensor()`가 픽셀값을 `0~1` 범위로 바꾸므로 `Normalize`에 전달할 평균과 표준편차도 같은 스케일에서 계산해야 한다. 학습 데이터에서 구한 동일한 통계값을 훈련·검증·테스트 전부에 적용한다.

```python
normalize = T.Normalize(
    mean=channel_mean.tolist(),
    std=channel_std.tolist(),
)
```

## 7. PIL과 OpenCV 이미지 처리

### 7.1 PIL

PIL은 이미지 파일을 열고 저장하며 색상 모드, 회전, 흑백 변환, 대비 조정 등을 처리할 수 있다.

```python
from PIL import Image, ImageEnhance

image = Image.open("deer.jpg")
gray = image.convert("L")
rotated = image.rotate(180)
high_contrast = ImageEnhance.Contrast(image).enhance(2)
```

NumPy 배열 슬라이싱으로 특정 영역을 선택하고 같은 크기의 다른 이미지 픽셀을 대입할 수도 있다.

```python
base = np.array(image).copy()
logo_rgb = np.array(logo)[:, :, :3]
height, width = logo_rgb.shape[:2]
base[:height, :width] = logo_rgb
```

### 7.2 OpenCV

OpenCV의 `cv2.imread()`는 컬러 이미지를 기본적으로 BGR 순서로 읽는다. Matplotlib은 RGB 순서를 사용하므로 표시 전에 채널 순서를 바꾼다.

```python
import cv2
import matplotlib.pyplot as plt

image_bgr = cv2.imread("deer.jpg")
image_rgb = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2RGB)

plt.imshow(image_rgb)
plt.show()
```

OpenCV의 `resize` 인자는 `(width, height)` 순서다.

```python
resized = cv2.resize(image_bgr, (300, 300))
```

`VideoCapture`를 사용하면 동영상의 프레임 수를 확인하거나 특정 프레임으로 이동해 이미지를 읽을 수 있다.

## 8. 형태학적 연산과 엣지 검출

침식(Erosion)은 객체 영역을 줄여 굵은 선을 가늘게 만들거나 작은 전경 노이즈를 제거한다. 팽창(Dilation)은 객체 영역을 넓혀 가는 선을 두껍게 만들거나 끊어진 부분을 연결한다.

가우시안 블러는 정규분포 형태의 가중치를 적용해 주변 픽셀을 부드럽게 섞는다. 작은 잡음과 급격한 픽셀 변화를 줄일 수 있지만 이미지가 흐려진다.

엣지 검출은 밝기나 색상값이 크게 변하는 경계를 찾는다. 객체의 윤곽과 형태를 강조하므로 제품 표면의 찍힘이나 깨짐처럼 경계 이상을 찾는 검사에 활용할 수 있다.

```text
원본 이미지
  ↓ 필요하면 블러로 잡음 완화
픽셀 변화 계산
  ↓
객체 경계인 엣지 추출
```

## 9. CNN이 필요한 이유

완전연결층은 이미지를 하나의 벡터로 펼치므로 픽셀 사이의 공간적 위치 관계를 직접 유지하기 어렵다. 이미지에서는 특정 픽셀 하나보다 주변 픽셀이 함께 만드는 모양과 배치가 중요하다.

CNN(Convolutional Neural Network)은 작은 커널을 이미지 위로 이동시키며 주변 픽셀을 함께 확인한다.

- 합성곱층 → 지역적인 패턴을 찾아 특징 맵 생성
- 풀링층 → 특징 맵의 크기를 줄이면서 중요한 정보 유지
- 완전연결층 → 추출된 특징으로 최종 분류나 예측 수행

```text
이미지
  ↓ 합성곱층
지역 특징 맵
  ↓ 풀링층
축소된 특징 맵
  ↓ 완전연결층
최종 예측
```

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `T.Compose([...])` | 여러 이미지 변환을 순서대로 결합 |
| `T.Resize((H, W))` | 이미지 크기 통일 |
| `T.ToTensor()` | 이미지를 `(C, H, W)` 텐서로 변환 |
| `T.Normalize(mean, std)` | 채널별 정규화 적용 |
| `cv2.cvtColor(..., cv2.COLOR_BGR2RGB)` | BGR 이미지를 RGB로 변환 |
| `torch.stack(images)` | 여러 이미지 텐서를 배치 축으로 결합 |

### ⭐ 오늘의 핵심

- 학습 데이터에는 데이터 증강을 적용할 수 있지만 검증·테스트 데이터에는 고정된 변환을 적용한다.
- 배치로 묶기 전 모든 이미지의 채널 수와 높이·너비를 같게 맞춘다.
- 정규화 통계는 학습 데이터에서만 계산하고 모든 데이터 분할에 동일하게 적용한다.
- 변환은 입력 자료형을 고려해 이미지 변형, `ToTensor`, `Normalize` 순서로 구성한다.
- CNN은 이미지의 공간적인 이웃 관계를 활용해 지역 특징을 학습한다.
