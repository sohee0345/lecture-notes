### Dataset, DataLoader와 이미지 텐서

`Dataset`은 개별 샘플의 입력값인 `feature`와 정답인 `target`을 제공하고, `DataLoader`는 이 샘플들을 `batch_size`만큼 묶어 학습 루프에 전달한다. 이미지 한 장은 보통 `(C, H, W)`, 여러 장을 묶은 배치는 `(N, C, H, W)` 형태의 텐서가 된다.

```python
features, targets = next(iter(train_dataloader))
print(features.shape)  # (batch, channel, height, width)
```

> **핵심:** 모델에 데이터를 넣기 전에는 각 축이 무엇을 뜻하는지 확인해야 한다.

## 1. torchvision으로 이미지 데이터 불러오기

`torchvision.datasets`는 자주 사용하는 이미지 데이터셋과 폴더 기반 데이터 로딩 기능을 제공한다. 데이터셋 객체는 전체 데이터 개수를 알려 주고, 인덱스로 접근하면 `(feature, target)` 한 쌍을 반환한다.

### 1.1 FashionMNIST와 ToTensor

`FashionMNIST`는 의류 흑백 이미지 분류 데이터셋이다. `train` 인자로 학습용과 테스트용 데이터를 구분하고, `ToTensor()`로 이미지를 PyTorch 텐서로 변환할 수 있다.

```python
from torchvision import datasets
from torchvision.transforms import ToTensor

train_dataset = datasets.FashionMNIST(
    root="fashion_data",
    train=True,
    download=True,
    transform=ToTensor(),
)

feature, target = train_dataset[0]
```

`ToTensor()`를 적용한 이미지는 `(channel, height, width)` 순서가 된다. Matplotlib은 컬러 이미지를 `(height, width, channel)` 순서로 받으므로 축 순서를 바꿔 표시한다. 흑백 이미지는 2차원 배열로도 표시할 수 있다.

```python
import matplotlib.pyplot as plt

plt.imshow(feature.permute(1, 2, 0))
plt.show()
```

### 1.2 ImageFolder의 폴더 구조

`ImageFolder`는 바로 아래의 하위 폴더 이름을 클래스 이름으로 인식하고 클래스별 숫자 라벨을 자동으로 만든다. 학습용과 테스트용 데이터를 나누려면 각 영역 아래에 동일한 클래스 폴더 구조를 둔다.

```text
data/pizza_steak_sushi/
├─ train/
│  ├─ pizza/
│  ├─ steak/
│  └─ sushi/
└─ test/
   ├─ pizza/
   ├─ steak/
   └─ sushi/
```

```python
from pathlib import Path
from torchvision.datasets import ImageFolder

base_path = Path("./data/pizza_steak_sushi")

train_dataset = ImageFolder(
    root=base_path / "train",
    transform=ToTensor(),
)
```

> **핵심:** `ImageFolder`에서는 폴더 구조가 데이터와 라벨의 대응 관계를 결정한다.

## 2. DataLoader로 미니배치 구성하기

`DataLoader`는 데이터셋을 지정한 크기의 배치로 나눈다. `shuffle=True`를 사용하면 Epoch마다 샘플 순서를 섞어 모델이 고정된 데이터 순서에 의존하는 것을 줄일 수 있다.

```python
from torch.utils.data import DataLoader

train_dataloader = DataLoader(
    train_dataset,
    batch_size=1,
    shuffle=True,
)

features, targets = next(iter(train_dataloader))
```

`len(train_dataloader)`는 배치의 개수다. 마지막 배치를 버리지 않는 기본 설정에서는 데이터 개수가 배치 크기로 나누어떨어지지 않아도 남은 샘플이 마지막 배치가 된다.

## 3. 사용자 정의 이미지 Dataset

PyTorch가 직접 제공하지 않는 데이터는 `torch.utils.data.Dataset`을 상속해 데이터셋으로 만들 수 있다. 사용자 정의 클래스는 데이터 위치와 변환 규칙을 저장하고, 전체 샘플 수와 인덱스별 샘플을 반환하도록 구현한다.

### 3.1 세 가지 핵심 메서드

- `__init__()` → 파일 경로, 라벨 목록, 전처리 함수처럼 반복해서 사용할 정보를 저장한다.
- `__len__()` → 전체 샘플 수를 반환한다.
- `__getitem__(idx)` → `idx`에 해당하는 `(feature, target)`을 반환한다.

```python
from PIL import Image
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, dir_path, transform=None):
        self.path_lst = list(dir_path.glob("*/*.jpg"))
        self.labels = [
            entry.name for entry in os.scandir(dir_path)
            if entry.is_dir()
        ]
        self.transform = transform

    def __len__(self):
        return len(self.path_lst)

    def __getitem__(self, idx):
        feature = Image.open(self.path_lst[idx])
        class_name = self.path_lst[idx].parent.stem
        target = self.labels.index(class_name)

        if self.transform:
            feature = self.transform(feature)

        return feature, target
```

라벨 이름을 숫자로 바꾸는 규칙은 학습·검증·테스트 데이터에서 항상 같아야 한다. 클래스 목록을 정렬하거나 하나의 공통 매핑을 재사용하면 폴더 탐색 순서에 따라 숫자 라벨이 달라지는 문제를 예방할 수 있다.

### 3.2 pathlib와 파일 탐색

`Path`는 `pathlib` 모듈이 제공하는 경로 객체다. `/` 연산자로 경로를 연결하고, `glob()`으로 패턴과 일치하는 파일을 찾을 수 있다. `os.walk()`는 시작 경로 아래의 폴더와 파일을 재귀적으로 순회한다.

```python
from pathlib import Path
import os

base_path = Path("./data/pizza_steak_sushi")
train_path = base_path / "train"

image_paths = list(train_path.glob("*/*.jpg"))

for dir_path, dir_names, file_names in os.walk(base_path):
    print(dir_path, dir_names, len(file_names))
```

## 4. 표 형태 데이터의 사용자 정의 Dataset

이미지가 아닌 표 형태 데이터도 같은 인터페이스로 다룰 수 있다. DataFrame에서 목표 열을 분리하고 NumPy 배열이나 텐서로 바꾸면 `DataLoader`가 배치로 묶을 수 있다.

```python
from torch.utils.data import Dataset

class TableDataset(Dataset):
    def __init__(self, df, target_name="survived", transform=None):
        self.arr_feature = df.drop([target_name], axis=1).to_numpy()
        self.arr_target = df[target_name].to_numpy()
        self.transform = transform

    def __len__(self):
        return self.arr_feature.shape[0]

    def __getitem__(self, idx):
        feature = self.arr_feature[idx]
        target = self.arr_target[idx]

        if self.transform:
            feature = self.transform(feature)

        return feature, target
```

모델에 전달할 때는 입력 특성과 정답이 모델 및 손실함수가 요구하는 `dtype`을 갖는지도 확인해야 한다.

## 5. 시계열 데이터의 슬라이딩 윈도우

시계열 예측에서는 시간 순서를 유지한 채 연속된 과거 구간을 입력으로, 그다음 미래 구간을 정답으로 만든다. 창을 한 칸씩 이동하며 샘플을 생성하는 방식을 슬라이딩 윈도우라고 한다.

- `input_size` → 모델이 참고하는 과거 시점의 수
- `pred_size` → 예측할 미래 시점의 수
- `target_idx` → 여러 열 중 정답으로 사용할 열의 위치

```python
import numpy as np

def transform_by_series_dataset(
    data,
    input_size=2,
    pred_size=2,
    target_idx=0,
):
    x_lst = []
    y_lst = []

    for i in range(input_size, data.shape[0] - pred_size + 1):
        x_lst.append(data[i-input_size:i])
        y_lst.append(data[i:i+pred_size, target_idx])

    return np.array(x_lst), np.array(y_lst)
```

입력 배열의 열 수를 $F$, 생성된 샘플 수를 $N$이라고 하면 결과 형태는 다음과 같다.

```text
features: (N, input_size, F)
targets : (N, pred_size)
```

시계열은 순서 자체가 정보이므로 학습용과 테스트용 데이터를 시간 순서대로 나눈 뒤 각 구간에서 윈도우를 구성해야 한다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `FashionMNIST` | torchvision이 제공하는 의류 이미지 데이터셋 |
| `ImageFolder` | 클래스별 폴더 구조에서 이미지와 라벨을 만드는 데이터셋 |
| 사용자 정의 `Dataset` | 원하는 데이터의 조회 규칙을 직접 구현한 데이터셋 |
| `transform` | 샘플을 조회할 때 적용하는 전처리 함수 |
| 슬라이딩 윈도우 | 연속된 과거 구간과 미래 구간으로 시계열 샘플을 만드는 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `ToTensor()` | 이미지를 PyTorch 텐서로 변환 |
| `ImageFolder(root=...)` | 폴더 구조로 이미지 분류 데이터셋 생성 |
| `feature.permute(1, 2, 0)` | 이미지 축을 Matplotlib 표시 순서로 변경 |
| `Path.glob("*/*.jpg")` | 클래스 하위 폴더의 JPG 파일 탐색 |
| `DataLoader(..., shuffle=True)` | 데이터셋을 섞어 미니배치로 구성 |

### ⭐ 오늘의 핵심

- Dataset은 데이터 종류와 관계없이 인덱스별 `feature`와 `target`을 제공하는 공통 인터페이스다.
- 이미지 분류에서는 폴더와 숫자 라벨의 대응 관계를 일관되게 유지해야 한다.
- 이미지 텐서와 배치는 각각 `(C, H, W)`, `(N, C, H, W)` 축 순서를 사용한다.
- 시계열 데이터는 시간 순서를 보존하며 과거 입력 구간과 미래 정답 구간으로 변환한다.
