### 선형회귀와 모델 파라미터

선형회귀는 Feature의 가중합으로 연속적인 값을 예측한다. 모델 파라미터는 학습 과정에서 데이터로부터 결정되고, 하이퍼파라미터는 학습 전에 설정하거나 탐색한다.

$$
\hat{y}=XW+b
$$

> **핵심:** 오늘은 가중치와 편향이 손실을 줄이는 방향으로 학습되는 과정과 분류 모델을 평가하는 여러 기준을 다룬다.

## 1. AI·머신러닝·딥러닝

```text
인공지능 AI
└─ 머신러닝 ML
   └─ 딥러닝 DL
```

머신러닝은 사람이 모든 규칙을 직접 작성하기 어려운 문제에서 데이터로부터 예측 규칙을 학습한다. 딥러닝은 머신러닝 가운데 인공신경망을 여러 층으로 구성해 학습하는 방식이다.

## 2. 가중치와 편향

단순 선형회귀는 하나의 Feature를 사용한다.

$$
\hat{y}=wx+b
$$

다중선형회귀는 여러 Feature와 가중치를 사용한다.

$$
\hat{y}=w_1x_1+w_2x_2+\cdots+w_px_p+b
$$

- $X$ → 주어진 Feature 데이터 행렬
- $W$ → 각 Feature의 영향을 나타내는 가중치 벡터
- $b$ → 단일 Target 회귀에서 모든 예측에 더하는 편향 스칼라
- $\hat{y}$ → 모델이 계산한 예측값 벡터

학습 데이터 `X_tr.shape == (379, 104)`는 샘플 379개와 Feature 104개를 뜻한다. 따라서 가중치는 104개이고 편향은 하나이며, 379는 학습 횟수가 아니라 학습에 사용하는 행의 수이다.

## 3. 손실함수와 경사하강법

선형회귀는 실제값과 예측값의 차이를 나타내는 손실을 작게 만드는 방향으로 $W$와 $b$를 조정한다. 평균제곱오차는 다음과 같다.

$$
\operatorname{MSE}=\frac{1}{N}\sum_i(\hat{y}_i-y_i)^2
$$

경사하강법은 손실함수의 기울기 반대 방향으로 파라미터를 이동한다.

$$
w \leftarrow w-\eta\frac{\partial L}{\partial w},
\qquad
b \leftarrow b-\eta\frac{\partial L}{\partial b}
$$

$\eta$는 학습률이다. 너무 작으면 학습이 느리고 너무 크면 최솟값을 지나치거나 학습이 불안정해질 수 있다.

```python
w = np.random.uniform(-1, 1)
b = np.random.uniform(-1, 1)
learning_rate = 0.7

for epoch in range(200):
    pred = w * x + b
    error = pred - y
    loss = np.mean(error ** 2)

    if loss < 0.001:
        break

    w_grad = 2 * np.mean(error * x)
    b_grad = 2 * np.mean(error)

    w -= learning_rate * w_grad
    b -= learning_rate * b_grad
```

손실을 MSE로 정의했다면 종료 조건과 기울기 계산도 같은 손실을 기준으로 맞춘다.

## 4. 과적합과 규제

과적합은 train에는 매우 잘 맞지만 새로운 데이터에는 성능이 낮은 상태이다. 하이퍼파라미터 튜닝은 점수를 무조건 높이는 일이 아니라 과적합과 과소적합 사이에서 일반화 성능이 좋은 설정을 찾는 과정이다.

실습 결과:

| 모델 | train $R^2$ | test $R^2$ |
| --- | ---: | ---: |
| LinearRegression | 0.9521 | 0.6075 |
| Ridge, `alpha=1` | 0.8858 | 0.7528 |
| Ridge, `alpha=0.1` | 0.9282 | 0.7722 |

### 4.1 L1과 L2 규제

- L1 규제 → 손실에 $\alpha\sum_j|w_j|$를 더한다. 일부 계수를 정확히 0으로 만들어 Feature 선택 효과가 생길 수 있다.
- L2 규제 → 손실에 $\alpha\sum_jw_j^2$를 더한다. 큰 계수를 줄이지만 보통 정확히 0으로 만들지는 않는다.
- ElasticNet → L1과 L2 규제를 함께 사용한다.

`alpha`는 학습률이 아니라 규제 강도이다. 값을 키우면 규제가 강해지지만 지나치게 강하면 모델이 너무 단순해져 과소적합될 수 있다.

```python
from sklearn.linear_model import ElasticNet, Lasso, Ridge

ridge = Ridge(alpha=0.1).fit(x_train, y_train)
lasso = Lasso(alpha=0.01, max_iter=100000).fit(x_train, y_train)
elastic = ElasticNet(alpha=0.01, l1_ratio=0.8).fit(x_train, y_train)
```

`l1_ratio=0`은 L2 쪽, `l1_ratio=1`은 L1 쪽이며 중간 값은 두 규제를 섞는다. 수렴 경고가 발생하면 반복 횟수와 Feature 스케일, 규제 설정을 확인한다.

## 5. 이진 분류와 혼동행렬

Digits 데이터에서 숫자 5이면 1, 아니면 0으로 바꾸어 이진 분류 문제를 만든다.

```python
from sklearn.datasets import load_digits

digits = load_digits()
x = digits.data
y = (digits.target == 5).astype(int)
```

혼동행렬은 실제 레이블과 최종 예측 레이블을 비교한다.

| 실제 / 예측 | Positive | Negative |
| --- | --- | --- |
| Positive | TP: 실제 양성을 양성으로 예측 | FN: 실제 양성을 음성으로 예측 |
| Negative | FP: 실제 음성을 양성으로 예측 | TN: 실제 음성을 음성으로 예측 |

```python
from sklearn.metrics import confusion_matrix

cm = confusion_matrix(y_valid, y_pred)
normalized_cm = confusion_matrix(
    y_valid,
    y_pred,
    normalize="true",
)
```

`normalize="true"`는 실제 클래스별 행의 합이 1이 되도록 정규화한다. 혼동행렬 자체에는 확률이 아니라 0·1 같은 예측 레이블을 사용한다.

## 6. Accuracy·Precision·Recall·F1

$$
\operatorname{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}
$$

$$
\operatorname{Precision}=\frac{TP}{TP+FP}
$$

$$
\operatorname{Recall}=\frac{TP}{TP+FN}
$$

$$
F1=2\frac{\operatorname{Precision}\cdot\operatorname{Recall}}
{\operatorname{Precision}+\operatorname{Recall}}
$$

- Accuracy → 전체 예측 중 맞힌 비율
- Precision → 양성이라고 예측한 것 중 실제 양성의 비율로, FP를 줄이는 일이 중요할 때 본다.
- Recall → 실제 양성 중 찾아낸 비율로, FN을 줄이는 일이 중요할 때 본다.
- F1 → Precision과 Recall의 조화평균

양성 클래스가 적으면 모두 음성으로 예측해도 Accuracy가 높을 수 있으므로 DummyClassifier 기준과 다른 지표를 함께 본다.

```python
from sklearn.metrics import classification_report

print(classification_report(y_valid, y_pred))
```

## 7. 분류 임계값과 Trade-off

분류 모델은 클래스 레이블을 만들기 전에 확률이나 결정 점수를 출력할 수 있다.

```python
probability = tree.predict_proba(x_valid)[:, 1]
score = sgd_clf.decision_function(x_valid)
```

- `predict_proba()` → 클래스별 확률을 반환한다.
- `decision_function()` → 분류 경계로부터의 결정 점수를 반환하며 확률과 같지 않다.

```python
threshold = 0.5
y_pred = np.where(probability >= threshold, 1, 0)
```

임계값을 높이면 일반적으로 양성 예측이 줄어 Precision은 올라가고 Recall은 내려가는 방향으로 움직인다. 낮추면 양성 예측이 늘어 Recall은 올라가고 Precision은 내려가는 방향으로 움직인다. 업무에서 FP와 FN 중 어떤 오류가 더 큰 비용을 만드는지에 따라 임계값과 지표를 선택한다.

## 8. ROC Curve와 AUC

ROC Curve는 여러 임계값에서 FPR과 TPR의 관계를 그린다.

$$
\operatorname{TPR}=\frac{TP}{TP+FN}
$$

$$
\operatorname{FPR}=\frac{FP}{FP+TN}
$$

AUC는 ROC Curve 아래 면적이다. 특정 임계값 하나를 고르기 전 모델이 양성과 음성을 구분해 순위를 매기는 능력을 요약한다.

```python
from sklearn.metrics import RocCurveDisplay, roc_auc_score

auc_score = roc_auc_score(y_valid, probability)
RocCurveDisplay.from_predictions(y_valid, probability)
```

> [!example] AUC 실습 결과
> 실습에서는 가장 빈번한 클래스만 예측한 DummyClassifier의 AUC가 `0.5`, 깊이 3의 DecisionTreeClassifier가 약 `0.9480`이었다. `0.5`는 무작위 순위 수준이고 `1`은 완벽한 구분이다. 성능 등급을 나누는 고정 구간은 분야에 따라 달라질 수 있다.

## 9. 오류 사례 확인

예측 확률과 Feature를 한 DataFrame으로 합치면 특정 오류 사례를 직접 확인할 수 있다.

```python
analysis = pd.DataFrame({
    "y_true": y_train,
    "positive_probability": tree.predict_proba(x_train)[:, 1],
})
analysis = pd.concat(
    [analysis, pd.DataFrame(x_train)],
    axis=1,
)

false_negative = (
    (analysis["y_true"] == 1)
    & (analysis["positive_probability"] < 0.5)
)

analysis.loc[false_negative]
```

실제 양성을 음성으로 예측한 사례는 FN이다. 가설검정의 1종·2종 오류와 분류의 FP·FN은 문맥과 양성 정의를 명확히 한 뒤 연결해야 하며 단순히 이름만 바꾸어 동일시하지 않는다.

| 개념 | 의미 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `w -= learning_rate * gradient` | 기울기 반대 방향으로 가중치 갱신 |
| `Ridge(alpha=...)` | L2 규제를 적용한 선형회귀 |
| `Lasso(alpha=...)` | L1 규제를 적용한 선형회귀 |
| `confusion_matrix(y_true, y_pred)` | 혼동행렬 계산 |
| `classification_report(...)` | 주요 분류 지표 출력 |
| `predict_proba(...)[:, 1]` | 양성 클래스 예측 확률 추출 |
| `roc_auc_score(y_true, score)` | ROC AUC 계산 |

### ⭐ 오늘의 핵심

- **학습:** 모델은 손실함수 값을 줄이도록 가중치와 편향을 조정한다.
- **일반화:** 규제 강도는 점수를 무조건 높이는 값이 아니라 과적합과 과소적합을 조절하는 값이다.
- **평가:** 분류 지표와 임계값은 FP·FN의 실제 비용과 클래스 불균형을 고려해 선택한다.
