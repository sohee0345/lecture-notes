### 데이터 분리·결측치·인코딩

전처리 과정에서 데이터로부터 기준을 배우는 작업은 train에만 `fit`하고 train과 test에는 같은 기준으로 `transform`한다. 범주형 Feature는 인코딩하고 수치형 Feature는 필요에 따라 스케일을 조정한다.

```text
train → fit + transform
test  → train에서 학습한 기준으로 transform
```

> **핵심:** 결측치 대체, 인코딩과 스케일링 모두 test에서 별도의 기준을 학습하지 않는다.

### 1.2 결측치 처리

결측치 대체 기준은 train에서 계산한 뒤 test에도 그대로 사용한다.

```python
def do_cleaning(train: pd.DataFrame, test: pd.DataFrame) -> None:
    for col in train.columns:
        if not train[col].isnull().any():
            continue

        if pd.api.types.is_numeric_dtype(train[col]):
            fill_value = train[col].mean()
        else:
            fill_value = train[col].mode().iloc[0]

        train[col] = train[col].fillna(fill_value)
        test[col] = test[col].fillna(fill_value)
```

> [!WARNING]
> **결측치 처리 기준**
> 결측 비율만으로 삭제·대체 방법이 자동 결정되지는 않는다. 비율, 발생 원인, 컬럼의 중요도와 대체 후 분포를 함께 살펴야 한다. Target을 이용한 그룹별 대체는 Target 정보가 Feature 전처리에 들어가므로 누수 여부를 특히 주의한다.

## 2. One-Hot Encoding 함수화

실습에서는 `category_encoders.OneHotEncoder`를 Enum으로 관리하고 각 범주형 컬럼을 train에서 학습한 뒤 train과 test를 변환했다.

```python
import category_encoders as ce

encoder = ce.OneHotEncoder(use_cat_names=True)
encoder.fit(x_train_str)

x_train_enc = encoder.transform(x_train_str)
x_test_enc = encoder.transform(x_test_str)
```

`use_cat_names=True`는 생성된 컬럼 이름에 범주 이름을 포함한다. 실습 결과는 다음과 같다.

```text
x_train_enc: (712, 19)
x_test_enc : (179, 19)
```

인코더 객체를 함수 안에서 생성하면 호출마다 독립된 학습 상태를 사용할 수 있다. 어떤 구조를 사용하더라도 `fit`은 train에만 수행해야 한다.

## 3. 수치형 데이터 스케일링

스케일링은 수치형 Feature의 값 범위를 변환하여 단위 차이를 줄이는 전처리이다.

### 3.1 StandardScaler

StandardScaler는 train의 평균과 표준편차를 학습하고 각 값을 표준화한다.

$$
z=\frac{x-\mu_{train}}{\sigma_{train}}
$$

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
x_train_scaled = scaler.fit_transform(x_train_number)
x_test_scaled = scaler.transform(x_test_number)
```

### 3.2 MinMaxScaler

MinMaxScaler는 train에서 관측한 최솟값과 최댓값을 기준으로 값을 일정 범위로 변환한다. 기본 범위는 0부터 1이다.

### 3.3 Normalizer

Normalizer는 컬럼별 통계를 학습하는 방식이 아니라 각 행 벡터의 Norm을 기준으로 행 자체를 정규화한다. L2 정규화를 사용하면 각 행의 L2 Norm이 1이 된다.

L2 Norm은 벡터의 길이이며, 두 벡터 차이의 L2 Norm이 유클리드 거리이다. 따라서 L2 Norm과 유클리드 거리를 같은 개념으로 보지는 않는다.

## 6. 선형회귀 학습과 예측

선형회귀는 여러 Feature의 선형 결합으로 연속적인 Target을 예측하는 회귀 모델이다.

$$
\hat{y}=\beta_0+\beta_1x_1+\cdots+\beta_px_p
$$

Diabetes 데이터는 442행, Feature 10개로 구성된다.

```python
from sklearn.datasets import load_diabetes
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split

diabetes = load_diabetes()

x_train, x_valid, y_train, y_valid = train_test_split(
    diabetes.data,
    diabetes.target,
    random_state=42,
)

model = LinearRegression()
model.fit(x_train, y_train)
pred = model.predict(x_valid)
```

실습에서 train은 331행, validation은 111행이었으며 예측값과 실제값은 모두 shape `(111,)`이었다.

## 7. 결정계수 $R^2$

$R^2$는 실제값을 평균으로만 예측하는 기준과 비교해 모델이 변동을 얼마나 설명하는지 나타낸다.

$$
R^2=1-\frac{\sum_i(y_i-\hat{y}_i)^2}{\sum_i(y_i-\bar{y})^2}
$$

```python
from sklearn.metrics import r2_score

r2 = r2_score(y_valid, pred)
# 0.4849058889476756
```

$R^2=1$이면 완벽한 예측이다. 0은 Target 평균을 사용한 기준 모델과 같은 수준이며, 성능이 기준보다 나쁘면 음수가 될 수도 있으므로 항상 0과 1 사이인 것은 아니다.

## 8. 오차 크기를 측정하는 회귀 지표

### 8.1 MAE

$$
\operatorname{MAE}=\frac{1}{n}\sum_i|y_i-\hat{y}_i|
$$

절대오차의 평균이므로 Target과 같은 단위를 사용한다. 실습 결과는 약 `41.55`였다.

### 8.2 MSE와 RMSE

$$
\operatorname{MSE}=\frac{1}{n}\sum_i(y_i-\hat{y}_i)^2
$$

$$
\operatorname{RMSE}=\sqrt{\operatorname{MSE}}
$$

MSE는 큰 오차를 제곱해 더 크게 반영하고, RMSE는 제곱근을 취해 Target과 같은 단위로 되돌린다.

```text
MSE  = 2848.31
RMSE = 53.37
```

## 9. 비율과 로그 기반 회귀 지표

### 9.1 RMSLE

$$
\operatorname{RMSLE}=\sqrt{\frac{1}{n}\sum_i\left(\log(1+y_i)-\log(1+\hat{y}_i)\right)^2}
$$

실제값과 예측값에 각각 `log1p`를 적용한 뒤 RMSE를 계산한다. 실제값과 예측값이 음수가 아닌 문제에 사용하며, 단순히 잔차 평균에 로그를 취하는 방식이 아니다. 실습 결과는 약 `0.4180`이었다.

### 9.2 MAPE

$$
\operatorname{MAPE}=\frac{1}{n}\sum_i\left|\frac{y_i-\hat{y}_i}{y_i}\right|
$$

실제값 대비 절대오차 비율의 평균이다. scikit-learn 함수는 백분율이 아니라 비율을 반환하므로 실습의 `0.3731`은 약 37.31%에 해당한다. 실제값이 0이거나 0에 가까우면 값이 정의되지 않거나 매우 커질 수 있다.

### 9.3 SMAPE

SMAPE는 실제값과 예측값의 크기를 함께 분모에 사용한다. 구현에 따라 100 또는 200을 곱하는 정의가 있으므로 지표 범위와 단위를 함께 확인해야 한다.

```python
def smape(y_true, y_pred):
    numerator = 2 * np.abs(y_true - y_pred)
    denominator = np.abs(y_true) + np.abs(y_pred)
    ratio = np.divide(
        numerator,
        denominator,
        out=np.zeros_like(numerator, dtype=float),
        where=denominator != 0,
    )
    return ratio.mean()
```

오차 지표는 일반적으로 작을수록 좋지만 각 지표가 강조하는 오차와 사용 조건이 다르므로 문제 목적에 맞게 선택한다.

## 10. EDA와 전처리 판단 기준

- Target이 연속적인 수치인지 범주인지 확인해 회귀와 분류를 구분한다.
- 분류 문제라면 먼저 클래스 비율을 확인한다.
- 결측치는 데이터의 의미와 도메인 지식을 바탕으로 관련 Feature를 묶은 통계값으로 대체할 수 있다.
- Target과 관련 있는 Feature뿐 아니라 Feature끼리 지나치게 중복된 정보를 가지는지도 확인한다.
- 전처리 방법을 정한 뒤에는 train에서 기준을 학습하고 test에는 같은 기준을 적용한다.

## 전체 흐름

```text
train·test 분리
  ↓
train 기준으로 결측치 처리
  ↓
범주형 Feature One-Hot Encoding
  ↓
수치형 Feature Scaling
  ↓
DataFrame으로 컬럼 복원
  ↓
인코딩·스케일링 결과 결합 및 shape 검증
  ↓
회귀 모델 학습과 예측
  ↓
R²·MAE·MSE·RMSE·RMSLE·MAPE·SMAPE 평가
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| Scaling | 수치형 Feature의 값 범위를 변환한다. |
| StandardScaler | train 평균과 표준편차로 표준화한다. |
| Normalizer | 각 행 벡터의 Norm을 1로 맞춘다. |
| 선형회귀 | Feature의 선형 결합으로 연속값을 예측한다. |
| $R^2$ | 평균 기준 모델 대비 설명력을 나타낸다. |
| 오차 지표 | 실제값과 예측값의 차이를 서로 다른 방식으로 요약한다. |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `scaler.fit(x_train)` | train에서 스케일 기준 학습 |
| `scaler.transform(x_test)` | train 기준으로 test 변환 |
| `pd.DataFrame(data, columns=...)` | 변환 배열에 컬럼 이름 복원 |
| `pd.concat([...], axis=1)` | 수치형·범주형 전처리 결과 결합 |
| `model.fit(x_train, y_train)` | 회귀 모델 학습 |
| `model.predict(x_valid)` | validation 예측값 생성 |

### ⭐ 오늘의 핵심

- **일관된 전처리:** 인코더·스케일러·결측치 기준은 train에만 학습하고 test에는 변환만 적용한다.
- **구조 보존:** NumPy 변환 결과를 DataFrame으로 복원하면 컬럼 확인과 데이터 결합이 쉬워진다.
- **지표 선택:** 회귀 지표의 단위, 이상치 민감도, 0과 음수 허용 여부를 확인한다.
