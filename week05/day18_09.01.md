## 1. 데이터 구조와 변수 유형

### 1.1 정형·반정형·비정형 데이터

| 구분 | 특징 | 예시 |
| --- | --- | --- |
| 정형 데이터 | 행과 열처럼 고정된 구조가 있음 | 데이터베이스 테이블, Excel 표 |
| 반정형 데이터 | 태그나 키처럼 구조 표시는 있지만 고정된 표는 아님 | XML, JSON |
| 비정형 데이터 | 일정한 행·열 구조가 없음 | 텍스트, 이미지 |

### 1.2 수치형 데이터

- 연속형 → 키, 몸무게처럼 범위 안에서 연속적으로 측정되는 값
- 이산형 → 승객 수처럼 개수로 셀 수 있는 값

### 1.3 범주형 데이터

- 명목형 → 성별, 혈액형처럼 종류만 구분하고 순서가 없음
- 순서형 → 등급, 만족도처럼 종류 사이에 순서가 있음

숫자로 저장되었다고 반드시 수치형은 아니다. Titanic의 `survived`, `pclass`, `sibsp`, `parch`는 숫자로 저장되어도 각각 상태나 등급, 개수를 나타내므로 분석 목적에 맞게 범주형 또는 이산형으로 해석한다.

## 2. EDA와 기술통계

EDA(Exploratory Data Analysis)는 모델링 전에 데이터의 구조와 분포, 결측치, 이상치와 변수 관계를 탐색하는 과정이다.

```python
import numpy as np
import seaborn as sns

df = sns.load_dataset("titanic")

df.shape
df.head()
df.info()
df.columns
```

### 2.1 자료형별 컬럼 선택

```python
numeric = df.select_dtypes(include=np.number)
non_numeric = df.select_dtypes(exclude=np.number)
```

저장 자료형 기준 선택이므로 숫자로 저장된 범주도 `numeric`에 포함될 수 있다. 이후 변수의 실제 의미를 다시 확인한다.

### 2.2 describe()

수치형 데이터의 `describe()`는 개수, 평균, 표준편차, 최솟값, 사분위수와 최댓값을 보여 준다.

```python
numeric.describe()
```

범주형 데이터에서는 다음 통계를 확인한다.

| 통계 | 의미 |
| --- | --- |
| `count` | 결측치를 제외한 값의 개수 |
| `unique` | 서로 다른 값의 개수 |
| `top` | 최빈값 |
| `freq` | 최빈값의 등장 횟수 |

분석에서 사용하지 않을 중복 컬럼은 삭제할 수 있다.

```python
df.drop(["alive", "class", "embark_town"], axis=1, inplace=True)
```

`axis=1`은 컬럼을 대상으로 하고 `inplace=True`는 현재 DataFrame에 직접 반영한다.

### 2.3 자료형 변경

숫자로 저장되어 있어도 등급이나 구분을 나타내는 값은 분석 목적에 따라 범주형으로 바꿀 수 있다.

```python
df["pclass"] = df["pclass"].astype(str)
```

`astype()`은 자료형을 변경한다. 숫자 컬럼에 결측치가 있으면 일반 `int`로 바로 변환할 때 오류가 날 수 있으므로 결측치를 먼저 확인한다.

### 2.4 범주형 변수 교차표

두 범주형 변수의 조합별 개수는 `pd.crosstab()`으로 확인할 수 있다.

```python
pd.crosstab(df["pclass"], df["survived"])
```

교차표는 범주 조합의 빈도를 보여 주므로 클래스별 차이를 탐색할 때 사용한다.

## 3. 왜도와 첨도

### 3.1 왜도

왜도(Skewness)는 분포의 비대칭 방향과 정도를 나타낸다.

```python
df["age"].skew()
```

|   왜도   |   분포 해석   |
| :----: | :-------: |
| `0` 근처 |  비교적 대칭   |
|   양수   | 오른쪽 꼬리가 김 |
|   음수   | 왼쪽 꼬리가 김  |

Titanic `age`의 왜도는 약 `0.389`로 비교적 대칭에 가깝지만 오른쪽 꼬리가 조금 더 긴 분포이다.

### 3.2 첨도

첨도(Kurtosis)는 분포의 꼬리와 이상치 발생 성향을 포함한 형태를 나타내는 통계량이다. Pandas의 `Series.kurt()`는 정규분포의 값을 0으로 맞춘 초과첨도를 반환한다.

```python
df["fare"].kurt()  # 약 33.398
```

- `0` 근처 → 정규분포와 비슷한 초과첨도
- 양수 → 정규분포보다 꼬리가 두껍고 극단값이 나타날 가능성이 큼
- 음수 → 정규분포보다 꼬리가 얇은 형태

첨도를 단순히 그래프 꼭대기의 뾰족함만으로 해석하지 않고 히스토그램과 Box Plot을 함께 확인한다.

------------------------------------------------------------------------

## 4. 로그 변환과 분포 확인

요금처럼 0 이상이고 오른쪽 꼬리가 긴 데이터는 `log1p()`로 큰 값 사이의 차이를 압축할 수 있다.

```python
df["fare_log"] = np.log1p(df["fare"])

print(df["fare"].skew())
print(df["fare_log"].skew())
```

`log1p(x)`는 $\log(1+x)$를 계산하므로 값이 0이어도 사용할 수 있다. 실습에서 로그 변환한 `fare_log`의 왜도는 약 `0.395`, 초과첨도는 약 `0.976`으로 원래 `fare`보다 대칭에 가까워지고 극단값의 영향이 줄었다.

```python
sns.displot(df, x="fare")
sns.displot(df, x="fare_log")
sns.boxplot(data=df, y="fare_log")
```

로그 변환이 항상 제곱근 변환보다 좋은 것은 아니다. 데이터 값의 범위와 목적에 맞게 변환 전후 분포를 비교하여 선택한다.

### 4.1 Box Plot 해석

상자 안의 선은 중앙값, 상자의 아래와 위 경계는 각각 제1사분위수(Q1)와 제3사분위수(Q3)이다. 수염 밖의 점은 Box Plot 기준에서 이상치 후보로 표시된다.

## 5. 상관행렬과 히트맵

`corr()`는 수치형 컬럼 사이의 상관계수를 계산한다.

```python
correlation = df.select_dtypes(include=np.number).corr()

sns.heatmap(
    correlation,
    vmin=-1,
    vmax=1,
    annot=True,
    linewidths=0.2,
    cmap="coolwarm",
)
```

- `1`에 가까움 → 강한 양의 선형 관계
- `-1`에 가까움 → 강한 음의 선형 관계
- `0`에 가까움 → 선형 관계가 약함

상관계수 0은 직교와 같은 표현으로 단순히 동일시할 수 없으며, 비선형 관계가 없다는 뜻도 아니다. 상관계수는 단위가 없고 인과관계를 의미하지 않는다.

## 6. 결측치 확인

Pandas에서는 `NaN`, `None`, `pd.NA` 등이 결측값으로 처리될 수 있다. `undefined`는 JavaScript에서 사용하는 값이며 Python·Pandas의 일반적인 결측값 표기가 아니다.

```python
missing_count = df.isnull().sum()
missing_ratio = missing_count / len(df)

missing_ratio.sort_values(ascending=False)
```

`isnull()`은 결측 위치에 `True`를 반환하고 `True`가 1처럼 합산되므로 `sum()`으로 컬럼별 결측치 수를 계산할 수 있다. 비율은 행 수로 나누며 `df.shape[0]`과 `len(df)`는 모두 행 개수 891을 나타낸다.

실습 결과:

| 컬럼            | 결측치 수 | 결측 비율   |
| :------------ | :---- | :------ |
| `deck`        | 688   | 약 77.2% |
| `age`         | 177   | 약 19.9% |
| `embarked`    | 2     | 약 0.2%  |
| `embark_town` | 2     | 약 0.2%  |

결측 위치는 히트맵으로도 확인할 수 있다.

```python
sns.heatmap(df.isnull(), cbar=False, cmap="viridis")
```

## 7. 결측치 발생 메커니즘

결측치 처리 방법은 빠진 비율만 아니라 결측이 발생한 원인을 함께 고려해야 한다.

| 구분 | 의미 |
| --- | --- |
| MCAR | 관측된 값과 관측되지 않은 값 모두와 무관하게 완전히 무작위로 결측 발생 |
| MAR | 다른 관측된 변수로 결측 발생을 설명할 수 있음 |
| MNAR | 결측된 값 자체나 관측되지 않은 원인과 관련해 결측 발생 |

Feature에서 결측이 발생했다는 이유만으로 무작위 결측이고 Target을 기준으로 발생했다는 이유만으로 비무작위 결측인 것은 아니다. 어떤 변수와 어떤 과정이 결측 확률에 영향을 주는지 조사해야 한다.

## 8. 결측치 처리

### 8.1 삭제

```python
df.drop(["deck"], axis=1, inplace=True)
clean_age = df["age"].dropna()
```

결측 비율이 높고 분석 가치가 낮은 컬럼은 삭제를 고려할 수 있다. 결측 행이 매우 적고 무작위로 발생해 삭제가 분포를 크게 바꾸지 않는 경우에는 행 삭제를 고려한다. `1%`, `20%`, `50%` 같은 비율은 참고 기준일 뿐 모든 데이터에 그대로 적용하는 고정 규칙이 아니다.

### 8.2 통계값 대체

```python
df["age_median"] = df["age"].fillna(df["age"].median())
df["age_mean"] = df["age"].fillna(df["age"].mean())
```

평균이나 중앙값으로 채우면 간단하지만 같은 값이 반복되어 원래 분포와 분산이 달라질 수 있다. 변환 전후 KDE를 비교해 왜곡을 확인한다.

### 8.3 랜덤 표본 대체

```python
missing_mask = df["age"].isnull()
samples = df["age"].dropna().sample(
    n=missing_mask.sum(),
    replace=True,
)

df["age_random"] = df["age"]
df.loc[missing_mask, "age_random"] = samples.to_numpy()
```

Pandas는 Series를 대입할 때 인덱스를 맞춰 정렬한다. 원본 인덱스를 가진 `samples`를 그대로 결측 위치에 대입하면 인덱스가 맞지 않아 값이 채워지지 않을 수 있으므로 위치 순서대로 넣을 때는 `to_numpy()`로 값을 전달한다.

성별처럼 결측과 관련 있을 가능성이 있는 그룹이 있다면 전체에서 무작위 추출하기 전에 그룹별 결측 수와 분포도 확인한다.

## 9. 데이터 누수

데이터 누수(Data Leakage)는 실제 예측 시점에는 알 수 없는 정보가 모델 학습 과정에 들어가 성능이 과대평가되는 문제이다.

```text
전체 데이터를 먼저 전처리 학습
  ↓
테스트 데이터 정보가 전처리 기준에 섞임
  ↓
평가 점수가 실제보다 좋아짐
```

학습 데이터와 테스트 데이터를 나눈 뒤 평균·스케일 같은 전처리 기준은 학습 데이터로만 학습한다. 테스트 데이터에는 학습 데이터에서 얻은 기준으로 `transform`만 적용한다.

```text
train → 전처리 fit + transform → 모델 학습
test  → 같은 전처리로 transform → 최종 평가
```

## 전체 흐름

```text
데이터 구조와 변수 유형 확인
  ↓
shape·info·describe로 기본 탐색
  ↓
왜도·첨도와 그래프로 분포 확인
  ↓
필요하면 log1p 변환 후 다시 비교
  ↓
상관행렬과 히트맵으로 수치형 관계 확인
  ↓
결측치 수·비율·패턴 확인
  ↓
결측 발생 원인과 변수 역할 검토
  ↓
삭제·통계값·랜덤 표본 중 처리 방법 선택
  ↓
train 정보만으로 전처리를 학습해 데이터 누수 방지
```

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `df.select_dtypes(...)` | 저장 자료형 기준으로 컬럼 선택 |
| `df.describe()` | 자료형에 맞는 기술통계 확인 |
| `series.skew()` / `series.kurt()` | 왜도 / 초과첨도 계산 |

| `df.isnull().sum()` | 컬럼별 결측치 수 계산 |
| `series.fillna(value)` | 결측치를 지정한 값으로 채움 |
| `df.drop(..., axis=1)` | 컬럼 삭제 |

### ⭐ 오늘의 핵심

- **해석 우선:** 저장 자료형만 보지 말고 변수의 실제 의미에 따라 수치형·범주형을 구분한다.
- **근거 있는 전처리:** 왜도·첨도·그래프와 결측 원인을 확인한 뒤 변환과 대체 방법을 선택한다.
- **평가 신뢰성:** 전처리 기준은 학습 데이터로만 학습하여 데이터 누수를 방지한다.
