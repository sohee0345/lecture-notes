## 1. GitHub SSH 인증과 다중 계정

SSH 키를 GitHub 계정에 등록하면 로컬 컴퓨터가 해당 계정의 저장소에 접근할 수 있음을 공개키 방식으로 인증할 수 있다.

### 1.1 SSH 키 등록

```text
GitHub Settings
  ↓
SSH and GPG keys
  ↓
New SSH key
  ↓
Title과 공개키 입력
  ↓
Add SSH key
```

여러 계정을 사용한다면 Windows 자격 증명 관리자에 남아 있는 기존 GitHub 인증 정보도 확인한다.

### 1.2 SSH Profile과 Alias

수업에서 사용한 VS Code의 SSH Profile 관리 기능으로 계정별 프로필을 만들고 필요한 프로필을 적용할 수 있다.

```text
Ctrl + Shift + P
  ↓
SSH Profiles: Open Manager
  ↓
Create Profile
```

SSH 설정에서 계정별 Host Alias를 사용하면 Clone 주소의 콜론 앞 호스트를 바꾸어 사용할 계정을 구분할 수 있다.

```text
기본 주소
git@github.com:sohee0345/test_github.git

Alias 적용 주소
git@github.com-sohee0345:sohee0345/test_github.git
```

```text
Ctrl + Shift + P → Git: Clone → Alias를 적용한 SSH 주소 입력
```

> **핵심:** 공개키, SSH Profile과 Host Alias를 계정별로 연결해야 여러 GitHub 계정의 저장소 접근을 구분할 수 있다.

## 2. Matplotlib의 Figure와 Axes

Matplotlib은 Python에서 그래프를 구성하는 시각화 라이브러리이다. Figure는 전체 그림 영역이고 Axes는 실제 데이터가 그려지는 좌표 영역이다.

```python
import matplotlib.pyplot as plt
import koreanize_matplotlib

plt.figure()
plt.axes()
plt.show()
```

- `plt.figure()` → Figure를 만든다.
- `plt.axes()` → 현재 Figure에 Axes를 만든다.
- `plt.show()` → 완성된 그래프를 표시한다.
- `import koreanize_matplotlib` → Matplotlib의 한글 글꼴 설정을 적용한다.

패키지는 다음과 같이 프로젝트에 추가한다.

```bash
uv add koreanize_matplotlib
```

### 2.1 선 그래프와 크기

```python
plt.figure(figsize=(15, 5))
plt.plot(np.arange(2, 7))
plt.plot(np.arange(5))
plt.show()
```

`plt.plot()`을 같은 Axes에 여러 번 호출하면 여러 선을 함께 표시한다. `figsize=(가로, 세로)`는 Figure 크기를 인치 단위로 지정한다.

### 2.2 subplots

```python
fig, axes = plt.subplots(2, 2, figsize=(15, 5))

fig.suptitle("전체 제목")
axes[0, 0].plot(np.arange(5))
axes[0, 1].plot(np.arange(2, 7))
axes[0, 1].set_title("그래프 제목")
axes[1, 0].plot(range(10), np.exp(range(10)))
axes[1, 1].plot(range(1, 1000), np.log1p(range(1, 1000)))

plt.show()
```

`subplots(2, 2)`는 2행 2열의 Axes 네 개를 만들며 `axes[행, 열]`로 원하는 영역을 선택한다. `suptitle()`은 전체 제목, `set_title()`은 개별 Axes 제목을 지정한다.

## 3. 데이터 유형과 그래프 선택

그래프를 고르기 전에 변수의 의미와 자료형을 확인한다.

- 수치형 데이터 → 나이, 길이, 금액처럼 크기와 연산에 의미가 있는 값
- 범주형 데이터 → 성별, 지역, 품종처럼 종류나 그룹을 구분하는 값

숫자로 저장되어도 `0=사망`, `1=생존`처럼 종류를 나타내면 범주형으로 해석할 수 있다.

| 확인 목적 | 주요 변수 유형 | 그래프 |
| --- | --- | --- |
| 두 수치형 변수의 관계 | 수치형 + 수치형 | 산점도 |
| 시간에 따른 변화 | 시간·순서 + 수치형 | 선 그래프 |
| 한 수치형 변수의 분포 | 수치형 | 히스토그램·KDE |
| 그룹별 분포·중앙값·이상치 | 범주형 + 수치형 | 상자 그림 |
| 범주별 수치 비교 | 범주형 + 수치형 | 막대그래프 |

일반적으로 x축에는 비교 기준, y축에는 확인하려는 수치 값을 둔다.

## 4. Matplotlib 막대그래프와 산점도

### 4.1 막대그래프

```python
x = np.arange(3)
years = ["2020", "2021", "2022"]
values = [100, 400, 800]

plt.bar(x, values, color=["red", "green", "blue"])
plt.xticks(x, years)
plt.show()
```

막대그래프는 연도처럼 구분되는 범주별 값을 비교한다. `xticks()`로 눈금 위치와 화면에 표시할 범주 이름을 연결한다.

### 4.2 산점도

```python
count = 50
x = np.random.randn(count)
y = np.random.randn(count)
sizes = (30 * np.random.rand(count)) ** 2
colors = np.random.rand(count)

plt.scatter(x, y, s=sizes, c=colors, alpha=0.5, cmap="coolwarm")
plt.colorbar()
plt.show()
```

점 하나가 관측값 하나를 나타내며 x와 y의 관계를 확인한다. 크기와 색상에 추가 수치 정보를 표현할 수도 있다.

## 5. Seaborn 관계형 그래프

Seaborn은 Matplotlib 위에서 DataFrame의 컬럼 이름을 직접 지정해 그래프를 그릴 수 있게 한다.

```python
import seaborn as sns

sns.set_theme(style="darkgrid")
tips = sns.load_dataset("tips")
```

### 5.1 산점도에 범주와 크기 표현

```python
sns.relplot(
    data=tips,
    x="total_bill",
    y="tip",
    kind="scatter",
    hue="smoker",
    style="time",
)
```

- `hue` → 색상으로 범주를 구분한다.
- `style` → 점 모양으로 범주를 구분한다.
- `size` → 점 크기로 수치 정보를 표현한다.
- `alpha` → 점의 투명도를 조절한다.

### 5.2 선 그래프와 패싯

```python
fmri = sns.load_dataset("fmri")

sns.relplot(
    data=fmri,
    x="timepoint",
    y="signal",
    kind="line",
    row="event",
    col="region",
)
```

`row`와 `col`은 범주별로 그래프 영역을 나누어 같은 관계를 여러 패널에서 비교하게 한다.

## 6. 분포와 범주형 데이터 시각화

### 6.1 히스토그램과 KDE

히스토그램은 수치 범위를 구간으로 나누어 각 구간의 빈도를 막대로 표현한다. KDE는 데이터가 많이 모인 영역을 부드러운 밀도 곡선이나 등고선으로 나타낸다.

```python
penguins = sns.load_dataset("penguins")

sns.displot(
    data=penguins,
    x="flipper_length_mm",
    hue="species",
    multiple="dodge",
)

sns.displot(
    data=penguins,
    x="bill_length_mm",
    y="bill_depth_mm",
    kind="kde",
    cbar=True,
)
```

`hue`는 품종별 분포를 색상으로 나누고 `col="species"`는 품종별 그래프를 별도 열에 배치한다. 2차원 KDE의 `cbar=True`는 밀도 수준을 읽을 수 있는 색상 막대를 표시한다.

### 6.2 Swarm Plot과 Box Plot

```python
tips = sns.load_dataset("tips")

sns.catplot(data=tips, x="day", y="tip", kind="swarm", hue="sex")
sns.catplot(data=tips, x="day", y="tip", kind="box")
```

- Swarm Plot → 관측값을 점으로 펼쳐 범주별 분포를 보여 준다.
- Box Plot → 중앙값, 사분위 범위, 퍼짐과 이상치를 요약한다.

점이 너무 많거나 공간이 좁으면 Swarm Plot의 일부 점을 배치할 수 없다는 경고가 발생할 수 있다.

## 7. 상관관계와 시각화의 필요성

상관관계는 두 변수의 관계 방향과 정도를 나타낸다. 수치형 변수 사이의 선형 관계를 확인할 때 상관계수를 사용할 수 있지만, 상관관계가 원인과 결과를 뜻하지는 않는다.

앤스콤 4분할(Anscombe's Quartet)은 평균, 분산, 상관계수와 회귀 결과가 비슷한 여러 데이터셋도 그래프의 모양은 크게 다를 수 있음을 보여 준다.

> **핵심:** 요약 통계량만 확인하지 말고 산점도와 분포 그래프를 함께 살펴야 데이터의 구조와 이상치를 발견할 수 있다.

## 8. Sweetviz 자동 탐색

Sweetviz는 DataFrame의 컬럼별 분포와 관계를 자동으로 분석해 보고서로 보여 준다.

```python
import seaborn as sns
import sweetviz as sv

df = sns.load_dataset("titanic")
df = df[[
    "survived", "pclass", "sex", "age",
    "sibsp", "parch", "fare", "embarked",
]]

feature_config = sv.FeatureConfig(
    skip="fare",
    force_cat=["survived"],
)

report = sv.analyze(source=df, feat_cfg=feature_config)
report.show_notebook(scale=0.9)
```

- `skip="fare"` → `fare` 컬럼을 분석에서 제외한다.
- `force_cat=["survived"]` → 숫자 0과 1로 저장된 생존 여부를 범주형으로 처리한다.
- `show_notebook()` → 생성된 분석 보고서를 노트북에 표시한다.
