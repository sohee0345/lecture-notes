``` python
import enum

    가위 = 0
    바위 = 1

사용자_선택 = "가위"
assert 사용자_선택 in 가위바위보.__members__, "잘못 입력했습니다."
```

> **핵심:** 이전에 배운 자료형과 조건 검사를 함수 안에 배치하면 입력을 검증하고 결과를 계산하는 하나의 기능으로 묶을 수 있다.

## 1. 함수의 기본 구조

함수는 반복해서 사용할 코드를 하나의 이름으로 묶은 것이다. 파라미터를 통해 입력을 받고, 함수 본문의 코드를 실행한 뒤 `return`으로 결과를 호출한 곳에 돌려줄 수 있다.

``` python
def func(p_x):
    return p_x + 10

x = func(20)
print(x)
```

실행 결과:

``` text
30
```

- `def` → 함수를 정의한다.
- `p_x` → 함수가 전달받는 파라미터이다.
- `func(20)` → 함수에 인자 `20`을 전달하여 호출한다.
- `return` → 계산 결과를 호출한 곳으로 반환하고 함수를 끝낸다.

반환값은 변수에 저장할 수도 있고 `print(func(20))`처럼 바로 사용할 수도 있다.

> **핵심:** 함수 정의와 함수 호출은 서로 다르며, 정의한 함수는 호출해야 본문이 실행된다.

### 1.1 입력과 반환값의 조합

함수는 입력값과 반환값의 유무에 따라 여러 형태로 작성할 수 있다.

```python
def func1():
    print("Hello World")

def func2(name):
    print(f"{name}님, 안녕하세요.")

def func3(name):
    return f"{name}님, 안녕하세요."
```

`print()`는 값을 화면에 표시하고, `return`은 함수의 결과를 호출한 곳으로 전달하면서 함수 실행을 끝낸다. 반환값은 변수에 저장할 수도 있고 다른 표현식에서 바로 사용할 수도 있다.

### 1.2 변수의 사용 범위

함수 안에서 만든 변수는 기본적으로 함수 내부에서 사용한다. 함수 밖의 값을 안으로 전달할 때는 파라미터를, 함수 내부의 결과를 밖으로 전달할 때는 `return`을 사용한다.

## 2. 파라미터와 인자

### 2.1 기본값 파라미터

파라미터에 기본값을 지정하면 호출할 때 인자를 생략할 수 있다. 인자를 전달하면 전달한 값이 기본값보다 우선한다.

``` python
def func(p_x=0):
    return p_x + 10

func()    # 10
func(20)  # 30
```

기본값이 없는 필수 파라미터는 기본값이 있는 파라미터보다 앞에 선언해야 한다.

``` python
def func(p_y, p_x=0):
    return p_x + 10 + (p_y * 2)

func(p_y=20)  # 50
func(20, 10)  # 60
```

### 2.2 위치 인자와 키워드 인자

위치 인자는 선언된 순서에 따라 전달되고, 키워드 인자는 파라미터 이름을 지정해 전달한다.

``` python
func(20, 10)    # p_y=20, p_x=10
func(p_y=20)    # p_y만 지정하고 p_x는 기본값 사용
```

> **핵심:** 특정 파라미터에 값을 명확히 전달하려면 `파라미터=값` 형태의 키워드 인자를 사용한다.

## 3. 가변 인자

### 3.1 `*args`

`*args`는 개수가 정해지지 않은 위치 인자를 하나의 튜플로 받는다.

``` python
def add(*args):
    total = 0
    for value in args:
        total += value
    return total

add(1, 2, 3, 4, 5, 6)
```

실행 결과:

``` text
21
```

### 3.2 `**kwargs`

`**kwargs`는 개수가 정해지지 않은 키워드 인자를 하나의 딕셔너리로 받는다.

``` python
def info(**kwargs):
    name = "신사임당"
    age = 18

    if "p_name" in kwargs:
        name = kwargs["p_name"]
    if "p_age" in kwargs:
        age = kwargs["p_age"]

    return f"{name}님은 나이가 {age}입니다."

info(p_name="홍길동", p_age=33)
```

실행 결과:

``` text
'홍길동님은 나이가 33입니다.'
```

> **핵심:** `*args`는 여러 위치 인자를 튜플로, `**kwargs`는 여러 키워드 인자를 딕셔너리로 묶는다.

## 4. 함수로 문제 해결하기

### 4.1 최솟값·최댓값·중앙값

리스트를 정렬하면 첫 원소가 최솟값, 마지막 원소가 최댓값이 된다. 중앙값은 데이터 개수가 홀수이면 가운데 값이고, 짝수이면 가운데 두 값의 평균이다.

``` python
def get_median(values):
    if len(values) % 2 != 0:
        return values[len(values) // 2]
    return (values[len(values) // 2 - 1] + values[len(values) // 2]) / 2

def summarize(values):
    values.sort()
    return f"{values[0]} / {values[-1]} / {get_median(values)}"

numbers = [8, 6, 2, 8, 5, 1, 2, 5, 4, 9]
print(summarize(numbers))
```

실행 결과:

``` text
1 / 9 / 5.0
```

`random.choice()`는 한 항목을 선택하므로 여러 번 호출하면 같은 값이 다시 나올 수 있다. `random.sample()`은 지정한 개수의 항목을 중복 없이 추출한다.

### 4.2 Enum을 활용한 가위바위보

``` python
import enum
import random

class 가위바위보(enum.Enum):
    가위 = 0
    바위 = 1
    보 = 2

def 게임(사용자_선택: str = "가위") -> str:
    assert 사용자_선택 in 가위바위보.__members__, "잘못 입력했습니다."
    컴퓨터_선택 = random.choice(list(가위바위보.__members__))
    결과 = (가위바위보[사용자_선택].value - 가위바위보[컴퓨터_선택].value) % 3
    print(f"사용자입력: {사용자_선택} & 컴퓨터입력: {컴퓨터_선택}")
    return "승" if 결과 == 1 else "무" if 결과 == 0 else "패"
```

두 선택의 Enum 값 차이를 `3`으로 나눈 나머지가 `1`이면 사용자 승리, `0`이면 무승부, 나머지는 패배로 판단한다.

## 5. 다양한 함수 활용 방식

### 5.1 람다 함수

람다 함수는 `def` 없이 한 줄로 작성하는 익명 함수이다. 짧은 함수를 다른 함수에 전달할 때 사용할 수 있다.

``` python
students = [("철수", 90), ("영희", 85)]
students.sort(key=lambda student: student[1], reverse=True)
```

### 5.2 클로저

클로저는 내부 함수가 정의될 때의 바깥 변수를 기억하여 바깥 함수 실행이 끝난 뒤에도 그 값을 사용하는 구조이다. 바깥 함수의 값을 변경하려면 `nonlocal`을 사용한다.

``` python
def counter():
    count = 0

    def increase():
        nonlocal count
        count += 1
        return count

    return increase

c = counter()
c()  # 1
c()  # 2
```

### 5.3 콜백 함수

콜백 함수는 다른 함수의 인자로 전달되어 필요한 시점에 호출되는 함수이다.

``` python
def 계산(x, y, callback):
    return callback(x, y)

def 더하기(x, y):
    return x + y

계산(3, 4, 더하기)  # 7
```

### 5.4 재귀 함수

재귀 함수는 자기 자신을 다시 호출한다. 호출이 끝나는 종료 조건이 반드시 필요하다.

``` python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

factorial(5)  # 120
```

### 5.5 데코레이터

데코레이터는 기존 함수의 코드를 직접 바꾸지 않고 함수 실행 앞뒤에 기능을 덧붙인다. `@데코레이터명` 형태로 적용한다.

``` python
def timer(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 실행 시작")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 실행 끝")
        return result
    return wrapper

@timer
def hello():
    print("hello")

hello()
```

실행 결과:

``` text
hello 실행 시작
hello
hello 실행 끝
```

## 전체 흐름

``` text
함수를 정의하고 호출
  ↓
기본값·위치·키워드 인자로 입력 제어
  ↓
*args·**kwargs로 가변 입력 처리
  ↓
기존 자료형과 조건 검사를 함수로 묶어 문제 해결
  ↓
람다·클로저·콜백·재귀·데코레이터로 함수 활용 확장
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 함수 | 이름을 붙여 재사용하는 코드 묶음 |
| 파라미터·인자 | 함수 정의의 입력 변수와 호출할 때 전달하는 값 |
| `return` | 결과를 호출한 곳으로 반환하고 함수 종료 |
| `*args` | 여러 위치 인자를 튜플로 받음 |
| `**kwargs` | 여러 키워드 인자를 딕셔너리로 받음 |
| 람다·클로저·콜백 | 짧은 함수, 환경을 기억하는 함수, 다른 함수에 전달되는 함수 |
| 재귀 함수 | 자기 자신을 다시 호출하는 함수 |
| 데코레이터 | 기존 함수를 감싸 추가 기능을 적용하는 함수 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `def 함수명(파라미터)` | 함수 정의 |
| `return 값` | 값 반환 후 함수 종료 |
| `def func(x=0)` | 기본값 파라미터 지정 |
| `func(x=10)` | 키워드 인자 전달 |
| `def func(*args)` | 여러 위치 인자 받기 |
| `def func(**kwargs)` | 여러 키워드 인자 받기 |
| `lambda x: 표현식` | 람다 함수 작성 |
| `@decorator` | 데코레이터 적용 |

### ⭐ 오늘의 핵심

- **함수 기본:** 파라미터로 입력을 받고 `return`으로 결과를 반환하는 재사용 가능한 코드를 만든다.
- **유연한 입력:** 기본값, 위치·키워드 인자, `*args`, `**kwargs`로 다양한 호출 방식을 처리한다.
- **함수 활용:** 함수를 값처럼 전달하거나 반환하고, 재귀와 데코레이터로 실행 구조를 확장할 수 있다.
