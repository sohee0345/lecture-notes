### 모듈, 패키지, import

Python 코드는 기능에 따라 모듈과 패키지로 나눌 수 있으며, 다른 모듈의 기능은 `import`로 가져와 사용한다. 오늘은 Python에 기본 포함된 표준 라이브러리와 별도로 설치하는 외부 라이브러리를 같은 방식으로 불러온다.

``` python

```

> **핵심:** 모듈 전체를 가져오거나 `from 모듈 import 이름`으로 필요한 기능만 가져올 수 있다.

## 1. Python 표준 라이브러리

표준 라이브러리는 Python을 설치할 때 함께 제공되는 기능의 모음이다. 별도 패키지 설치 없이 `import`하여 사용할 수 있다.

### 1.1 `collections`

`collections`는 리스트와 딕셔너리 같은 컬렉션을 더 편리하게 다루는 자료형을 제공한다.

``` python
from collections import Counter, defaultdict

counter = Counter(["a", "b", "a", "c", "a"])
print(counter)

counts = defaultdict(int)
counts["x"] += 1
print(dict(counts))
```

실행 결과:

``` text
Counter({'a': 3, 'b': 1, 'c': 1})
{'x': 1}
```

- `Counter` → 각 값이 몇 번 등장했는지 자동으로 센다.
- `defaultdict` → 존재하지 않는 키에 접근할 때 지정한 방식으로 기본값을 만든다.
- `counter.elements()` → 개수만큼 반복된 원소를 차례로 돌려준다.

### 1.2 `math`

`math`는 수학 계산에 필요한 함수와 상수를 제공한다.

``` python
import math

math.sqrt(16)   # 4.0
math.ceil(3.1)  # 4
math.floor(3.9) # 3
math.pi         # 3.141592...
math.pow(2, 4)  # 16.0
```

### 1.3 `datetime`

`datetime`은 날짜와 시간을 표현하고 계산한다. `datetime.now()`로 현재 날짜와 시간을 구하며, `strftime()`으로 날짜를 문자열로 바꾸고 `strptime()`으로 문자열을 날짜·시간 객체로 바꿀 수 있다.

``` python
from datetime import datetime, timedelta

now = datetime.now()
text = now.strftime("%Y-%m-%d %H:%M")
parsed = datetime.strptime(text, "%Y-%m-%d %H:%M")
after_week = now + timedelta(days=7)
```

- `now.year`, `now.month`, `now.day` → 날짜 구성 요소 조회
- `now.date()`, `now.time()` → 날짜 부분과 시간 부분 조회
- `now.weekday()` → 월요일을 `0`으로 하는 요일 번호 반환
- `timedelta()` → 날짜와 시간의 차이를 표현하여 더하거나 뺄 때 사용

> **핵심:** 표준 라이브러리는 자주 필요한 자료 처리, 수학, 날짜·시간 기능을 별도 설치 없이 제공한다.

## 2. URL 인코딩과 디코딩

URL 인코딩은 한글, 공백, 특수문자 등을 URL로 전송할 수 있는 형태로 바꾸는 과정이다. 디코딩은 인코딩된 값을 다시 원래 문자로 되돌린다.

``` python
from urllib.parse import quote, unquote

encoded = quote("안녕하세요")
decoded = unquote(encoded)

print(encoded)
print(decoded)
```

실행 결과:

``` text
%EC%95%88%EB%85%95%ED%95%98%EC%84%B8%EC%9A%94
안녕하세요
```

- `quote()` → 문자를 URL 인코딩한다.
- `unquote()` → 인코딩된 문자열을 디코딩한다.

> **핵심:** URL에 직접 넣기 어려운 문자는 인코딩하여 전송하고 사용할 때 디코딩한다.

## 3. 정규표현식

정규표현식은 문자열의 형태를 패턴으로 표현하여 원하는 내용을 찾거나 검사하고 치환하는 방법이다. Python에서는 표준 라이브러리 `re`를 사용한다.

``` python
import re

text = "a1b2c3d4"
letters = re.findall(r"[a-zA-Z]", text)
numbers = re.findall(r"[0-9]", text)

print(letters)
print(numbers)
```

실행 결과:

``` text
['a', 'b', 'c', 'd']
['1', '2', '3', '4']
```

| 함수 | 역할 |
| --- | --- |
| `re.findall()` | 패턴과 일치하는 모든 문자열을 리스트로 반환 |
| `re.match()` | 문자열의 시작 부분이 패턴과 일치하는지 확인 |
| `re.sub()` | 패턴과 일치하는 부분을 다른 문자열로 치환 |
| `re.compile()` | 정규식 패턴을 미리 만들어 반복 사용 |

``` python
re.sub(r"\s+", " ", "hello    world")
```

실행 결과:

``` text
'hello world'
```

`\d`는 숫자, `\s`는 공백 문자를 나타내며 `+`는 앞의 패턴이 한 번 이상 이어지는 경우를 뜻한다.

> **핵심:** 정규표현식은 문자열을 직접 하나씩 비교하는 대신 규칙을 만들어 검색·검사·치환한다.

## 4. Streamlit 웹 앱

Streamlit은 Python 코드로 간단한 웹 애플리케이션을 만드는 외부 라이브러리이다. 표준 라이브러리와 달리 별도로 설치해야 하며 pandas, NumPy, Matplotlib, Seaborn 등과 함께 데이터를 표시하고 시각화할 수 있다.

### 4.1 텍스트와 사용자 입력

``` python
import streamlit as st

st.title("제목")
st.header("머리글")
st.caption("설명")
st.text("일반 텍스트")
st.markdown("**마크다운**")
st.code("print('Hello')", language="python")

name = st.text_input("이름을 입력하세요.")
```

각 함수는 웹 화면에 다른 형태의 텍스트나 입력 위젯을 만든다.

### 4.2 DataFrame 출력

`st.dataframe()`은 pandas DataFrame을 웹 화면에 표시한다. `column_config`를 이용하면 링크, 숫자, 차트 등 각 열의 표시 형식을 지정할 수 있다.

``` python
import numpy as np
import pandas as pd
import streamlit as st

df = pd.DataFrame(
    np.random.randn(5, 5),
    columns=[f"col_{i}" for i in range(5)]
)

st.dataframe(df)
```

### 4.3 버튼과 링크 버튼

``` python
if st.button("Say Hello"):
    st.write("Hello World!")

st.link_button("Naver", "https://www.naver.com")
```

일반 버튼은 눌렸을 때 조건식이 참이 되어 연결된 코드를 실행한다. 링크 버튼은 지정한 URL로 이동한다.

### 4.4 Form

일반 위젯은 값이 바뀔 때 앱이 다시 실행될 수 있다. `st.form()`은 여러 입력을 모은 뒤 Submit 버튼을 눌렀을 때 한 번에 처리한다.

``` python
with st.form(key="my_form"):
    name = st.text_input("이름을 입력하세요.").strip()
    submitted = st.form_submit_button("Submit")

if submitted:
    st.write(f"Hello, {name}!")
```

### 4.5 여러 페이지 구성

실습에서는 `pages` 폴더 아래에 `page01.py`, `page02.py`를 만들고 각 파일에서 Streamlit 제목을 출력했다.

``` python
import streamlit as st

st.title("Page 01")
```

> **핵심:** Streamlit은 출력 함수와 위젯을 Python 코드로 선언하여 데이터와 상호작용하는 웹 화면을 구성한다.
