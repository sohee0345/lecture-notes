## 1. 클래스와 인스턴스

클래스는 객체를 만들기 위한 설계도이고, 인스턴스는 클래스를 호출하여 실제로 만든 객체이다. 하나의 클래스로 여러 인스턴스를 만들 수 있으며 각 인스턴스는 서로 다른 데이터를 가질 수 있다.

``` python
class Person:
    def __init__(self, name):
        self.name = name

lee = Person("이순신")
kim = Person("김유신")

print(lee.name)
print(kim.name)
```

실행 결과:

``` text
이순신
김유신
```

클래스를 다시 정의해도 이미 만든 인스턴스는 이전 클래스 정의를 참조한다. 새 정의를 적용하려면 인스턴스도 다시 생성해야 한다.

### 1.1 클래스 속성과 인스턴스 속성

``` python
class Person:
    species = "Human"

    def __init__(self, name):
        self.name = name
```

- `Person.species` → 클래스에 저장되어 여러 인스턴스가 함께 참조하는 클래스 속성
- `lee.name` → 각 인스턴스에 저장되는 인스턴스 속성

### 1.2 `self`

`self`는 메서드를 호출한 현재 인스턴스를 가리킨다. `self.name = name`은 전달받은 값을 현재 인스턴스의 속성으로 저장하여 다른 메서드에서도 사용할 수 있게 한다.

``` python
class Person:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(self.name)
```

값을 기억할 필요가 없는 작업은 함수로 만들 수 있고, 상태를 저장하여 여러 메서드에서 함께 사용해야 한다면 클래스가 알맞다.

### 1.3 `__init__`

`__init__`은 인스턴스를 만들 때 자동으로 호출되어 인스턴스의 초기 상태를 설정하는 매직 메서드이다.

``` python
class Person:
    def __init__(self, name, age=0):
        self.name = name
        self.age = age

lee = Person("이순신")
kim = Person("김유신", 45)
```

> **핵심:** `self`를 통해 각 인스턴스의 속성을 저장하며 `__init__`은 생성 직후 필요한 초기값을 설정한다.

## 2. 상속과 오버라이딩

상속은 부모 클래스의 속성과 메서드를 자식 클래스가 물려받는 기능이다. 자식 클래스는 부모 기능을 그대로 사용하거나 필요한 메서드만 다시 정의할 수 있다.

``` python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "소리를 냅니다."

class Dog(Animal):
    def speak(self):
        return "멍멍"
```

`Dog`는 `Animal`의 `__init__()`과 `name` 속성을 물려받고, `speak()`는 자신의 동작에 맞게 오버라이딩한다.

> **핵심:** 상속은 기존 기능을 재사용하고 오버라이딩은 물려받은 메서드의 동작을 자식 클래스에 맞게 바꾼다.

## 3. 속성 접근과 이름 맹글링

Python에서는 속성 이름 앞의 밑줄 개수로 외부 접근에 대한 의도를 표현한다.

| 형태 | 의미 |
| --- | --- |
| `self.name` | 외부에서도 사용하는 공개 속성 |
| `self._name` | 내부 사용을 권장하는 관례 |
| `self.__name` | 이름 맹글링이 적용되는 속성 |

``` python
class Account:
    def __init__(self):
        self.name = "홍길동"
        self._note = "내부용"
        self.__pin = "1234"
```

`__pin`은 내부적으로 클래스 이름이 포함된 이름으로 바뀌기 때문에 `instance.__pin`으로 직접 조회할 수 없다. 이는 완전한 접근 차단이 아니라 외부에서 실수로 접근하거나 이름이 충돌하는 일을 줄이기 위한 방식이다.

## 4. `property`로 속성 관리하기

`@property`는 메서드를 `()` 없이 속성처럼 조회하게 한다. `@이름.setter`와 `@이름.deleter`를 함께 정의하면 같은 이름으로 값의 수정과 삭제도 관리할 수 있다.

``` python
class Student:
    def __init__(self, name):
        self.__name = name

    @property
    def name(self):
        return self.__name

    @name.setter
    def name(self, new_name):
        self.__name = new_name

    @name.deleter
    def name(self):
        del self.__name

student = Student("홍길동")
student.name = "신사임당"
print(student.name)
```

실행 결과:

``` text
신사임당
```

`@staticmethod`와 `@classmethod`도 메서드의 사용 방식을 지정하는 클래스용 데코레이터이다.

> **핵심:** property를 사용하면 내부 속성을 직접 노출하지 않고 조회·수정·삭제 동작을 메서드로 관리하면서 속성 문법을 유지할 수 있다.

## 5. 매직 메서드

매직 메서드는 이름 앞뒤에 `__`가 붙으며 특정 문법이나 상황에서 Python이 자동으로 호출한다.

| 매직 메서드 | 호출되는 상황 |
| --- | --- |
| `__init__` | 인스턴스 초기화 |
| `__call__` | 인스턴스를 함수처럼 호출 |
| `__getitem__` | `인스턴스[인덱스]` 사용 |
| `__str__` | `str(인스턴스)` 또는 `print(인스턴스)` |
| `__len__` | `len(인스턴스)` |
| `__add__` | `인스턴스 + 인스턴스` |

``` python
class MyDataset:
    def __init__(self, data):
        self.data = data

    def __getitem__(self, index):
        return self.data[index]

    def __len__(self):
        return len(self.data)

dataset = MyDataset(list(range(50, 100)))
print(dataset[-1])
print(len(dataset))
```

실행 결과:

``` text
99
50
```

> **핵심:** 매직 메서드를 정의하면 사용자 클래스의 인스턴스도 함수 호출, 인덱싱, `len()` 같은 Python 문법에 맞춰 동작하게 만들 수 있다.

## 6. 싱글톤 패턴

싱글톤은 클래스의 인스턴스를 하나만 만들고 프로그램 전체에서 공유하는 디자인 패턴이다. 데이터베이스 연결이나 설정처럼 하나의 객체를 공유하려는 경우에 사용할 수 있다.

``` python
class Singleton(type):
    _instances = {}

    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Database(metaclass=Singleton):
    pass

db1 = Database()
db2 = Database()
print(db1 is db2)
```

실행 결과:

``` text
True
```

처음 호출할 때만 인스턴스를 만들어 저장하고, 이후 호출에서는 저장된 인스턴스를 반환한다.

## 7. 모듈과 패키지로 코드 분리하기

기능을 여러 Python 파일과 폴더로 나누면 필요한 함수만 가져와 사용할 수 있다. 실습에서는 `common` 아래의 유틸리티, 샘플, AI 관련 모듈을 `app.py`에서 불러왔다.

``` python
from common.ai.ml import get_model
from common.samples import get_happy
from common.utils import add, sub

def main():
    print(f"model name: {get_model()}")

if __name__ == "__main__":
    main()
```

`from 경로 import 이름`은 지정한 모듈에서 필요한 함수나 값을 가져온다. `if __name__ == "__main__":` 블록은 해당 파일을 직접 실행할 때 진입점 역할을 한다.
