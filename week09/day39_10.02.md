### 자연어 감성분류 파이프라인

리뷰 문장은 형태소 분석과 토큰화를 거쳐 어휘집의 정수 인덱스로 변환된다. 길이를 패딩으로 통일한 뒤 임베딩 계층에서 토큰 벡터를 만들고, 1D CNN이 시퀀스 방향의 지역 패턴을 추출한다. 이진분류 모델은 하나의 logit을 출력하며 `BCEWithLogitsLoss`로 학습한다.

```text
리뷰 정제 → 토큰화 → 어휘집 인덱스 → 패딩
  ↓
Embedding → 1D CNN → Linear → logit
  ↓
BCEWithLogitsLoss → Sigmoid → 긍정·부정 예측
```

> **핵심:** 텍스트 전처리와 모델 구조는 유지하면서, 이번 수업에서는 학습률을 훈련 중에 조절하는 방법을 추가한다.

df = pd.read_csv(

```text
전체 데이터
  ├─ 학습 데이터 → 교차검증과 모델 선택

```

### 1.1 토큰화와 어휘집

Kiwi로 명사·형용사·관형사·부사·동사를 선택하고 불용어를 제거한다.

```python
stopwords = Stopwords()
kiwi = Kiwi()

def tokenizer(text):
    tokens = kiwi.tokenize(text=text, stopwords=stopwords)
    return [token.form for token in tokens if token.tag[0] in "NJMV"]
```

`<pad>`와 `<unk>`를 포함한 어휘집을 만든 뒤 토큰을 정수 인덱스로 변환하고 길이를 통일한다. 실습 전체 데이터 기준 결과에서는 어휘집 크기 10,582, 최대 문장 길이 47, 입력 배열 형태 `(9928, 47)`을 확인했다. 실제 모델 평가 파이프라인에서는 데이터 분할 후 학습 데이터만으로 어휘집과 길이 기준을 만든다.

## 2. 1D CNN 감성분류 모델

Dataset은 패딩된 토큰 인덱스를 `LongTensor`로, 이진 target을 실수 Tensor로 반환한다. 배치 크기 256에서 입력은 `(256, 47)`, target은 `(256, 1)`이었다.

### 2.1 임베딩과 특징 추출

임베딩 계층은 `(batch, sequence_length)` 형태의 인덱스를 `(batch, sequence_length, embedding_dim)` 형태의 벡터로 변환한다.

```python
class EmbeddingLayer(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

    def forward(self, features):
        return self.embedding(features)
```

실습에서 임베딩 차원 256을 사용했을 때 `(256, 47)` 입력은 `(256, 47, 256)`이 되었다. 1D CNN은 채널 축이 두 번째에 오도록 `permute(0, 2, 1)`을 적용한 뒤 두 합성곱 블록과 전역 평균 풀링으로 특징을 추출했다.

```python
self.feature_extractor = nn.Sequential(
    nn.Conv1d(embedding_dim, embedding_dim * 2, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool1d(2),
    nn.Conv1d(embedding_dim * 2, embedding_dim * 4, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool1d(2),
    nn.AdaptiveAvgPool1d(1),
)
```

임베딩 차원 256 기준 CNN 출력은 `(256, 1024, 1)`이고, Flatten과 `Linear(1024, 1)`을 거쳐 `(256, 1)` 형태의 이진분류 logit을 출력한다.

### 2.2 샘플 수 기준 손실과 정확도

`BCEWithLogitsLoss`의 기본 결과는 배치 평균 손실이다. 배치 크기를 곱해 손실 합계로 누적한 뒤 전체 샘플 수로 나누면 마지막 배치 크기가 달라도 올바른 평균을 구할 수 있다. 정확도도 맞힌 샘플 수를 전체 샘플 수로 나눈다.

```python
total_loss += loss.item() * features.size(0)
total_correct += (
    (torch.sigmoid(outputs) > 0.5).float() == targets
).sum().item()

mean_loss = total_loss / len(dataloader.dataset)
accuracy = total_correct / len(dataloader.dataset)
```

## 3. 학습률 스케줄러

학습률은 optimizer가 한 번에 파라미터를 얼마나 크게 갱신할지 정한다. 하나의 학습률을 끝까지 유지할 수도 있지만, 학습 단계에 따라 값을 바꾸면 초반에는 넓게 탐색하고 후반에는 더 세밀하게 조정할 수 있다.

학습률 스케줄러는 optimizer의 학습률을 정해진 규칙에 따라 변경한다. 스케줄러는 파라미터를 직접 갱신하지 않고 optimizer가 사용할 학습률만 조절한다.

### 3.1 CyclicLR

`CyclicLR`은 `base_lr`와 `max_lr` 사이에서 학습률을 반복적으로 올리고 내린다. 실습에서는 AdamW와 함께 다음 범위를 사용했다.

```python
base_lr = 5e-6
max_lr = 2e-5

optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=base_lr,
)

scheduler = torch.optim.lr_scheduler.CyclicLR(
    optimizer,
    base_lr=base_lr,
    max_lr=max_lr,
    step_size_up=len(train_loader),
    mode="exp_range",
    gamma=gamma,
    cycle_momentum=False,
)
```

- `base_lr` → 주기에서 사용할 최소 학습률
- `max_lr` → 주기에서 사용할 최대 학습률
- `step_size_up` → 최소값에서 최대값까지 올리는 배치 step 수
- `mode="exp_range"` → 주기가 반복될수록 진폭을 `gamma` 비율로 줄이는 방식
- `cycle_momentum=False` → AdamW처럼 momentum을 순환시키지 않는 optimizer와 사용할 설정

`step_size_up`을 배치 수로 지정했으므로 `scheduler.step()`도 각 배치의 `optimizer.step()` 직후 호출한다.

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
scheduler.step()
```

이렇게 하면 한 에포크 동안 학습률이 `base_lr`에서 `max_lr`까지 올라가고, 다음 구간에서 다시 내려오는 주기를 만들 수 있다.

### 3.2 고정 학습률과 순환 학습률

| 구분 | 고정 학습률 | CyclicLR |
| --- | --- | --- |
| 학습 중 값 | 일정 | 최소·최대 사이에서 변화 |
| 장점 | 단순하고 해석하기 쉬움 | 여러 학습률 범위를 반복적으로 탐색 |
| 주의점 | 값이 부적절하면 학습이 느리거나 불안정 | step 호출 위치와 주기 설정이 중요 |

> **핵심:** 스케줄러의 종류에 따라 `step()` 호출 시점이 다르므로 해당 스케줄러의 단위를 확인해야 한다.

## 4. 층화 교차검증과 학습 관리

`StratifiedKFold`는 각 fold의 클래스 비율을 전체 데이터와 비슷하게 유지한다. 이진 감성분류처럼 target 비율이 성능에 영향을 줄 수 있는 문제에서 유용하다.

```python
cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42,
)
```

## 5. Early Stopping과 TensorBoard 연동

Early Stopping은 검증 손실이 개선될 때 최적 모델을 저장하고, 일정 횟수 동안 개선되지 않으면 학습을 멈춘다. 학습률 스케줄러는 파라미터가 이동하는 크기를 조절하고, Early Stopping은 학습을 언제 끝낼지 결정하므로 역할이 다르다.

에포크마다 학습·검증 손실과 정확도를 TensorBoard에 기록하면 학습률 변화와 성능 곡선을 함께 해석할 수 있다.

```python
writer.add_scalar("Loss/Train", train_loss, epoch)
writer.add_scalar("Accuracy/Train", train_accuracy, epoch)
writer.add_scalar("Loss/Valid", valid_loss, epoch)
writer.add_scalar("Accuracy/Valid", valid_accuracy, epoch)
writer.add_scalar(
    "LearningRate",
    optimizer.param_groups[0]["lr"],
    epoch,
)
```

실습 실행에서 저장된 최저 검증 손실은 마지막 반복 기준 `0.1559`였고, 최종 테스트 출력은 다음과 같았다.

```text
test_loss: 0.5555
test_accuracy: 0.7684
```

이 값은 해당 실행에서 얻은 결과다. 전처리 기준과 모델 선택 과정이 테스트 데이터와 완전히 분리되어야 일반화 성능으로 해석할 수 있다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 학습률 | optimizer가 파라미터를 갱신하는 이동 크기 |
| 학습률 스케줄러 | 학습 진행에 따라 optimizer의 학습률을 변경하는 도구 |
| CyclicLR | 최소·최대 학습률 사이를 주기적으로 오가는 스케줄러 |
| 층화 교차검증 | fold마다 클래스 비율을 비슷하게 유지하는 교차검증 |
| Early Stopping | 검증 성능이 개선되지 않으면 학습을 중단하는 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `AdamW(..., lr=base_lr)` | AdamW optimizer와 초기 학습률 설정 |
| `CyclicLR(...)` | 순환 학습률 스케줄러 생성 |
| `scheduler.step()` | 다음 학습률로 갱신 |
| `optimizer.param_groups[0]["lr"]` | 현재 학습률 확인 |
| `StratifiedKFold(...)` | 클래스 비율을 유지하는 fold 생성 |

### ⭐ 오늘의 핵심

- **호출 단위:** 배치 단위로 설계한 `CyclicLR`은 각 배치의 `optimizer.step()` 뒤에 갱신한다.
- **fold 독립성:** 교차검증에서는 fold마다 모델과 학습 상태를 새로 초기화한다.
- **평가 분리:** 어휘집·패딩·모델 선택에는 테스트 데이터를 사용하지 않고 마지막 평가에만 사용한다.
