### PyTorch 분류 모델의 학습 흐름

이번 수업에서도 Dataset과 DataLoader로 배치를 만들고, 학습 루프와 평가 루프를 분리한다. 이진분류 모델은 하나의 logit을 출력하며 `BCEWithLogitsLoss`로 학습한다. 예측할 때만 Sigmoid를 적용해 확률로 바꾸고, 임계값 `0.5`를 기준으로 클래스를 결정한다.

```text
Dataset → DataLoader → 모델의 logit 출력
  ↓
BCEWithLogitsLoss로 학습
  ↓
Sigmoid로 확률 변환 → 임계값으로 클래스 결정
```

> **핵심:** 손실 함수에는 logit을 그대로 전달하고, 확률이나 클래스가 필요할 때 Sigmoid를 적용한다.

## 1. 형태소 분석과 토큰화

형태소는 의미를 가진 가장 작은 말의 단위다. 한국어는 조사와 어미가 단어에 붙기 때문에 공백만으로 나누는 것보다 형태소 분석을 통해 어간·조사·어미 등을 구분하는 것이 유용하다.

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 실질 형태소 | 대상·상태·동작 등 어휘적 의미를 가짐 | 명사, 동사·형용사의 어간 |
| 형식 형태소 | 문법적 관계나 기능을 나타냄 | 조사, 어미 |
| 자립 형태소 | 홀로 어절을 이룰 수 있음 | 명사, 대명사, 부사 등 |
| 의존 형태소 | 다른 형태소와 함께 사용됨 | 조사, 어미, 용언의 어간 |

형태소 분석기는 문장을 토큰으로 나누고 각 토큰에 품사 태그를 붙인다. 실습에서는 영어에 NLTK와 spaCy를, 한국어에 KoNLPy의 Okt·Mecab과 Kiwi를 사용했다. 분석기마다 토큰 경계와 품사 태그 체계가 다르므로 실제 데이터에 적용한 결과를 확인한 뒤 선택해야 한다.

```python
from kiwipiepy import Kiwi

kiwi = Kiwi()
tokens = kiwi.tokenize("아버지가 방에 들어가신다.")
words = [token.form for token in tokens if token.tag[0] in "NV"]
```

불용어는 분석 목적에 도움이 적은 토큰이다. Kiwi의 `Stopwords`를 전달하면 토큰화와 함께 기본 불용어를 제거할 수 있고, 데이터에 맞는 항목을 추가하거나 제거할 수도 있다.

```python
from kiwipiepy.utils import Stopwords

stopwords = Stopwords()
stopwords.add(("네이버", "NNG"))
tokens = kiwi.tokenize(text, stopwords=stopwords)
```

## 2. 어휘집과 패딩

신경망은 문자열을 직접 입력받지 못하므로 토큰을 정수 인덱스로 바꿔야 한다. 어휘집(vocabulary)은 토큰과 정수 인덱스의 대응 관계를 보관한다.

### 2.1 어휘집 생성

`build_vocab_from_iterator()`는 토큰 목록을 차례로 받아 어휘집을 만든다. `yield`를 사용한 제너레이터는 모든 토큰화 결과를 한꺼번에 메모리에 저장하지 않고 필요할 때 하나씩 제공한다.

```python
from torchtext.vocab import build_vocab_from_iterator

def yield_tokens(data, tokenizer):
    for text in data:
        yield tokenizer(text)

token_stream = yield_tokens(train_texts, tokenizer)
vocab = build_vocab_from_iterator(
    token_stream,
    specials=["<pad>", "<unk>"],
)
vocab.set_default_index(vocab["<unk>"])
```

- `<pad>` → 길이가 짧은 문장의 빈 부분을 채우는 특수 토큰
- `<unk>` → 어휘집에 없는 토큰을 나타내는 특수 토큰
- `vocab(tokens)` → 토큰 목록을 정수 인덱스 목록으로 변환
- `vocab.lookup_tokens(indices)` → 정수 인덱스를 토큰으로 복원

어휘집은 데이터 분할 후 학습 데이터만으로 만든다. 검증·테스트 데이터의 토큰 빈도를 미리 사용하면 평가 데이터의 정보가 학습 과정에 들어가는 데이터 누수가 발생한다. 검증·테스트에서 처음 만난 토큰은 `<unk>`로 처리한다.

### 2.2 패딩으로 길이 통일

문장마다 토큰 수가 다르지만 한 배치의 텐서는 같은 길이를 가져야 한다. 정수로 변환한 문장이 기준 길이보다 짧으면 뒤에 `<pad>` 인덱스를 추가하고, 길면 정한 기준에 맞게 잘라 낸다.

```python
pad_index = vocab["<pad>"]

def pad_sequence(indices, max_length):
    indices = indices[:max_length]
    return indices + [pad_index] * (max_length - len(indices))
```

네이버 리뷰 실습에서는 5,000개 문장으로 7,065개 토큰의 어휘집을 만들고 길이를 40으로 맞춘 `(5000, 40)` 배열을 확인했다. 모델 입력에서는 토큰 인덱스를 `torch.LongTensor`로 변환해야 `nn.Embedding`이 사용할 수 있다.

## 3. 단어 임베딩

정수 인덱스는 토큰을 구분하는 번호일 뿐 그 자체로 의미의 가까움을 표현하지 않는다. 임베딩 계층은 각 인덱스를 학습 가능한 밀집 벡터로 바꾼다.

```python
class EmbeddingLayer(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

    def forward(self, features):
        return self.embedding(features)
```

입력 형태가 `(batch, sequence_length)`라면 출력은 `(batch, sequence_length, embedding_dim)`이다. iPhone 리뷰 실습에서는 `(256, 576)` 입력이 임베딩 차원 128을 거쳐 `(256, 576, 128)`로 변환되었다.

| 값 | 의미 |
| --- | --- |
| `vocab_size` | 어휘집에 등록된 전체 토큰 수 |
| `embedding_dim` | 토큰 하나를 표현할 벡터의 크기 |
| 입력 dtype | 정수 인덱스이므로 `torch.long` |

## 4. 1D CNN 텍스트 분류

1D CNN은 문장의 토큰 순서를 따라 커널을 이동시키며 인접한 토큰 벡터의 지역 패턴을 찾는다. 이미지 CNN이 높이와 너비를 따라 움직이는 것과 달리, 텍스트에서는 시퀀스 길이 한 축을 따라 합성곱한다.

### 4.1 입력 축 변환

임베딩 출력은 `(batch, sequence_length, embedding_dim)`이지만 `Conv1d`는 `(batch, channels, length)`를 입력으로 받는다. 따라서 임베딩 차원을 채널로 사용하도록 축을 바꾼다.

```python
features = embedded.permute(0, 2, 1)
```

```text
(batch, sequence_length, embedding_dim)
  ↓ permute(0, 2, 1)
(batch, embedding_dim, sequence_length)
```

### 4.2 합성곱과 전역 풀링

`kernel_size`는 한 번에 살펴볼 연속 토큰 범위를, `stride`는 커널의 이동 간격을 뜻한다. Max Pooling은 중요한 반응을 남기며 길이를 줄이고, `AdaptiveAvgPool1d(1)`은 길이 축을 1로 만들어 문장 길이와 관계없이 고정 크기 벡터를 만든다.

```python
self.cnn = nn.Sequential(
    nn.Conv1d(embedding_dim, embedding_dim * 2, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool1d(2),
    nn.Conv1d(embedding_dim * 2, embedding_dim * 4, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool1d(2),
    nn.AdaptiveAvgPool1d(1),
)
```

iPhone 리뷰 실습에서 `(256, 576, 128)` 임베딩은 1D CNN을 거쳐 `(256, 512, 1)`이 되었고, Flatten과 선형층을 거쳐 이진분류 logit 형태 `(256, 1)`이 되었다.

```python
class CNN1dModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim=128):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.cnn = CNN1dLayer(embedding_dim)
        self.fc = nn.Sequential(
            nn.Flatten(),
            nn.Linear(embedding_dim * 4, 1),
        )

    def forward(self, features):
        embedded = self.embedding(features)
        extracted = self.cnn(embedded)
        return self.fc(extracted)
```

## 5. 감성분류 데이터와 학습

네이버 영화 리뷰 실습은 리뷰 문장을 feature로, 긍정·부정 label을 target으로 사용했다. 결측치를 제거하고 불필요한 문자를 정리한 뒤 Kiwi로 토큰화하고, 어휘집 인덱스와 패딩을 적용해 Dataset을 구성했다.

iPhone 리뷰 실습에서는 검증된 리뷰만 선택하고 제목과 본문을 합쳐 feature를 만들었다. 평점 5점은 `Like`, 나머지는 `Dislike`인 이진 target으로 만들었으며, 중복 제거 후 1,829개 데이터를 사용했다.

```python
df_train, df_valid = train_test_split(
    reviews,
    stratify=reviews["target"],
    test_size=0.1,
    shuffle=True,
)
```

클래스 비율을 유지하도록 `stratify`를 사용한다. 그 다음 학습 데이터로 tokenizer와 어휘집을 준비하고, 학습·검증 데이터에 같은 어휘집과 같은 길이 기준을 적용한다.

정확도는 각 배치 정확도의 단순 평균보다 전체 정답 수를 전체 샘플 수로 나누어 계산하는 편이 안전하다. 마지막 배치의 크기가 다를 수 있기 때문이다.

```python
correct = 0
sample_count = 0

probabilities = torch.sigmoid(logits)
predicted = (probabilities > 0.5).long()
correct += (predicted == targets.long()).sum().item()
sample_count += targets.numel()

accuracy = correct / sample_count
```

## 6. Ray Tune을 이용한 하이퍼파라미터 탐색

Ray Tune은 여러 설정의 학습 작업(trial)을 실행하고 성능을 비교하는 도구다. 실습에서는 임베딩 차원, 학습률, 배치 크기를 탐색했다.

```python
config = {
    "embedding_dim": tune.choice([64, 128, 256, 512]),
    "lr": tune.loguniform(1e-4, 1e-1),
    "batch_size": tune.choice([16, 32, 64, 128]),
}
```

ASHA 스케줄러는 성능이 좋지 않은 trial을 일찍 중단하고 계산 자원을 유망한 trial에 집중한다. 각 에포크가 끝날 때 검증 손실과 정확도, 모델·optimizer 상태를 보고하고 체크포인트를 저장한다.

```python
scheduler = ASHAScheduler(
    metric="loss",
    mode="min",
    max_t=max_num_epochs,
    grace_period=1,
    reduction_factor=2,
)

tune.report(
    {"loss": valid_loss, "accuracy": valid_accuracy},
    checkpoint=checkpoint,
)
```

12개 trial을 5에포크까지 실행한 기록에서 선택된 설정과 마지막 검증 결과는 다음과 같았다.

```text
embedding_dim: 64
learning rate: 0.0006844129600502225
batch size: 64
validation loss: 0.6755058964093527
validation accuracy: 0.581155303030303
```

이 값은 해당 실행의 결과이며 항상 같은 최적값을 보장하지 않는다. 탐색 과정에는 학습 데이터와 검증 데이터만 사용하고, 최종 테스트 데이터는 설정 선택이 끝난 뒤 한 번 평가한다.

## 전체 흐름

```text
리뷰 데이터 정제와 학습·검증 분할
  ↓
학습 문장 형태소 분석·토큰화
  ↓
학습 데이터로 어휘집 생성
  ↓
토큰을 정수 인덱스로 변환하고 패딩

Embedding으로 토큰 벡터 생성

Conv1d로 인접 토큰 패턴 추출

전역 풀링과 선형층으로 감성 logit 출력
  ↓
BCEWithLogitsLoss로 학습·검증
  ↓
Ray Tune과 ASHA로 설정 비교
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 형태소 분석 | 문장을 형태소로 나누고 품사 정보를 부여하는 과정 |
| 어휘집 | 토큰과 정수 인덱스의 대응 관계 |
| 패딩 | 서로 다른 문장 길이를 같은 길이로 맞추는 처리 |
| 임베딩 | 토큰 인덱스를 학습 가능한 밀집 벡터로 변환 |
| 1D CNN | 시퀀스 방향으로 커널을 이동해 지역 패턴을 추출하는 모델 |
| ASHA | 성능이 낮은 trial을 조기에 중단하는 스케줄링 방법 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `kiwi.tokenize(text)` | 한국어 형태소 분석과 토큰화 |
| `build_vocab_from_iterator(...)` | 토큰 스트림으로 어휘집 생성 |
| `nn.Embedding(...)` | 토큰 인덱스를 벡터로 변환 |
| `embedded.permute(0, 2, 1)` | Conv1d 입력 순서로 축 변경 |
| `nn.Conv1d(...)` | 시퀀스의 지역 패턴 추출 |
| `nn.AdaptiveAvgPool1d(1)` | 길이 축을 고정 크기로 축소 |
| `tune.report(...)` | trial의 지표와 체크포인트 보고 |

### ⭐ 오늘의 핵심

- **전처리 순서:** 데이터를 먼저 분할하고 학습 데이터만으로 어휘집을 만든 뒤 모든 데이터에 같은 변환을 적용한다.
- **형태 변화:** 정수 인덱스 `(B, L)`은 임베딩 `(B, L, E)`을 거쳐 Conv1d 입력 `(B, E, L)`이 된다.
- **실험 선택:** 하이퍼파라미터는 검증 성능으로 비교하고 테스트 데이터는 최종 평가에만 사용한다.
