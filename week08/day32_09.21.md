### 이미지 데이터와 전처리 파이프라인

이미지 한 장을 PyTorch 텐서로 바꾸면 축 순서는 `(채널, 높이, 너비)`가 되고, `DataLoader`가 여러 장을 묶으면 `(배치, 채널, 높이, 너비)`가 된다. `ImageFolder`는 클래스별 하위 폴더의 이름을 라벨로 사용하여 이미지 분류용 데이터셋을 만든다.

학습 데이터에는 무작위 자르기 같은 증강을 적용할 수 있지만, 평가 데이터에는 결과가 매번 달라지는 변환을 사용하지 않는다. 두 전처리 파이프라인이 달라도 최종 이미지 크기와 채널 수는 모델의 입력 형식에 맞아야 한다.

```python
train_transform = transforms.Compose([
    transforms.Resize((256, 256)),
    transforms.RandomCrop((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=train_mean, std=train_std),
])
```

> **핵심:** 변환은 작성한 순서대로 실행되며, `Normalize`는 텐서에 적용하므로 `ToTensor` 뒤에 배치한다.

## 1. CNN의 입력과 특징 추출

CNN(Convolutional Neural Network)은 이미지의 공간 구조를 유지하면서 주변 픽셀의 패턴을 학습하는 신경망이다. 합성곱층과 풀링층으로 특징을 추출하고, 마지막에는 특징 맵을 펼쳐 분류층에 전달한다.

### 1.1 이미지 텐서의 형태

손글씨 숫자 데이터는 한 장이 `8×8`인 흑백 이미지다. 한 번에 20장을 모델에 넣는다면 입력 형태는 `(20, 1, 8, 8)`이다.

| 축 | 의미 |
| --- | --- |
| 배치 | 한 번에 처리하는 이미지 수 |
| 채널 | 흑백은 1개, RGB는 3개 |
| 높이 | 이미지의 세로 픽셀 수 |
| 너비 | 이미지의 가로 픽셀 수 |

실습에서는 `load_digits()` 데이터를 학습용 1,437개와 평가용 360개로 나누었다. 사용자 정의 `Dataset`이 각 64개 픽셀 벡터를 `(1, 8, 8)` 텐서로 바꾸고, `DataLoader`는 이를 `(64, 1, 8, 8)` 형태의 미니배치로 묶었다.

### 1.2 합성곱층

합성곱층은 커널이라는 작은 필터를 이미지 위로 이동시키며 선, 모서리, 질감처럼 분류에 필요한 지역 특징을 찾는다. 커널의 가중치는 학습 과정에서 조정되고, 연산 결과는 특징 맵(feature map)이 된다.

```python
conv = nn.Conv2d(
    in_channels=1,
    out_channels=10,
    kernel_size=3,
)

images = torch.randn(20, 1, 28, 28)
features = conv(images)
print(features.shape)
```

실행 결과:

```text
torch.Size([20, 10, 26, 26])
```

- `in_channels` → 입력 이미지 또는 이전 층에서 들어오는 특징 맵의 수
- `out_channels` → 현재 합성곱층이 만들 특징 맵의 수
- `kernel_size` → 커널이 한 번에 확인하는 영역의 크기
- `stride` → 커널이 한 번에 이동하는 간격
- `padding` → 입력 가장자리에 추가하는 여백

정사각형 입력에서 dilation을 사용하지 않을 때 한 변의 출력 크기는 다음과 같이 계산한다.

$$O=\left\lfloor\frac{I-K+2P}{S}\right\rfloor+1$$

$I$는 입력 크기, $K$는 커널 크기, $P$는 패딩, $S$는 스트라이드다. 분류층의 입력 크기를 정할 때는 추측하지 말고 이 계산이나 실제 출력 텐서의 `shape`를 확인해야 한다.

### 1.3 풀링층

풀링은 특징 맵의 작은 영역을 대표값 하나로 줄여 공간 크기를 축소한다. 최대 풀링은 영역의 최댓값을, 평균 풀링은 평균값을 사용한다. 두 방식 모두 모델의 구조와 목적에 따라 사용할 수 있다.

```python
pool = nn.MaxPool2d(kernel_size=3, stride=2)
pooled = pool(features)
print(pooled.shape)
```

실행 결과:

```text
torch.Size([20, 10, 12, 12])
```

풀링을 통과해도 배치 수와 채널 수는 유지되고, 특징 맵의 높이와 너비가 줄어든다.

> **핵심:** 합성곱은 학습 가능한 커널로 특징을 추출하고, 풀링은 각 특징 맵의 공간 크기를 줄인다.

## 2. 특징 추출부와 분류부 연결

CNN은 크게 특징 추출부와 분류부로 나눌 수 있다. 특징 추출부는 `Conv2d → ReLU → Pooling`을 반복하고, 분류부는 마지막 특징 맵을 `Flatten`으로 펼친 뒤 완전연결층에 전달한다.

### 2.1 작은 손글씨 CNN

```python
class ConvLayer(nn.Module):
    def __init__(self, in_channels, out_channels=10):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, kernel_size=2),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
            nn.Conv2d(out_channels, out_channels, kernel_size=2),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2, stride=2),
        )

    def forward(self, x):
        return self.layers(x)
```

`(20, 1, 8, 8)` 입력은 두 합성곱층과 두 풀링층을 거쳐 `(20, 10, 1, 1)`이 된다. 따라서 분류부의 첫 `Linear` 계층이 받을 특징 수는 `10×1×1=10`이다.

```text
(20, 1, 8, 8)
  → Conv2d
(20, 10, 7, 7)
  → MaxPool2d
(20, 10, 3, 3)
  → Conv2d
(20, 10, 2, 2)
  → MaxPool2d
(20, 10, 1, 1)
  → Flatten
(20, 10)
```

입력이 작은데 합성곱과 풀링을 너무 많이 적용하면 높이와 너비가 0에 가까워져 연산할 수 없게 된다. 커널 하나만 따로 보는 것이 아니라 앞선 모든 층을 통과한 출력 크기를 차례로 확인해야 한다.

### 2.2 Flatten과 분류층

```python
class DenseLayer(nn.Module):
    def __init__(self, feature_size, target_size, hidden_size=10):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Flatten(),
            nn.Linear(feature_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, target_size),
        )

    def forward(self, x):
        return self.layers(x)
```

`feature_size`는 마지막 특징 맵의 `채널 수 × 높이 × 너비`와 정확히 일치해야 한다. `target_size`는 손글씨 숫자 `0~9`를 구분하므로 10이 된다. `torchinfo.summary()`로 각 층의 출력 형태와 파라미터 수를 확인하면 설계 오류를 빠르게 찾을 수 있다.

## 3. 이미지 분류 데이터 준비

### 3.1 ImageFolder의 폴더 구조

일반 이미지 분류 데이터는 학습용과 평가용 폴더 아래에 클래스별 하위 폴더를 둔다. `ImageFolder`는 하위 폴더 이름을 클래스 이름으로 읽고 숫자 라벨을 자동으로 연결한다.

```text
train/
  pizza/
  steak/
  sushi/
test/
  pizza/
  steak/
  sushi/
```

`Path`로 파일 경로를 모은 뒤 이미지를 직접 열어 보면 파일, 클래스 폴더, 라벨이 예상대로 연결되는지 먼저 검증할 수 있다.

### 3.2 학습용과 평가용 전처리 분리

| 전처리 | 역할 |
| --- | --- |
| `Resize` | 이미지 크기를 모델 입력에 맞게 조정 |
| `RandomCrop` | 무작위 위치를 잘라 학습 입력의 다양성 확대 |
| `ToTensor` | 이미지를 `(C, H, W)` 텐서로 변환 |
| `Normalize` | 채널별 평균과 표준편차로 픽셀 분포 조정 |

`RandomCrop`은 같은 파일을 읽을 때마다 다른 영역을 선택할 수 있지만 원본 파일 수를 늘리지는 않는다. 잘라낼 크기는 해당 시점의 이미지보다 클 수 없으므로 `Resize`와 `RandomCrop`의 순서와 크기를 함께 점검한다.

평가 데이터에는 무작위 변환을 제외해 같은 모델을 같은 조건에서 비교한다. 정규화에 사용하는 평균과 표준편차는 학습 데이터에서만 계산한 뒤 학습용과 평가용 데이터에 동일하게 적용해야 한다. 평가 데이터까지 통계 계산에 포함하면 데이터 누수가 발생한다.

## 4. VGG16 구조

VGG16은 작은 `3×3` 합성곱을 반복하고 각 블록 끝에서 최대 풀링으로 공간 크기를 줄이는 CNN이다. 앞부분은 이미지 특징을 추출하고, 뒷부분의 완전연결층은 추출된 특징으로 클래스를 분류한다.

### 4.1 다섯 개 특징 추출 블록

입력이 `3×224×224`일 때 블록별 출력은 다음과 같다.

| 단계 | 출력 형태: 채널 × 높이 × 너비 |
| --- | ---: |
| 입력 | `3 × 224 × 224` |
| 블록 1 | `64 × 112 × 112` |
| 블록 2 | `128 × 56 × 56` |
| 블록 3 | `256 × 28 × 28` |
| 블록 4 | `512 × 14 × 14` |
| 블록 5 | `512 × 7 × 7` |

```python
block1 = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
)
```

`kernel_size=3, padding=1`인 합성곱은 높이와 너비를 유지하고, `MaxPool2d(2, 2)`가 공간 크기를 절반으로 줄인다. 블록이 깊어질수록 공간 크기는 작아지고 채널 수는 늘어나므로 위치 정보는 압축되지만 더 다양한 특징을 표현할 수 있다.

### 4.2 분류층과 VGG16의 이름

다섯 번째 블록의 `512×7×7` 특징 맵은 `Flatten`을 거쳐 완전연결층으로 들어간다. 실습 데이터가 피자, 스테이크, 스시의 세 클래스이므로 마지막 계층의 출력 수는 3이다.

VGG16의 `16`은 가중치를 학습하는 합성곱층 13개와 완전연결층 3개를 합한 수다. ReLU와 풀링층은 여기에 포함하지 않는다.

> **핵심:** VGG16은 합성곱 블록을 지날수록 공간 크기를 줄이고 채널을 늘린 뒤, `512×7×7` 특징을 펼쳐 분류한다.

## 5. 학습 결과 해석

VGG16은 파라미터와 메모리 사용량이 큰 모델이므로 실습에서는 GPU를 사용했다. 그러나 모델이 크다는 사실만으로 적은 데이터에서 좋은 성능이 보장되지는 않는다. 실습에서 낮은 F1 점수가 나타났다면 데이터 부족을 우선 의심할 수 있지만, 원인을 판단할 때는 다음 요소를 함께 확인해야 한다.

- 클래스별 학습·평가 데이터 수와 불균형
- 학습 손실과 평가 손실의 변화
- 학습용·평가용 전처리 설정
- 입력 이미지 크기와 라벨 연결 상태
- 모델의 크기와 학습 설정

데이터가 부족할 때는 의미를 유지하는 데이터 증강이나 사전 학습 모델의 미세조정을 고려할 수 있다.

## 전체 흐름

```text
클래스별 이미지 폴더 구성과 라벨 확인
  ↓
학습용·평가용 transform 분리
  ↓
ImageFolder와 DataLoader로 (N, C, H, W) 배치 생성
  ↓
합성곱으로 특징 추출
  ↓
풀링으로 공간 크기 축소
  ↓
Flatten으로 특징 맵을 벡터로 변환
  ↓
완전연결층으로 클래스 예측
  ↓
손실과 F1 점수로 학습 결과 점검
```

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| `Conv2d` | 커널을 이동시키며 지역 특징을 추출하는 합성곱층 |
| 특징 맵 | 합성곱으로 추출된 특징의 위치별 반응 |
| 풀링 | 배치와 채널 수를 유지하면서 특징 맵의 공간 크기를 축소하는 연산 |
| `Flatten` | 다차원 특징 맵을 분류층이 받을 벡터로 변환하는 연산 |
| VGG16 | 작은 합성곱과 최대 풀링을 블록 단위로 반복하는 CNN 구조 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `nn.Conv2d(in_channels, out_channels, kernel_size)` | 2차원 합성곱층 생성 |
| `nn.MaxPool2d(kernel_size, stride)` | 영역별 최댓값으로 공간 크기 축소 |
| `nn.Flatten()` | `(C, H, W)` 특징을 `C×H×W` 벡터로 변환 |
| `ImageFolder(root, transform=...)` | 폴더 기반 이미지 분류 데이터셋 생성 |
| `torchinfo.summary(model, input_size=...)` | 층별 출력 형태와 파라미터 수 확인 |

### ⭐ 오늘의 핵심

- **출력 크기 추적:** 분류층의 입력 수는 마지막 특징 맵의 `채널×높이×너비`와 일치해야 한다.
- **전처리 원칙:** 학습 데이터만 무작위 증강하고, 정규화 통계는 학습 데이터에서만 계산한다.
- **VGG16 구조:** 다섯 블록을 지나며 공간 크기는 줄고 채널 수는 늘어나며, 마지막에는 `512×7×7` 특징을 분류에 사용한다.
