### CNN과 VGG16의 특징 추출

CNN은 합성곱층으로 이미지의 지역 특징을 추출하고 풀링층으로 특징 맵의 공간 크기를 줄인다. VGG16은 `3×3` 합성곱을 반복하는 다섯 개 블록을 사용하며, `3×224×224` 입력을 마지막에 `512×7×7` 특징 맵으로 변환한다.

```text
3×224×224
  ↓ VGG 블록 1~5
512×7×7
  ↓ Flatten
25,088개 특징
  ↓ 완전연결층
3개 클래스 logits
```

이전 실습에서는 피자·스테이크·스시 이미지가 적어 VGG16을 처음부터 학습했을 때 충분한 성능을 얻기 어려웠다. 이번 수업에서는 학습 이미지의 다양성을 늘리고, 깊은 신경망의 학습을 돕는 새로운 구조를 살펴본다.

> **핵심:** 데이터가 적을 때는 모델을 크게 만드는 것만으로 부족하며, 학습 데이터와 모델 구조를 함께 개선해야 한다.

## 1. 이미지 데이터 증강

이미지 데이터 증강(Data Augmentation)은 기존 학습 이미지를 회전하거나 반전하는 등 의미를 유지하는 변형을 적용해 다양한 학습 사례를 만드는 방법이다. 이미지 수가 적을 때 모델이 일부 사진의 위치, 방향, 배경을 외우는 현상을 줄이고 일반화에 도움을 줄 수 있다.

### 1.1 증강할 때 지켜야 할 원칙

증강은 단순히 이미지를 많이 만드는 작업이 아니다. 변형된 이미지가 여전히 같은 클래스로 보이고, 실제 환경에서 나타날 수 있는 모습이어야 한다.

- 클래스의 의미를 바꾸지 않는 범위에서 변형한다.
- 원본을 그대로 복사하기보다 방향과 형태에 실제 변화를 준다.
- 지나친 왜곡으로 음식의 특징이 사라지지 않도록 한다.
- 피자·스테이크·스시의 증강 비율을 비슷하게 유지한다.
- 평가 데이터는 증강하지 않고 일정한 조건으로 평가한다.

이번 데이터의 클래스별 학습 이미지 수는 스시 72장, 스테이크 75장, 피자 78장으로 총 225장이다. 실습에서는 각 원본에 네 번씩 무작위 변환을 적용하여 클래스 구조를 유지한 900장의 변환 이미지를 별도 폴더에 저장했다.

| 클래스 | 원본 수 | 원본당 변환 수 | 저장된 변환본 수 |
| --- | ---: | ---: | ---: |
| 스시 | 72 | 4 | 288 |
| 스테이크 | 75 | 4 | 300 |
| 피자 | 78 | 4 | 312 |
| 합계 | 225 | 4 | 900 |

### 1.2 증강 변환 구성

```python
from torchvision import transforms as T

transformer = T.Compose([
    T.RandomPerspective(distortion_scale=0.1, p=1.0),
    T.RandomRotation(degrees=(0, 180)),
    T.RandomHorizontalFlip(p=0.5),
    T.RandomVerticalFlip(p=0.5),
    T.ElasticTransform(alpha=50.0),
])
```

| 변환 | 역할 |
| --- | --- |
| `RandomPerspective` | 원근에 따른 형태 변화를 적용 |
| `RandomRotation` | 지정한 각도 범위에서 무작위 회전 |
| `RandomHorizontalFlip` | 확률에 따라 좌우 반전 |
| `RandomVerticalFlip` | 확률에 따라 상하 반전 |
| `ElasticTransform` | 이미지에 탄성 형태의 왜곡 적용 |

`Compose` 안의 변환은 앞에서부터 순서대로 실행된다. 각 변환에 무작위성이 있으므로 같은 원본을 여러 번 처리해도 서로 다른 결과가 나올 수 있다.

### 1.3 변환 이미지를 파일로 저장하기

```python
from pathlib import Path
from torchvision.io import read_image, write_jpeg

for class_name in ["sushi", "steak", "pizza"]:
    save_dir = augmentation_path / class_name
    save_dir.mkdir(parents=True, exist_ok=True)

    for image_path in train_path.glob(f"{class_name}/*.jpg"):
        image = read_image(image_path)

        for index in range(4):
            transformed = transformer(image)
            filename = f"{index}_{image_path.name}"
            write_jpeg(transformed, save_dir / filename)
```

저장할 폴더도 `sushi`, `steak`, `pizza`처럼 클래스별로 나누어야 이후 `ImageFolder`가 라벨을 올바르게 연결할 수 있다. 파일명 앞에 반복 번호를 붙이면 같은 원본에서 만든 여러 이미지가 서로 덮어써지는 것을 막을 수 있다.

> **핵심:** 저장형 증강은 변환 결과를 새 파일로 만들며, 온라인 증강은 학습 중 이미지를 불러올 때마다 변환한다.

## 2. 증강 데이터로 VGG16 다시 학습하기

증강 효과를 확인하려면 모델과 평가 조건을 가능한 한 동일하게 유지하고 학습 데이터만 바꾸어야 한다. 그래야 성능 차이가 데이터 증강과 관련 있는지 비교하기 쉽다.

### 2.1 VGG16 입력과 출력 확인

```python
class VGG16(nn.Module):
    def __init__(self, class_count=3):
        super().__init__()
        self.features = ConvLayer(color_size=3)
        self.classifier = DenseLayer(
            feature_size=512 * 7 * 7,
            target_size=class_count,
        )

    def forward(self, x):
        return self.classifier(self.features(x))
```

`224×224` RGB 이미지가 다섯 개 블록을 지나면 `(배치, 512, 7, 7)`이 되고, `Flatten` 이후 한 이미지당 25,088개의 특징이 분류층에 전달된다. 실습의 출력 클래스는 피자·스테이크·스시 세 개이므로 마지막 `Linear` 계층의 출력 수는 3이다.

### 2.2 정규화 스케일 일치시키기

`read_image()`가 반환하는 정수 텐서는 일반적으로 `0~255` 범위를 사용하고, `ToTensor()`는 픽셀값을 `0~1` 범위의 실수 텐서로 바꾼다. 따라서 평균과 표준편차를 계산한 스케일과 `Normalize`에 입력되는 이미지 스케일이 같아야 한다.

```python
from torchvision.io import read_image

images = [
    read_image(path).float() / 255.0
    for path in train_path.glob("*/*.jpg")
]

# 채널별 통계를 학습 데이터의 0~1 스케일에서 계산한다.
channel_mean = torch.stack([
    image.mean(dim=(1, 2)) for image in images
]).mean(dim=0)

channel_std = torch.stack([
    image.std(dim=(1, 2)) for image in images
]).mean(dim=0)
```

```python
train_transform = T.Compose([
    T.ToTensor(),
    T.Normalize(
        mean=channel_mean.tolist(),
        std=channel_std.tolist(),
    ),
    T.RandomCrop((262, 262)),
    T.Resize((224, 224)),
])
```

정규화 통계는 학습 데이터에서만 계산하고 평가 데이터에는 같은 값을 적용한다. `0~255`에서 구한 통계를 `0~1` 텐서에 그대로 적용하면 값의 크기가 맞지 않아 학습이 불안정해질 수 있다.

### 2.3 저장된 학습 결과 해석

증강 전 VGG 실습의 저장된 F1 점수는 다음과 같다.

```text
F1 score: 0.23747474747474748
```

증강 데이터를 사용한 노트북에서는 첫 에포크부터 손실이 매우 큰 값으로 기록되었다. 이 결과는 증강의 효과로 해석할 수 없으며, 먼저 입력 픽셀과 정규화 통계의 스케일, 실제 데이터셋 크기, 배치 형태를 점검해야 한다. 전처리를 바로잡아 같은 조건에서 다시 학습한 평가 결과가 있어야 증강 전후 성능을 비교할 수 있다.

데이터 증강은 성능 향상을 보장하지 않는다. 변형의 종류와 강도가 데이터에 맞지 않거나 전처리 파이프라인에 문제가 있으면 성능이 유지되거나 오히려 나빠질 수 있다.

## 3. ResNet과 잔차 학습

신경망을 깊게 만들면 더 복잡한 특징을 표현할 수 있지만, 모든 층을 단순히 순서대로 쌓는다고 항상 잘 학습되는 것은 아니다. 앞쪽 층까지 기울기가 원활하게 전달되지 않거나, 깊이가 늘어난 모델의 학습이 오히려 어려워질 수 있다.

ResNet(Residual Network)은 입력을 몇 개의 층 뒤로 직접 전달하는 스킵 연결(skip connection)을 사용하여 이 문제를 완화한다.

### 3.1 잔차 블록의 동작

일반적인 블록이 입력 $x$를 목표 출력으로 직접 바꾸는 함수를 학습한다면, 잔차 블록은 입력에서 달라져야 할 부분인 $F(x)$를 학습하고 원래 입력 $x$를 더한다.

$$y=F(x)+x$$

```text
x ───────────────┐
│                │ shortcut
↓                │
Conv → BN → ReLU │
↓                │
Conv → BN        │
│                │
└──── F(x) + x ──┘
         ↓
       ReLU
```

스킵 연결은 원래 정보가 합성곱층을 거치지 않고도 뒤쪽으로 전달되는 경로를 만든다. 역전파 때도 기울기가 이 직접 경로를 통해 전달될 수 있어 깊은 모델의 학습을 돕는다.

### 3.2 BasicBlock 구현

```python
class BasicBlock(nn.Module):
    expansion = 1

    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()

        self.residual = nn.Sequential(
            nn.Conv2d(
                in_channels, out_channels,
                kernel_size=3, stride=stride, padding=1,
            ),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(),
            nn.Conv2d(
                out_channels, out_channels,
                kernel_size=3, padding=1,
            ),
            nn.BatchNorm2d(out_channels),
        )

        self.shortcut = nn.Identity()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(
                    in_channels, out_channels,
                    kernel_size=1, stride=stride,
                ),
                nn.BatchNorm2d(out_channels),
            )

        self.relu = nn.ReLU()

    def forward(self, x):
        return self.relu(self.residual(x) + self.shortcut(x))
```

`residual` 경로는 두 번의 `3×3` 합성곱으로 $F(x)$를 만든다. `shortcut` 경로는 입력을 덧셈 위치까지 전달한다. 두 텐서를 더하려면 채널 수와 높이·너비가 모두 같아야 한다.

- 형태가 같으면 `nn.Identity()`로 입력을 그대로 전달한다.
- 채널 수가 달라지면 `1×1` 합성곱으로 채널을 맞춘다.
- `stride=2`로 공간 크기를 줄일 때는 shortcut에도 같은 stride를 적용한다.

실습에서 `(1, 3, 224, 224)` 입력을 `BasicBlock(3, 64)`에 넣은 출력은 `(1, 64, 224, 224)`였다. 채널 수가 3에서 64로 바뀌므로 shortcut의 `1×1` 합성곱이 덧셈 가능한 형태를 만든다.

### 3.3 ResNet18 구성

```python
def ResNet18(class_count):
    return ResNet(
        block=BasicBlock,
        num_blocks=[2, 2, 2, 2],
        num_classes=class_count,
    )
```

ResNet18은 네 단계에 BasicBlock을 각각 두 개씩 쌓는다. 단계가 바뀔 때 첫 블록의 `stride=2`로 공간 크기를 줄이고 채널 수를 `64 → 128 → 256 → 512`로 늘린다.

```text
입력: 3×224×224
  ↓ 초기 합성곱
64×224×224
  ↓ BasicBlock × 2
64×224×224
  ↓ BasicBlock × 2
128×112×112
  ↓ BasicBlock × 2
256×56×56
  ↓ BasicBlock × 2
512×28×28
  ↓ AdaptiveAvgPool2d(1, 1)
512×1×1
  ↓ Flatten + Linear
3개 클래스 logits
```

`AdaptiveAvgPool2d((1, 1))`는 각 채널의 공간 정보를 하나의 값으로 요약한다. 그 결과 입력 이미지의 공간 크기에 직접 의존하는 큰 완전연결층을 줄이고, 512개 특징을 마지막 분류층에 전달할 수 있다.

> **핵심:** ResNet은 잔차 경로와 shortcut 경로의 출력을 더하며, 덧셈 전에는 두 텐서의 형태가 반드시 같아야 한다.

## 4. VGG와 ResNet 비교

| 구분 | VGG16 | ResNet18 |
| --- | --- | --- |
| 기본 구조 | 합성곱을 순차적으로 반복 | 잔차 블록과 스킵 연결 반복 |
| 정보 흐름 | 앞 층의 출력이 다음 층으로만 전달 | 입력이 블록 출력을 향해 직접 전달되는 경로 존재 |
| 공간 축소 | 주로 최대 풀링 사용 | 단계 시작 블록의 stride와 적응형 평균 풀링 사용 |
| 분류부 | 큰 완전연결층 사용 | 채널별 평균 후 작은 선형층 사용 |
| 핵심 목적 | 일정한 규칙의 깊은 특징 추출 | 깊은 모델에서 정보와 기울기 전달 보조 |

두 모델의 성능을 공정하게 비교하려면 같은 학습·평가 데이터 분할과 전처리, 같은 평가 지표를 사용해야 한다. 모델 구조 외의 조건이 달라지면 성능 차이의 원인을 하나로 판단하기 어렵다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| 이미지 데이터 증강 | 의미를 유지하는 변형으로 학습 이미지의 다양성을 높이는 방법 |
| 저장형 증강 | 변환 결과를 실제 이미지 파일로 저장하는 방식 |
| 스킵 연결 | 입력을 여러 층 뒤의 출력에 직접 전달하는 경로 |
| 잔차 블록 | $F(x)+x$ 형태로 합성곱 경로와 shortcut을 결합한 블록 |
| ResNet18 | BasicBlock을 `[2, 2, 2, 2]`로 쌓은 잔차 신경망 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `T.Compose([...])` | 여러 이미지 변환을 순서대로 결합 |
| `write_jpeg(tensor, path)` | 변환한 이미지 텐서를 JPEG 파일로 저장 |
| `self.residual(x) + self.shortcut(x)` | 잔차 경로와 스킵 연결의 결과 결합 |
| `nn.Conv2d(..., kernel_size=1)` | shortcut의 채널과 공간 크기 조정 |
| `nn.AdaptiveAvgPool2d((1, 1))` | 각 채널의 공간 정보를 하나의 값으로 요약 |

### ⭐ 오늘의 핵심

- **증강의 기준:** 이미지 수보다 클래스 의미를 유지하는 적절한 변형과 클래스 균형이 중요하다.
- **공정한 비교:** 증강 효과는 올바른 전처리와 동일한 평가 조건에서 다시 측정해야 한다.
- **ResNet의 핵심:** $F(x)+x$ 구조는 정보와 기울기가 깊은 네트워크를 통과하도록 돕는다.
