## 🔁 이전 내용 복습

### ResNet과 이미지 분류

ResNet은 잔차 블록에서 합성곱 경로의 출력 $F(x)$와 입력 $x$를 더하는 스킵 연결을 사용한다. 이 구조는 깊은 네트워크에서 정보와 기울기가 전달되도록 돕는다. 이미지 분류 모델의 앞부분은 이미지 특징을 추출하고, 마지막 분류층은 추출된 특징으로 클래스별 logits를 만든다.

```text
입력 이미지
  ↓ 사전학습된 특징 추출부
일반적인 이미지 특징
  ↓ 새 분류층
피자·스테이크·스시 logits
```

> **핵심:** 기존 특징 추출부를 재사용하고 마지막 분류층을 새 문제에 맞게 바꾸면 적은 데이터에서도 학습을 시작하기 유리하다.

## 1. 사전학습과 전이학습

### 1.1 세 개념의 관계

사전학습(pre-training)은 큰 데이터셋으로 모델의 가중치를 미리 학습하는 과정이다. 전이학습(transfer learning)은 이렇게 얻은 지식을 새로운 문제에 재사용하는 전체 방법을 뜻한다. 미세조정(fine-tuning)은 전이학습 과정에서 사전학습된 층의 일부 또는 전체 가중치를 새 데이터에 맞게 추가 학습하는 방식이다.

| 개념 | 의미 |
| --- | --- |
| 사전학습 | 큰 데이터셋으로 일반적인 특징을 미리 학습 |
| 전이학습 | 사전학습 모델의 표현을 새로운 문제에 활용 |
| 특징 추출 방식 | 사전학습 층을 동결하고 새 분류층만 학습 |
| 미세조정 | 사전학습 층의 일부 또는 전체도 추가 학습 |

전이학습과 미세조정은 서로 완전히 분리된 개념이 아니다. 전이학습이 더 넓은 개념이고, 미세조정은 이를 수행하는 한 방식이다.

### 1.2 동결과 학습 대상

모델이 학습된다는 것은 역전파로 계산한 기울기를 이용해 가중치를 업데이트한다는 뜻이다. PyTorch에서는 `requires_grad`로 각 파라미터의 학습 여부를 제어할 수 있다.

```python
for parameter in model.parameters():
    parameter.requires_grad = False
```

위 코드는 기존 모델의 모든 파라미터를 동결한다. 이후 새 `Linear` 계층을 생성하면 그 계층의 파라미터는 기본적으로 학습 가능하므로 분류기만 새 데이터에 맞게 학습할 수 있다.

데이터가 적고 사전학습 데이터와 새 데이터가 비슷하면 특징 추출부를 많이 동결하는 방식이 유리할 수 있다. 두 문제가 다르거나 새 데이터가 충분하면 뒤쪽 층부터 동결을 풀어 미세조정할 수 있다.

> **핵심:** 동결 범위는 데이터의 양과 사전학습 문제·새 문제의 유사성을 함께 고려해 정한다.

## 2. 사전학습 ResNet18 적용

### 2.1 가중치와 전처리를 함께 사용하기

```python
import torchvision

weights = torchvision.models.ResNet18_Weights.IMAGENET1K_V1
transform = weights.transforms()
```

사전학습 가중치는 특정 크기 조정과 정규화 조건에서 학습되었다. 따라서 가중치 객체가 제공하는 `transforms()`를 사용해야 입력 분포를 학습 당시 조건에 맞출 수 있다.

실습의 ResNet18 전처리는 다음 조건을 사용했다.

| 항목 | 설정 |
| --- | --- |
| resize | 256 |
| center crop | 224 |
| RGB 평균 | `[0.485, 0.456, 0.406]` |
| RGB 표준편차 | `[0.229, 0.224, 0.225]` |

이 전처리를 적용한 배치의 형태는 `(8, 3, 224, 224)`였다. 학습 데이터는 225장, 평가 데이터는 75장이었다.

### 2.2 분류층 교체

```python
from torch import nn
from torchvision.models import resnet18

model = resnet18(weights=weights)

for parameter in model.parameters():
    parameter.requires_grad = False

model.fc = nn.Linear(
    in_features=model.fc.in_features,
    out_features=3,
)
```

ImageNet 사전학습 ResNet18의 기존 `fc`는 1,000개 클래스를 출력한다. 현재 문제는 피자·스테이크·스시 세 클래스를 구분하므로 출력층을 `512 → 3` 구조로 교체한다.

새 `fc`는 모델 전체를 동결한 다음 생성했기 때문에 학습 가능하다. `torchinfo.summary()`로 학습 가능한 파라미터를 확인하면 실제로 의도한 층만 업데이트되는지 검증할 수 있다.

## 3. EfficientNet-B0 전이학습

EfficientNet은 CNN의 깊이, 너비, 입력 해상도를 함께 조절해 계산량 대비 좋은 성능을 얻도록 설계된 모델 계열이다. 실습에서는 ImageNet 사전학습 EfficientNet-B0를 세 종류의 음식 분류에 적용했다.

### 3.1 모델과 전처리 불러오기

```python
from torchvision.models import (
    EfficientNet_B0_Weights,
    efficientnet_b0,
)

weights = EfficientNet_B0_Weights.DEFAULT
transform = weights.transforms()
model = efficientnet_b0(weights=weights)
```

ResNet과 마찬가지로 EfficientNet도 가중치에 대응하는 전처리를 함께 사용한다. 임의의 정규화 값을 사용하면 사전학습 모델이 예상하는 입력 분포와 달라질 수 있다.

### 3.2 특징 추출부 동결과 새 분류기 추가

```python
class MyModel(nn.Module):
    def __init__(self, target_size=3):
        super().__init__()
        self.pretrained_model = efficientnet_b0(weights=weights)

        for parameter in self.pretrained_model.parameters():
            parameter.requires_grad = False

        self.classifier = nn.Sequential(
            nn.SiLU(),
            nn.Linear(in_features=1000, out_features=target_size),
        )

    def forward(self, features):
        pretrained_logits = self.pretrained_model(features)
        return self.classifier(pretrained_logits)
```

실습에서는 기존 EfficientNet-B0가 만든 1,000개 ImageNet logits 뒤에 `1000 → 3` 분류기를 추가했다. 모델 요약에서는 전체 파라미터 5,291,551개 가운데 새 선형층의 3,003개만 학습 가능했고, 나머지 5,288,548개는 동결되어 있었다. 기존 마지막 선형층 자체를 `1280 → 3`으로 교체하는 방법도 가능하지만, 두 방식은 모델 구조와 학습 가능한 파라미터 수가 다르므로 구분해야 한다.

### 3.3 학습과 평가 결과

실습에서는 교차 엔트로피 손실, Adam optimizer, 조기 종료를 사용했다. 가장 낮은 검증 손실은 약 `0.2995`였고, 저장된 최적 모델의 평가 정확도는 다음과 같았다.

```text
best validation loss: 0.2994522700707118
test accuracy: 0.8257575757575758
```

에포크별 정확도는 데이터 순서와 배치에 따라 변할 수 있으므로, 최종 모델은 마지막 에포크가 아니라 검증 손실이 가장 좋을 때 저장한 체크포인트를 사용한다.

## 4. 예측 결과 확인

다중분류 모델의 출력은 클래스별 logits다. `softmax`로 확률로 변환하고 `argmax`로 가장 큰 확률의 클래스 인덱스를 선택한다.

```python
model.eval()

with torch.inference_mode():
    image = transform(pil_image).unsqueeze(0).to(device)
    logits = model(image)
    probabilities = torch.softmax(logits, dim=1)
    predicted_index = torch.argmax(probabilities, dim=1)
```

- `eval()` → dropout과 batch normalization을 평가 모드로 전환
- `inference_mode()` → 기울기 계산을 끄고 추론 비용 절감
- `unsqueeze(0)` → 한 장의 이미지에 배치 축 추가
- `softmax(..., dim=1)` → 클래스별 logits를 확률로 변환
- `argmax(..., dim=1)` → 가장 높은 확률의 클래스 선택

정확도만으로 모델을 모두 이해할 수는 없다. 모델이 음식 자체를 보고 판단했는지, 배경이나 접시 같은 우연한 요소에 의존했는지도 확인할 필요가 있다.

## 5. XAI와 Occlusion Attribution

XAI(Explainable AI)는 모델이 왜 특정 예측을 했는지 사람이 이해할 수 있도록 설명하는 방법이다. 이미지 분류에서는 입력의 어느 영역이 특정 클래스 점수에 영향을 주었는지 히트맵으로 확인할 수 있다.

### 5.1 Occlusion의 동작 방식

Occlusion Attribution은 이미지의 작은 영역을 기준값으로 가린 뒤 목표 클래스의 출력이 얼마나 달라지는지 측정한다.

```text
원본 이미지의 목표 클래스 점수
  ↓ 작은 영역을 가림
가린 이미지의 목표 클래스 점수
  ↓ 점수 변화 계산
해당 영역의 기여도 추정
```

가렸을 때 점수가 크게 떨어지는 영역은 목표 클래스 예측에 긍정적으로 기여했을 가능성이 크다. 반대로 점수가 올라가면 그 영역이 목표 클래스 점수를 낮추는 방향으로 작용했을 수 있다.

### 5.2 Captum으로 기여도 계산

```python
from captum.attr import Occlusion

model.eval()
occlusion = Occlusion(model)

attribution = occlusion.attribute(
    input_img,
    strides=(3, 9, 9),
    target=target_index,
    sliding_window_shapes=(3, 20, 20),
    baselines=0,
)
```

- `target` → 설명할 클래스 인덱스
- `sliding_window_shapes` → 한 번에 가릴 채널·높이·너비
- `strides` → 가림 창의 이동 간격
- `baselines` → 가린 영역을 채울 기준값

실습에서 `(1, 3, 224, 224)` 입력으로 계산한 attribution도 같은 형태인 `(1, 3, 224, 224)`였다. stride가 작으면 더 촘촘한 설명을 얻을 수 있지만 반복 추론 횟수가 늘어 계산이 느려진다.

### 5.3 히트맵 해석 시 주의점

히트맵과 함께 표시하는 원본 이미지는 모델에 실제로 입력한 영역과 같은 크롭·해상도를 사용해야 한다. 서로 다른 영역을 겹치면 강조 위치를 잘못 해석하게 된다.

또한 Occlusion 결과는 가림 창의 크기, stride, baseline, 목표 클래스에 따라 달라진다. 강조된 영역은 모델의 민감도를 보여 주는 설명이지, 그 영역이 현실의 인과적 원인임을 증명하는 것은 아니다.

> **핵심:** XAI 히트맵은 정확도와 함께 모델의 판단 근거를 점검하는 도구이며, 설명 결과 자체를 정답이나 인과관계로 해석하면 안 된다.

## 6. EfficientNet과 MobileNet

EfficientNet과 MobileNet은 모두 계산 효율을 고려하지만 목적과 설계 방식은 다르다.

| 구분 | EfficientNet | MobileNet |
| --- | --- | --- |
| 중심 목표 | 깊이·너비·해상도의 균형 있는 확장 | 모바일 환경을 위한 연산량과 모델 크기 절감 |
| 주요 활용 | 성능과 계산 비용의 균형이 필요한 작업 | 자원이 제한된 기기에서의 빠른 추론 |
| 공통점 | 효율적인 이미지 특징 추출을 목표로 하는 CNN | 효율적인 이미지 특징 추출을 목표로 하는 CNN |

모델은 정확도만으로 선택하지 않는다. 실제 사용할 장치의 메모리, 추론 속도, 모델 크기와 요구 성능을 함께 고려해야 한다.

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `weights.transforms()` | 사전학습 가중치에 맞는 전처리 반환 |
| `parameter.requires_grad = False` | 기존 파라미터 동결 |

### ⭐ 오늘의 핵심

- **전이학습의 범위:** 미세조정은 전이학습의 한 방식이며, 일부 또는 전체 사전학습 가중치를 업데이트한다.
- **가중치와 전처리:** 사전학습 가중치는 해당 가중치가 제공하는 입력 변환과 함께 사용한다.
- **설명과 평가:** 성능 지표와 Occlusion 히트맵을 함께 보되 히트맵을 인과관계로 해석하지 않는다.
