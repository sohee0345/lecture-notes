### NumPy 배열의 차원과 축

NumPy의 벡터는 1차원 배열, 행렬은 2차원 배열로 표현할 수 있다. `shape`은 축별 크기, `ndim`은 축의 개수를 나타낸다. 기본 산술 연산은 같은 위치의 원소끼리 수행되며 집계 함수에 `axis`를 지정하면 해당 축을 따라 값을 줄인다.

```python
import numpy as np

arr = np.arange(20).reshape(4, 5)
arr.min(axis=1)  # [0, 5, 10, 15]
```

> **핵심:** 행렬 곱셈은 전날 배운 원소별 곱셈과 계산 방식과 shape 조건이 다르다.

## 1. Feature와 Target

머신러닝 데이터는 예측에 사용하는 특성(Feature)과 예측하려는 결과인 타깃(Target)으로 나눌 수 있다.

| 구분 | 다른 표현 | 기호 | 역할 |
| --- | --- | --- | --- |
| 독립변수 | Feature | `X` | 결과를 설명하거나 예측하는 입력 변수 |
| 종속변수 | Target | `y` | 모델이 예측하려는 결과 |

집값 예측에서는 평수, 방 개수, 역과의 거리가 Feature이고 집값이 Target이다. 여기서 독립변수라는 이름은 각 Feature가 서로 통계적으로 독립이라는 뜻이 아니다. Feature끼리 지나치게 비슷한 정보를 가지면 특히 선형회귀에서 다중공선성 문제가 생길 수 있다.

```text
몸무게(kg) × 1000 = 몸무게(g)
```

두 컬럼은 표현 단위만 다를 뿐 같은 정보를 담으므로 함께 사용할 때 중복 정보가 된다. 실제 Feature 사이에 어느 정도 상관관계가 있다는 이유만으로 바로 제외하는 것은 아니며 예측과 모델에 미치는 영향을 확인해야 한다.

## 2. 벡터의 관계

### 2.1 직교

두 벡터의 내적이 0이면 직교(Orthogonal)한다. 영벡터가 아닌 두 직교 벡터는 기하학적으로 90도를 이룬다.

```text
A ↑
B →
```

### 2.2 선형 독립과 선형 종속

여러 벡터 중 어느 하나도 나머지 벡터의 선형 결합으로 표현할 수 없으면 선형 독립이다. 반대로 0이 아닌 계수를 사용한 선형 결합이 영벡터가 되면 선형 종속이다.

두 벡터만 비교할 때 한 벡터가 다른 벡터의 배수라면 선형 종속이다.

```text
A = [1, 2]
B = [2, 4] = 2A
C = [-1, -2] = -A
```

`A`와 `B`, `A`와 `C`는 모두 선형 종속이다. 배수가 양수인지 음수인지는 종속 여부를 바꾸지 않는다.

## 3. 코사인 유사도

코사인 유사도는 두 벡터 사이 각도의 코사인 값으로 방향의 유사성을 측정한다.

$$
\mathrm{cos\_sim}(\mathbf{a},\mathbf{b})
=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|_2\|\mathbf{b}\|_2}
$$

| 값 | 방향 관계 |
| ---: | --- |
| `1` | 같은 방향 |
| `0` | 직교 |
| `-1` | 반대 방향 |

벡터 사이의 각도가 커질수록 코사인 값이 작아지는 것이며 벡터 자체의 길이가 짧아지는 것은 아니다. 크기가 0인 벡터는 분모가 0이 되므로 위 식으로 코사인 유사도를 계산할 수 없다.

## 4. 행렬과 행렬 곱셈

행렬은 숫자를 행과 열로 배치한 2차원 구조이다. 덧셈과 뺄셈, `*` 연산은 같은 위치의 원소끼리 계산하지만 행렬 곱셈은 앞 행렬의 행과 뒤 행렬의 열을 내적한다.

```text
A shape (2, 4) × B shape (4, 8)
                    ↓
안쪽 크기 4가 같으므로 곱셈 가능
                    ↓
결과 shape (2, 8)
```

일반화하면 다음과 같다.

```text
(a, b) × (b, c) → (a, c)
```

연속 곱셈도 왼쪽부터 중간 결과의 shape을 확인한다.

```text
(2, 4) × (4, 8) × (8, 3)
  → (2, 8) × (8, 3)
  → (2, 3)
```

> [!WARNING]
> **행렬 곱셈 순서**
> 행렬 곱셈은 교환법칙이 일반적으로 성립하지 않으므로 $AB$와 $BA$는 결과가 다르거나 한쪽 곱셈이 불가능할 수 있다.

## 5. L1·L2 Norm과 거리

Norm은 벡터 자체의 크기를 측정한다. 두 벡터의 거리는 차이 벡터에 Norm을 적용해 구한다.

### 5.1 L1 Norm과 맨해튼 거리

$$
\|\mathbf{x}\|_1=\sum_i |x_i|
$$

```text
x = [1, 2, 3]
L1 Norm = |1| + |2| + |3| = 6
```

두 점 `A=[1, 2]`, `B=[4, 6]`의 L1 거리는 다음과 같다.

```text
A - B = [-3, -4]
|-3| + |-4| = 7
```

이 거리를 맨해튼 거리(Manhattan Distance)라고 한다.

### 5.2 L2 Norm과 유클리드 거리

$$
\|\mathbf{x}\|_2=\sqrt{\sum_i x_i^2}
$$

```text
x = [3, 4]
L2 Norm = √(3² + 4²) = 5
```

`A=[1, 2]`, `B=[4, 6]`의 L2 거리는 5이며 유클리드 거리(Euclidean Distance)라고 한다.

## 6. Pandas Series와 DataFrame

Pandas는 NumPy를 기반으로 표 형태 데이터를 다루는 라이브러리이다. Series는 값과 인덱스를 가진 1차원 구조이고 DataFrame은 여러 Series가 컬럼으로 모인 2차원 구조이다. 벡터와 행렬에 비유할 수 있지만 Pandas 객체는 인덱스·컬럼 이름과 서로 다른 자료형도 다룬다는 차이가 있다.

```python
import numpy as np
import pandas as pd

series = pd.Series(
    data={"a": 1, "b": 2, "c": 3},
    dtype=np.int16,
)

df = pd.DataFrame({
    "one": pd.Series(np.random.randn(5)),
    "two": pd.Series(np.random.randn(5)),
})
```

```python
df.shape
df.index
df.columns
```

- `shape` → `(행 개수, 컬럼 개수)`이다.
- `index` → 각 행을 구분하는 레이블이다.
- `columns` → 컬럼 이름을 담은 Index이다.

새 컬럼은 기존 컬럼 연산으로 만들 수 있다.

```python
df["new"] = df["one"] + df["two"]
```

## 7. DataFrame 탐색과 조건 필터링

Iris 데이터는 150행 5열이며 네 개의 수치형 특성과 품종 컬럼으로 구성된다.

```python
import seaborn as sns

iris = sns.load_dataset("iris")

iris.head()
iris.tail()
iris.info()
iris.shape  # (150, 5)
```

`RangeIndex(start=0, stop=150, step=1)`은 0부터 149까지의 기본 인덱스를 뜻한다. 일반적으로 Pandas Index는 숫자에 한정되지 않고 각 행을 식별하는 레이블이다.

### 7.1 범주형 컬럼 확인

```python
iris["species"].unique()
iris["species"].nunique()
iris["species"].value_counts()
iris["species"].mode()[0]
```

- `unique()` → 중복을 제거한 고유값을 반환한다.
- `nunique()` → 고유값 개수를 반환한다.
- `value_counts()` → 값별 행 개수를 계산한다.
- `mode()` → 최빈값을 반환한다.

### 7.2 조건 조합

```python
cond = (
    iris["sepal_width"].isin([3.5, 3.2])
) & (
    iris["species"] == "setosa"
)

selected = iris[cond]
excluded = iris[~cond]
```

- `isin([...])` → 여러 후보 중 하나와 일치하는지 검사한다.
- `&` → 두 조건을 모두 만족하는 행을 선택한다.
- `~` → 불리언 조건을 반대로 뒤집는다.

`iris[cond] = True`처럼 대입하면 조회가 아니라 선택한 위치의 실제 값이 바뀌므로 결과를 변수에 저장하는 필터링과 구분한다.

### 7.3 iloc과 컬럼 선택

```python
iris.iloc[1:4, 1:3]
iris[["sepal_length", "sepal_width"]]
```

`iloc`은 행과 열을 정수 위치로 선택한다. 여러 컬럼을 이름으로 선택할 때는 컬럼 이름 리스트를 사용한다.

```python
new_order = list(iris.columns[4:]) + list(iris.columns[:4])
iris = iris[new_order]
```

Pandas Index끼리 `+`를 사용하면 단순 리스트 연결과 다르게 원소별 문자열 연산이 일어날 수 있으므로 컬럼 순서를 합칠 때는 리스트로 변환한다.

## 8. groupby와 집계

`groupby()`는 같은 값을 가진 행을 그룹으로 묶고 그룹별 통계를 계산한다.

```python
iris.groupby("species")["sepal_length"].agg(["mean", "max"])
```

실행 결과:

| species | mean | max |
| --- | ---: | ---: |
| setosa | 5.006 | 5.8 |
| versicolor | 5.936 | 7.0 |
| virginica | 6.588 | 7.9 |

```python
iris.groupby("species")[["sepal_length", "sepal_width"]].min()
```

그룹 기준, 집계할 컬럼, 집계 함수를 순서대로 정하면 된다.

```text
groupby(그룹 기준)
  ↓
[집계할 컬럼]
  ↓
mean·min·max·agg
```

## 9. map과 apply

`Series.map()`은 Series의 각 값에 함수나 매핑 규칙을 적용한다.

```python
sex_code = {"male": 0, "female": 1}
df["sex_code"] = df["sex"].map(sex_code)
```

`DataFrame.apply(..., axis=1)`은 각 행을 함수에 전달해 여러 컬럼을 함께 계산할 수 있다.

```python
def family_count(row: pd.Series) -> int:
    return row["sibsp"] + row["parch"]

df["family_cnt"] = df.apply(family_count, axis=1)
```

`axis=1`이므로 함수의 `row`에는 한 행을 나타내는 Series가 전달된다.

나이대를 만든 뒤 그룹별 생존율을 계산할 수도 있다.

```python
age_data = df[(df["age"] >= 10) & (df["age"] < 40)].copy()
age_data["age_group"] = age_data["age"].map(
    lambda age: (age // 10) * 10
)

age_data.groupby("age_group")["survived"].mean()
```

실행 결과:

| age_group | survived mean |
| ---: | ---: |
| 10 | 0.401961 |
| 20 | 0.350000 |
| 30 | 0.437126 |

> [!NOTE]
> **`map()`과 `apply()` 구분**
> `Series.apply()`도 사용할 수 있으므로 `map()`은 한 컬럼, `apply()`는 여러 컬럼이라는 구분은 절대적인 규칙이 아니다. 이번 실습에서는 값 하나씩 변환할 때 `map()`, 한 행의 여러 컬럼을 함께 계산할 때 DataFrame의 `apply(axis=1)`를 사용했다.

## 🟦 핵심 정리

### 💡 주요 개념

| 개념 | 의미 |
| --- | --- |
| Feature / Target | 예측에 사용하는 입력 변수 / 예측하려는 결과 |
| 선형 독립 | 어느 벡터도 나머지 벡터의 선형 결합으로 표현되지 않는 관계 |
| 코사인 유사도 | 벡터 사이 방향의 유사성을 측정하는 값 |
| 행렬 곱셈 | 앞 행렬의 행과 뒤 행렬의 열을 내적하는 연산 |
| L1 / L2 Norm | 절댓값 합 / 제곱합의 제곱근으로 벡터 크기를 측정 |
| Series / DataFrame | Pandas의 1차원 / 2차원 데이터 구조 |
| `groupby` | 같은 값을 가진 행을 묶어 그룹별로 계산 |

### 💻 주요 코드

| 코드 | 의미 |
| --- | --- |
| `iris[cond]` / `iris[~cond]` | 조건을 만족하는 행 / 만족하지 않는 행 선택 |
| `iris.iloc[rows, cols]` | 정수 위치로 행과 열 선택 |
| `series.unique()` / `value_counts()` | 고유값 / 값별 개수 확인 |
| `df.groupby(key)[cols].agg(...)` | 그룹별 여러 통계 계산 |
| `series.map(func)` | Series의 각 값을 변환 |
| `df.apply(func, axis=1)` | 각 행에 함수를 적용 |

### ⭐ 오늘의 핵심

- **선형대수:** 벡터의 관계와 방향, 행렬 곱셈, Norm은 데이터의 구조와 거리를 이해하는 기초이다.
- **Pandas 선택:** Index와 컬럼을 확인하고 불리언 조건 또는 `iloc`으로 필요한 데이터를 선택한다.
- **Pandas 변환·집계:** 값 단위 변환은 `map()`, 행 단위 계산은 `apply(axis=1)`, 그룹 통계는 `groupby()`를 활용한다.
